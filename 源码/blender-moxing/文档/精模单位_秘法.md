# 秘法单位 · 精模（破法者 / 魔金傀儡）

> 单位库的第二条管线：**低模 cage + 倒角**。
> 与「方块人」（`unitkit.py`，4 点截面 + 平面着色）**并行存在，互不影响** —— 不要拿方块人的判据验收这两件，也不要把这里的写法套回步兵/弩兵。
>
> **v2 已重做（2026-11-09）。** v1 的病根是"笔触比例"：85% 的零件填了 `soft`（CC 细分），
> 做出来是橡皮泥骑士 + 穿金宇航员。v2 把语言翻成硬边，见第 2 节的笔触表。

---

## 1 为什么另开一条管线

方块人的判据是「截面 4 点 + 平面着色」，做出来是 1.7 m 高的方头小人；这两件的设计要求是
「小巧精致、材质干净、俯视角 96 px 可读」的**小品精游**质感 —— 需要比方块人多一档的转折密度
（一条棱、一条缝、一枚钉），但**不需要圆**。

v1 把"精致"理解成了"细分"，于是整件变圆。v2 的结论：

> **精致来自"棱上的那条倒角高光"，不来自曲面细分。**

| 对比项 | unitkit.py（方块人） | unitkit2.py（精模） |
|---|---|---|
| 截面 | 4 点方截面 | 4 / 8 点**切角**矩形（`octs`）、超椭圆 |
| 着色 | `smooth=False` | `facet/chunk*` 平面着色；只有 `soft` 走平滑 |
| 材质 | 单人色板图集，统一粗糙度 | 每材质独立 metallic / roughness |
| 装配 | 按材质合并（3 个物体） | **按模块合并**（可整组摘换） |
| 低模档 | 去倒角 | **关细分 + 关倒角**（cage 原样） |

## 2 笔触表（v2 的核心）

`unitkit2.STYLE`，按"越靠上越硬"排序：

| 笔触 | bevel / seg | sub | smooth | 用在哪 |
|---|---|---|---|---|
| `facet` | 0 / – | 0 | False | 内胆、薄刃、被完全遮住的体积（剪影最硬的一档） |
| `chunk` | 6 mm / 1 | 0 | False | 小件、单条棱的高光（钉、血槽、边条） |
| `chunk2` | 13 mm / 2 | 0 | False | **甲片主力**（胸甲、腿甲、护肩层、拳） |
| `chunk3` | 24 mm / 2 | 0 | False | 超大件（傀儡的板甲/靴/膝） |
| `sharp` | 0 / – | 0 | False | 纯几何（特效力场、薄片） |
| `soft` / `soft2` | 0 | 1 / 2 | True | **只给必须真的圆的件**（透镜式盾鼓面） |

**硬规矩：一件单位里 `soft` 类零件的占比不许超过 15%**（v1 是 85%，所以整件糊）。
超了就一定会读成软胶玩具，无论细节加多少。

配套几何件：

| 函数 | 作用 |
|---|---|
| `octs(w,d,cw,cd)` | 八边切角矩形截面。`cw=0` 回到 4 点纯方；`cw≈0.22w` 是"磨圆的方管" |
| `otube(name, stations, cw)` | 沿 Z 的八边放样。`stations` 第 6/7 项可逐段给切角 |
| `olimb(name, p0, p1, secs)` | 沿任意骨轴的八边放样（四肢内胆） |
| `arc_band(name, p0, p1, r0, r1, a0, a1, …)` | **绕任意骨轴**的开口弧片。护肩、腿甲、臂甲全靠它 |
| `rivet(name, c, n, r, h)` | 铆钉/轴销端盖（平着色下就是一颗硬点） |
| `arc_panel(...)` | 绕**竖轴**的弧片（裙甲、腰甲） |

`arc_band` 的角度以 `out_dir` 为 0°。**注意它的 `ez` 是 p0→p1**：腿甲从髋往踝放样时 `ez` 指向下，
于是 `perp = ez × out` 会翻向 +X。所以左腿和右腿的弧段**必须取镜像的 (a0,a1)**，
否则两片腿甲会绕到内侧、在中轴对撞（v2 踩过：YELLOW 12 处）。

## 3 破法者（Spellbreaker）

**一句话**：切角方大盔 + 三层叠片护肩 + 四块刚性腿裙 + 长面鸢盾（左）+ 跨度 0.72 m 的四刃投掷刃（右）。

| 项 | 实测（v2） |
|---|---|
| 三角面 | **22,978**（低模 9,476 / 只身体 16,746 / 刃 1,268 / 盾 4,668） |
| 包围盒 | 1.352 × 0.680 × **1.798** m |
| 脚底 | z = **0.000** |
| 骨 | **26**（root/hips/spine/chest/neck/head + 四肢 8×2 + weapon_R/L + shield + fx_cast） |
| 材质 | 钢 / 钢暗 / 银 / 布 / team / team_trim / 辉（7） |
| 零件 | 193 个，7 模块：body / head / pauldron / skirt / shield / weapon / fx |
| 动作 | idle(120f 叉腰) · idle_alt(96f 摇头) · walk(32f) · attack(45f 抛接刃) · cast(60f 举刃+闪电) · hurt(11f) · death(46f) |
| 穿模 | 跨模块 **0** / 同模块跨骨 **0** |

### 3.1 造型要点

* **盔**：一件连续放样的**切角方**大盔（8 点 `octs`，切角 32 mm），侧壁接近垂直、平顶、下颌收。
  正面只有 **±34°** 一块折面 —— 所以眼缝 / 鼻梁 / 金眉必须全部压在这块面上，否则会绕到侧脸变成"面罩天线"。
  `_se(a, w, d)` 用射线求交把折线多边形按角度参数化（这个函数写错过一次：`u` 的符号反了，
  结果盔体左右不对称、一只眼睛跑到侧面）。
* **护肩**：绕上臂轴的**三层锥面叠片**（`arc_band`），每层下沿比上层外扩 14~26 mm，层间露一条暗缝；
  顶盖用一枚八角盘 + 金环封口，俯视不漏。
* **裙甲**：前 / 左 / 右 / 后四块**刚性硬片**（片间 8° 缝），缝里塞四条 team 蓝衬条；
  前片正中一条金脊把"围裙"劈成两半。**腿从小腿起露出来** —— v1 是闭合钟罩，腿被吞掉、剪影成陀螺。
* **十字刃**：四把**直刃**，靠根 39% 等宽、之后一条直线收到尖；刃面正反各压一条钢色血槽
  （否则整把刃是"白锥子"，会读成四片花瓣）。**骨轴 = +Y = 飞行轴**，抛掷只写 `weapon_R` 的局部位移。
* **明度阶梯**：布 0.055 < 钢暗 0.17 < team 0.21 < 钢 0.30 < 金 0.55 < 银 0.72。
  蓝只落三处：盾面 / 裙衬 / 眼缝。

### 3.2 动作特技

* **抛刃**（attack）：`P.aim("weapon_R", DIR)` 定飞行方向 → `P.LOC["weapon_R"]=(0,d,0)` 沿骨轴飞出去 →
  绕当前骨轴自旋（飞盘式）→ 回到掌心。d 的曲线 0 → 1.52 → 0；命中帧 f18 = 40%。
* **施法**（cast）：`fx_cast` 骨从 1.0 放大到 45 倍（特效网格按 1/45 建，静止时只有一个 1.5 cm 的小点）。
* **走路**（v2 重做）：步幅 **0.38 m**（v1 0.208，读成小碎步），支撑相匀速后移不打滑，
  脚跟着地 +9° / 脚尖蹬离 −16°，髋部每步一次下沉，躯干反相扭转 ±6°。

## 4 魔金傀儡（Arcane Gold Golem）

**一句话**：4.30 m 的秘金**拼板傀儡** —— 梯形图腾面具、外露轴销关节、胸口熔炉口、两只方块巨拳。

| 项 | 实测（v2） |
|---|---|
| 三角面 | **25,424**（低模 8,968） |
| 包围盒 | 2.650 × 1.221 × **4.304** m |
| 脚底 | z = **0.000** |
| 骨 | **26**（人类骨架 + core / rune_chest / rune_R / rune_L 四根"只挂发光件"的骨） |
| 材质 | 金 / 金暗 / 铁 / team / team_trim / 辉（6） |
| 零件 | 200 个，4 模块：body / head / pauldron / runes |
| 动作 | idle(150f 纹路呼吸+打量) · walk(40f) · attack(40f 右拳) · attack_alt(40f 左拳) · dash(78f) · hurt(12f) · death(54f) |
| 穿模 | 跨模块 **0** / 同模块跨骨 **0** |

### 4.1 五条"傀儡特征"（v1 一条都没有）

1. **拼板构造**：所有体积件都能看出"这是几块板 + 几条缝"，缝里是铁色（每段 3~4 cm）。
   腿 = 大腿上板 / 大腿下板 / 膝 / 胫上板 / 胫下板 / 靴，六段独立。
2. **外露轴销**：肩、肘、膝、踝各一根横穿的圆柱 + 两端端盖。这是"机械构造"的硬证据，一条顶十条纹路。
3. **图腾面具**：平顶、平脸的切角方柱，一条横贯眼缝 + 一道**竖鼻脊**把眼缝劈成两段，
   两侧各三颗铆钉，顶上一块独立盖板 + 三颗冠钉。**不戴冠、不长角、没有表情**。
4. **方块拳**：拳体 + 4 根手指 ×2 节（正面竖排、块间 12 mm 缝）+ 指节横板 + 拇指 ×2 节 + 铁腕箍。
   判据是**正面能数出四根手指**。v1 是"rrect 放样球 + 4 个横向小凸点"= 带疙瘩的水球。
5. **熔炉口**：八角金唇边（最高）→ 铁炉膛（最低）→ 发光炉芯，上面压三道炉栅。
   v1 是发光圆贴片，读起来像钢铁侠的反应炉；**加了炉栅才是"炉"**。

### 4.2 材质与明度

* 抛光金 `metal 0.95 / rough 0.16` 太亮像电镀塑料，v2 降到 **0.82 / 0.37**；
* 明度阶梯只在一个色相里做：**铁 0.08（缝/内胆/轴销） < 金暗 0.20（次级板/四肢） < 金 0.42（头/胸/肩/拳）**；
* team 蓝只落"熔炉环 / 腰带窄带"，辉 青只落"眼缝 / 炉芯 / 纹路"；
* **金属必须给环境光才不会发黑**（`qc_unit.py` / `prev_unit.py` 用渐变天空）。

### 4.3 纹路

`core / rune_chest / rune_R / rune_L` 四根骨只挂发光件，缩放它们不会带动甲片。
脉冲 = `core` ±5%、`rune_*` 沿轴 +4%。glTF 不支持材质关键帧，所以用**骨缩放**模拟亮度变化。

## 5 动作（v2）

### 5.1 三条通用规矩

1. **逐帧写关键帧**（`_bake`）。双骨 IK 只保证"关键帧那一帧"手脚落在目标点；两帧之间插值四元数
   （尤其 Bezier 逐分量插值）会让踝关节飘出去 —— 脚交叉、穿地 5 cm 都是这么来的。
   代价是曲线大，可接受（`export_optimize_animation_size=False`）。
2. **`P.arm()` 只改 upperarm / forearm，不动 hand**。不补 `P.aim("hand_"+side, 方向)`，
   拳头会一直保持站立时"垂着"的朝向 —— 挥拳就变成"收着肘短打"，这是 v1 别扭的真正来源。
3. **符号**：`chest_pitch / hips_pitch / spine_pitch` **正值 = 后仰，负值 = 前倾**。
   v1 的 dash 写 `pitch=16` 想"向前冲"，实际是后仰 16°。绕 +Z 的 `chest_yaw` 正值 = 右肩朝前。

### 5.2 走路（两件都重做）

| | 步幅 | 抬脚 | 节奏 | 特点 |
|---|---|---|---|---|
| 破法者 | ±0.19（总跨 0.38 m） | 0.085 | 32f / 1.07 s | 支撑相匀速后移不打滑，脚跟着地 +9、蹬离 −16 |
| 魔金傀儡 | ±0.50（总跨 1.00 m） | 0.26 | 40f / 1.33 s | 接触帧 dz −0.105、侧移 ±0.055、落地后 2 帧再沉降 0.03 |

walk 的 `loop_d`：破法者 3.9e-18、傀儡 1.35e-17（首末帧逐骨矩阵差）。

### 5.3 挥拳（傀儡）

命中帧不用写死的世界点，按**当前姿态的肩关节**算：

```python
P.solve_T(); S = P.T["upperarm_" + side]
fist = S + DIR * (L_UPPER + L_FORE) * 0.985
P.arm(side, fist - DIR * WRIST_OFF, pole)   # pole 指向"肘部朝下后方"
P.aim("hand_" + side, DIR)
```

实测命中帧：**肘角 160°**（几乎伸直）、躯干前倾 **+10°**、腕从 y 0.57 打到 y 1.90（1.33 m 行程）。
v1 是把目标写在"肩前方 1.36 m"的死点上，躯干还在后仰，所以永远像够不着。

### 5.4 冲刺（傀儡，2.60 s）

* f0→f7 下沉起势；f13 **前摇：两手错开**（右拳护面门 y+0.66，左拳甩在体侧后方 y−0.34）；
* f20 蹬地：躯干**前倾 −17°**、脊柱 −6°、髋 −7°，前腿跨出、后腿撑直脚尖蹬地（pitch −22）；
* f20→f70 **保持冲刺姿势 1.7 s**，只给 ±1.2° 的发力颤动与纹路呼吸，**dy/dx 无净位移**（不真的冲出去）；
* f70→f78 收势，方便引擎混合回 idle。

### 5.5 `min_r` 陷阱

冲刺的护体姿势里，拳的世界目标点一转躯干就会**贴到肩膀上**（肩会往前挪 30~40 cm），
肘角掉到 4°，读成"两手糊在胸口"。`_fist(..., min_r=)` 给"拳心离肩的最小距离"，
肘角就永远留在能读出来的范围里。

## 8 这一轮踩到的坑（都写进代码注释了）

1. **`arc_band` 的 `perp` 会随 p0→p1 翻转**：腿甲从髋往踝放样时 `perp = +X`，
   所以左右腿的弧段要取镜像的 `(a0,a1)`，否则两片腿甲绕到内侧、在中轴对撞（YELLOW 12 处）。
2. **`arc_panel` 的 rx/ry 是半径，不是宽度**：`tube` 的 w/d 是直径，两者差一倍。
3. **`dome_patch` 的 theta 从 +X 起算**（不是 +Y）：要盖"正前方"得用 90±60。
4. **斜的肢体**：大腿/小腿是斜的（膝盖前探 7.7 cm），甲片必须逐高度偏移（`stations` 第 6 项 `cy`），
   否则腿肉会从甲片里钻出来。
5. **`helm_patch` 的角度不能超过正面折面的一半**：切角方盔的正面只有 ±34°，
   眼缝写 ±62° 就会绕到侧脸、变成两根"面罩天线"。
6. **`grid_shell` 的 `inside` 决定法线朝向**：给错点，整片会翻面、在渲染里变黑。
7. **倒角 + 细分仍然是禁忌**；倒角角度阈值 58°，否则弧形甲片内部每条边都倒角、面数翻三倍。
8. **踝高要按脚的 pitch 算**：`foot_clear(pitch)`。死亡跪姿里 L 脚 pitch 16°，
   脚跟会往下掉 8 mm、切进地面 —— 直接给 `U.Z_ANKLE + 0.05*q` 是不够的。
9. **导出后帧率**：glTF 存秒，QC 脚本必须先把 `scene.render.fps` 设成 30。
10. **中文路径**：`cv2.imread/imwrite` 直接失败，用 PIL 或 `imdecode`。

## 9 已知取舍

1. 精模两件不做手游三级 LOD，只给「细分 / 低模」两档（低模 = cage 关掉倒角与细分）。
2. 破法者的盾挂在 `forearm_L`（跟小臂走），左手做不了独立盾击；左手"攥"盾背把手
   是跨模块唯一那 1 处相交，物理上正确，不算缺陷。
3. 纹路发光是**几何缩放**模拟的亮度脉冲，不是材质动画。
4. 傀儡的腿占身高 47%（标准人形），但躯干宽 2.65 m，视觉上偏"矮壮" —— 刻意的重量感。
5. 破法者总高 1.798 m（v1 1.855）：盔压低 4 cm 换"脸在正面折面上"的可读性。

## 10 联盟骑士（Knight，2026-11-10）

**一句话**：2.82 m 高的**人马一体**重骑 —— 暗马 + 暖象牙甲 + 蓝面金线 + 一根 2.10 m 的骑枪。

> **本条的意义不在"又多一件"，在于"多个主体、一副骨架"这件事被解决了。**
> 之前的单位都是单人：一个 `root`，四肢从胯/肩长出去。骑兵有两个主体（马和骑手），
> 而且"阵亡"要求骑手离开马、摔到地上，马继续向前倒 —— 天真的做法是父子绑定（骑手挂马背），
> 那样马一倒骑手会被拖着走；另一条路是两个 GLB 拼，引擎那边要多一套逻辑。

### 10.1 骨架：两条链 + 一个"可脱离的锚"

```
root
├── horse_hips → horse_spine → horse_chest → horse_neck → horse_head
│      ├── horse_thigh_L/R → horse_shin_* → horse_hoofH_*          （后腿，飞节朝后）
│      ├── horse_chest → horse_upper_L/R → horse_fore_* → horse_hoofF_*  （前腿，膝朝前）
│      └── horse_tail_01 → horse_tail_02
└── rider_root → r_hips → r_spine → r_chest → r_head
                       ├── r_shoulder_* → r_upperarm_* → r_forearm_* → r_hand_* → weapon_*
                       └── r_thigh_* → r_shin_* → r_foot_*
```

`rider_root` 的父是 **`root`，不是 `horse_chest`**。它每帧被 `poselib2.Frame.place()`
放到"当前鞍点"：

```python
rel = rest[horse_chest]ᵀ · (SADDLE − T_rest[horse_chest])
T_seat = T[horse_chest] + R[horse_chest] @ rel          # 鞍点跟着马走
R_seat = R[horse_chest] · rest[horse_chest]ᵀ · rest[rider_root]
P.place("rider_root", T_seat, R_seat)                   # 写 LOC 到骨局部平移
```

`place()` 是这一轮给 `poselib2` 加的唯一一个 API：把一根骨**连位置带朝向**摆到世界点，
同时记 `TFIX`，后续再 `solve_T()` 不会掉回父链算出来的位置（子骨跟着走）。
于是"跟着马"和"摔到地上"是同一根骨的两种写法，切换点就是 `if f > 6: 用绝对世界点`。

**顺序很要紧**：`seat()` 必须在写骑手躯干**之前**调用 —— `place()` 会把整个骑手子树的朝向
重置成"跟着马"，之后 `rider_pose()` 加的 `chest_pitch/chest_yaw` 才是骑手自己的动作。

### 10.2 四条马腿

两段 IK + 蹄骨单独摆平（`hleg()`）。只有两条规矩：

| | pole | 为什么 |
|---|---|---|
| 前腿 | **+Y** | 马的腕关节（knee）向前凸，折起来时下段往后收 |
| 后腿 | **−Y** | 飞节（hock）向后凸，这是"马"和"狗"的分界线 |

蹄骨用 `set_world(hoof, R_pitch @ rest)` 单独摆平 —— 蹄底必须平行地面，不能跟着小腿转。
**踝高按几何算**：`HOOF_Z*cos(p) + 0.098*|sin(p)|`（0.098 是蹄底前后半长）。
写 `0.035*|sin|` 会少补 2/3，站姿一压就穿地 2 cm。

`stand_legs()` 收的是**世界坐标的绝对落点**（`FR/FL/HR/HL` 四元组），
所以躯干怎么沉、怎么转，蹄子都钉在地上 —— 这是马能"人立"的前提。

### 10.3 "人立"不能用位移

第一版 `dash` 的前摇写了 `dz=+0.09`（身体抬 9 cm），结果后蹄离地 9 cm、
IK 拉到极限也够不到地面，整匹马浮在空中。**人立靠的是 `hips_pitch`（绕胯转 26°）**，
后蹄的落点是世界坐标、不动；身体绕胯转，前半身自然抬起来。

### 10.4 造型：为什么是"暖象牙"不是"冷钢"

用户要求"骑士的铠甲武器语言和步兵看齐"。步兵是**暖象牙甲 + 蓝带 + 皮革棕**，
破法者是**冷钢 + 金线**。所以骑士的 `MATS` 走步兵那一支：

|---|---|---|

| `甲暗` | #A2937A m0.18 r0.50 | 面甲、护肩主片、臂甲 |

### 12.5 阵亡的"脱手"写法

`poselib2.drop_to(P, 骨, 目标世界点, 目标世界朝向, k)`：k=0 完全跟着手，k=1 完全落到目标，
中间做位置 lerp + 四元数 slerp。所以武器不会在"松手"那一帧跳一下。
目标朝向用 `_lay(rest_R, 目标轴向)` 从静止朝向旋出来（刀躺平指 −Y、盾面朝天）。

1. **盾要早脱手**：手还高（z≈0.4）时开始放，盾从"竖着"转到"平放"的过程中边缘才不会扫到地面。

2. **倒地方向要避开有甲的那侧肩膀**：战士右肩是三层铁甲，向右侧倒会把肩甲压进地面 0.19 m；

## 13 豺狼人斥候（Gnoll Scout，2026-11-11）

**一句话**：1.83 m 的棕灰皮刺客 —— **连帽披风从头罩到小腿**、兜帽下露出长吻大耳，

### 13.1 兜帽这件"难件"的解法

**问题**：兜帽要罩住颅骨，但豺狼人的耳朵从颅顶两侧伸出去 —— 布面与耳朵必然相交。

**解法（三步）**：
1. 兜帽拆**两件**：`cl_hood`（1.42→1.71 的环形围片，正面留脸） + `cl_crown`（1.70→1.83 的整圈帽顶）。
   一张网格里同时有"开口行"和"整圈行"会扭面，拆开就没这个问题。
2. 耳朵**从帽顶侧后方穿出**，交接处压一圈 `cl_earring` 皮革耳箍 —— 把"穿孔"讲成设计。
3. 兜帽三件和耳朵**同属 `head` 模块 + `head` 骨**，所以零件审计里它们是"同骨"，不算穿模；
   视觉上穿孔位置被耳箍盖住，96 px 下完全看不出。

### 13.2 披风：为什么是"椭球截面"

第一版披风是"绕身体 260° 的圆柱片"，结果**把两条手臂全包进去了**（审计 70 处 RED）。
原因：手臂在 x≈±0.34，而圆柱在肩高处半径只有 0.26 —— 布面从手臂中间穿过去。

v3 把截面改成**扁椭球并整体后移**（cy 从 −0.166 到 −0.046，rx 0.258→0.458、
ry 0.176→0.414），并且**前缘角从 80° 起**（萨满式的前包 52° 是在手臂前面）。
于是：上段在手臂之后，下段张开到 x=±0.46 从正面也能看见；背后留 **26° 尾巴开衩**，
尾巴从缝里出去（不做开衩会与尾巴相交 25 处）。

### 13.5 "匕首插胸口"的坐标写法

伤口点不能用世界点硬写（身体一倒就飘）。做法：**静止时**把世界点换算成胸骨的局部偏移，
之后每帧 `wound = T_chest + R_chest @ OFF`：

```python
OFF   = rest_chestT . (WOUND_W - rest_chest_head)
wound = T["chest"] + R["chest"] @ OFF
```

匕首的朝向也不能用"跟着胸转"了事：**刃尖朝胸内、柄留在体外 0.20 m** 才是"插着"。
`q = (rest_R @ Y).rotation_difference(-outward)`，`R = q @ rest_R`。
