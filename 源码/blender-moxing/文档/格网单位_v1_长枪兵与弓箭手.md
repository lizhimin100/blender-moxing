## 1 这一版改了什么（只改动作 + 动作需要的几何）

| 项 | v1 | v2 |
|---|---|---|
| 弓箭手 attack | 两只手都在胸前，弓没举起来；抽箭走 x≈0.16 的**胸腔内部**，`hand_R×chest 432` | 弓臂伸到 y=0.62、弓腹朝瞄准线；抽箭走**肩外侧高位**（x≥0.30，绕开胸、披风）；箭 = 腕点→弓握把的两点连线 |
| 弓箭手 walk | 关键帧插值给脚，步幅 ±0.16，重心 2 cm | `anims_lib.gait()` 解析式：步幅 ±0.25、抬膝 0.145、重心 4.8 cm、胸胯反转 5.5° |
| 弓箭手 death | `hipdrop .66 + hr −88` → 身体沉到地下 0.47 m，`lift_fix` 把**人**抬起来（悬空） | 改用 `hp`（髋俯仰）+ 明确髋高度，最后一帧髋 0.20；`lift_fix` 只按身体兜底 |
| 长枪兵 attack | `grip=-0.30` 是负值，`if grip>=0` 不成立 → 左掌**从来没上过杆** | 左掌给世界点，`hand_shaft` 从 0.857 降到 0.10~0.13（见 §4 的几何结论） |
| 长枪兵 walk | 同弓箭手 | 同弓箭手（枪另加 3° 摆 + 2 cm 纵向惯性） |
| 长枪兵 death | 同上（悬空 0.27 m） | 前扑：跪 → 压 → 面朝下贴地，枪先着地留在身侧 |
| 几何 | 箭横着建（轴和骨轴差 90°）、枪缨只写在 DIFF 里没建 | 箭沿骨轴（+Y）、弓握把对准骨原点、弓臂 46 级亚格放样、枪缨/缠绳握把/护臂补齐 |

## 3 新增的组件（`库/anims_lib.py`，两个兵种共用）

```
basis(y,x)              正交基：+Y = 长轴，+X = 给定方向
weapon_frame(P,side,..) 转 hand 让武器到指定朝向（拳头跟着武器走，不会在手里自转）
hold(P,side,palm,..)    握点驱动：掌心落点 + 武器定向 + align（武器轴对到掌心）
hand_at(P,side,palm,..) 副手：掌心到点、手骨定向
two_hand(...)           双手：主轴手给掌心，副手自动落到杆上 t2 处
arrow_at(P,tail,tip)    两点定一支箭（箭尾 + 箭尖）
gait(ph,stride,..)      行军步解析式（支撑脚匀速后移 —— 这是"不像散步"的唯一原因）
make_fn(...)            逐帧解析烘焙（循环动作首末强制同一帧）
```

工具：`库/pose_vox.py`（格网档专用动作体检 + 接触表出图）、`voxbase.body_min_z()`、
`voxbase.vert_bone()`、`voxbase._overlap()` 改成精确浮点 AABB。

## 4 三条硬经验（下一批别再踩）

1. **"手摆在哪"和"武器朝哪"必须分开写**。v1 用一个 `wd` 向量同时表达，于是
   "手到了、枪歪了"和"枪对了、手插进胸口"两件事只能靠试。现在的接口是：
   手 = IK 目标（可量够不够得着），武器 = 两根轴（可量和瞄准线的夹角）。
2. **长件一定会戳地**。死倒时弓/枪必有一头进地下，`lift_fix` 如果按"全模型最低点"
   兜底，抬起来的是**人** → "尸体悬在半空"。判定必须按**身体**（`body_min_z`，
   排武器/披风/箭筒），并且披风是 100% 单骨刚性壳，躯干一俯仰下摆就甩到 −0.37 m。
3. **步幅是被腿长卡死的**。腿 0.68、胯 0.90 ⇒ 跨 0.25 就必须沉 0.07（勾股定理，
   不是审美）。所以 `gait()` 里的 `dz` 是算出来的：`−0.044 − 0.024·cos(4πφ)`。
   不沉就够不着地，跨不大就永远是散步。

## 6 结构性限制（要改就得开基准 v2）

**① 双手不能握同一根"指前"的长杆。**
肩距 0.76、臂长 0.40 ⇒ 在 z=1.30 这一层，左掌最远到 x=−0.15、右掌最远到 x=+0.15
（再往下余量更小：z=1.05 时只有 ±0.15，z=0.95 时 ±0.19）。枪要指 +Y，两只手就得
一前一后落在同一条 +Y 线上；而两只手最近的横向间距是 0.30，等于杆必须从躯干中线
穿过（胸 x ±0.3 / z 1.0..1.3 是实心）—— 实测 `weapon_R×chest` 200~450 对，
肉眼就是"一根杆插在胸口上"。抬到 z=1.34 穿头，斜 40° 在 RTS 机位（218°）缩成一个点。
**结论：0.40 的臂长做不出"两手都掐在杆上 + 枪指前"。**
现在交付的是**枪贴右侧、单手送枪 + 副手同拍前推**（两手同向同节奏）。
彻底解决只有一条路：前臂 +1 格（0.20 → 0.30，臂长 0.40 → 0.50），需要开基准 v2
并重跑全部联盟兵种。

**② 上臂和胸是齐平的。**
基准的臂箱 x 0.30..0.50、胸 x ±0.30，两面共面 ⇒ 静止就有 60 对相交。任何内收 1 cm
的姿势都会把它推到 200+。要根治得把臂箱外移 1 格（肩宽 10 → 12 格），同样是基准 v2。
