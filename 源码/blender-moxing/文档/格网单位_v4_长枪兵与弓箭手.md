## 1 这一版改了什么（逐条对应用户反馈）

| 反馈 | 病根 | v4 怎么改 |
|---|---|---|
| **低模直接不成人样** | `Grid.lod()` 把格索引除以 2，却**没把格块放大**：中档 LOD 是"半尺寸小人 + 1.7 m 骨架 + 原尺寸的枪/弓/贴片"三套互不对应的坐标系，渲染出来是一堆漂浮板片 | 新增 `Part.step`：合并后每个格块**占 step 个半格**，总尺寸 / 骨架 / 贴片坐标全都不动。远档同格宽，省面靠丢薄贴片 |
| **长枪兵攻击"枪从身体穿过去再向斜右刺"** | `two_hand_points` 用两只手定枪轴。肩距 0.76 / 臂长 0.40 的体型下，两点连线**必然**偏离正前 40~60°，只能靠躯干反拧 40° 去补，看起来就是枪先横穿身体再斜着扎出去 | 改**单手直刺**：右手单手持枪、枪轴直接压到正前方（`say=0.9995`），掌心前送 0.34 m + 枪在手里前滑 0.50 m，左臂后甩平衡 |
| **弓箭手除攻击外弓都拿反了** | `CARRY` 的 `aim`（= 弓背朝向）给成了 `(0.55, −0.80)` —— 弓背朝右后、弦朝左前（朝外）。idle / walk / hurt 三个动作全走这个常量，所以三个都反 | `aim` 改成 `(−0.92, 0.38)`：弓背朝左前、弦朝身体内侧，弓面几乎正对 3/4 机位。攻击的 `AIM` 本来就是对的（弓背朝前、弦朝射手） |
| **攻击的弓弦也要拉开** | 弦是一根直的 loft（刚性壳），`hook` 只转手腕，弦本身**不会动** —— 看上去就是"手在拉空气" | 弦拆成上下两段，各挂一根辅骨 `bow_up` / `bow_dn`（head 在弓梢、+Y 指向弦中点）。每帧把骨转向"弓梢 → 拉弦手"，再沿骨轴缩放到实际长度，弦自然成 V 形；撒放时 `pull` 掉回 0.16 做回弹 |
| （连带）举枪 / 举弓过顶时枪从脸前穿过 | cast 的后手放在身体中线 (x = −0.02)，枪轴从右腰斜穿到脸上 | cast 两只手都留在身体右侧（x = 0.38），枪竖着举过头顶 |

## 4 四条硬经验

1. **LOD 是"格块变大"，不是"模型变小"。** 降采样的语义是"2×2×2 个格并成 1 个**双倍大**的格"，
   不是"把模型缩到一半"。v3 的 `x // 2` 只做了坐标减半，格块尺寸还是 1 个半格 ——
   于是中档 LOD 是 0.85 m 高的小人 + 1.7 m 的骨架 + 全尺寸的枪和贴片。
   远档也别把格块放到 3：手臂的 3 格块胖到 0.6 m 宽，正好把身侧的弓吞掉。

2. **`Frame.solve_T()` 必须认 `P.LOC`。** 以前 LOC 只交给 Writer 写关键帧，
   Frame 自己的 `T` 不含它 —— 对"叶子骨"（枪、弓本身）没影响，但**挂在武器骨下面的零件**
   （弓弦）会整体少一个 `HAND_R = 0.10 m`。`hold()` 的返回值也因此改成直接用 `P.T[bone]`，
   不要再自己加一遍 `R @ off`。

3. **刚性壳不能拉弦。** 弦要能变形只有三条路：拆段 + 骨缩放（本版）、双骨权重混合、
   morph target。选第一条是因为它不破坏"刚性蒙皮 1.0"、不需要引擎侧支持，
   而且滑杆类道具（弩弦、投石索、旗绳）都能照抄。

4. **手短就是手短（v3 的结论，这版更硬）。** 想"双手握杆 + 枪指正前"只有加长前臂一条路；
   在现有体型下，正确做法是**放弃双手**，用单手 + 枪在手里滑给行程。

5. **zfight 的 1.2 mm 容差会被"差一点点"的设计意图撞上。** 胸甲背带的金扣原先只比背带
   往外 **1 mm**（2.09 对 2.07），于是被判定共面 —— 两个兵种各 2 对。
   贴片之间要留 **3 mm**，不是"看起来压在上面"就行。本轮把金扣改到 2.12，三档归零。

## 5 已知偏差（登记，不改判据）

| 资产 | 项 | 实测 | 说明 |
|---|---|---|---|
| 两者 | 手 / 武器 vs 躯干 | `hand_L×chest` 11~265 对 | 手臂 0.40、胸厚 0.4：手放在身前的姿势**必然**含进胸里，拳心在胸面之外，肉眼看是"手贴在甲上" |
| 弓箭手 | 拉弦手 / 箭 vs 头 | `hand_R×head` 78、`weapon_R×head` 24 | 手贴下颌、箭从下巴下方过；体素手宽 0.2 m，贴脸就是相交 |
| 弓箭手 | 弓弦骨缩放 | 1.63 / 1.70 | **规范 §5.3 已登记为例外**：弦是道具形变，不是关节拉伸 |
| 弓箭手 | 死倒时弓 vs 身体 | `weapon_L×chest` 288 对 | 弓是 100 % 单骨刚性壳，仰躺时压在身侧；地面不透明，只看得见轮廓 |
| 弓箭手 | 披风 vs 地面 | −0.38 | 同 v3：披风单骨刚性，仰躺时钻到身下 |
| 长枪兵 | 举枪时枪 vs 肩套筒 | `weapon_R×chest` 306 对 | 枪轴在 x=0.38，肩套筒伸到 0.40 —— "枪靠在肩窝"是想要的效果，不是错位 |
| 两者 | LOD 远档 | 腿并成一根柱子 | 2×2×2 合并把 4 mm 的裤缝吃掉，20 m 外无所谓 |

## 6 重建

```bash
# 造型 / 自检 / 三档 LOD / glb
blender -b --factory-startup --python 库/run_vox.py -- 联盟/长枪兵 unit_长枪兵
blender -b --factory-startup --python 库/run_vox.py -- 联盟/弓箭手 unit_弓箭手
# 动作体检（六动作 + 逐帧探针 + 接触表）
blender -b --factory-startup --python 库/pose_vox.py -- 联盟/长枪兵 unit_长枪兵 --step 2
# 低模三档（0=全量 1=中 2=远）
blender -b --factory-startup --python 库/_dbg_lod.py -- 联盟/长枪兵 unit_长枪兵 docs/_tmp/lod 0,1,2
# 图标
blender -b --factory-startup --python 库/icon_vox.py -- 联盟/长枪兵 unit_长枪兵 docs/_tmp/icon/sp.png icon 0
python 库/icon_post_vox.py docs/_tmp/icon/sp.png assets/单位/联盟/长枪兵/长枪兵_图标.png
```

调试脚本（本轮新增，可留可删）：`库/_dbg_lod.py`（三档 LOD 出图）、
`库/_dbg_pose.py`（动作定格，按视角命名）、`库/_dbg_str.py`（打印弦骨 / 弦顶点的世界坐标）。
