## 一、步兵：举盾为什么要烤十二条

引擎动画状态只有 `idle / walk / attack / hurt / death` 五个槽；glTF 不支持分层动画。
"举着盾能同时移动、攻击、待机、受击、阵亡"只有两条路：

1. 引擎侧做 additive 层（要改引擎，且每件武器都要配一套）；
2. **在资产侧把组合烤成独立 action**。

选 2。于是：

```
guard_raise → [guard_idle | guard_walk | guard_attack | guard_hurt] → guard_lower
                              └→ guard_death
```

十二条共用同一张表：

```python
GSHIELD = (-0.150, 0.316, 1.084)      # 盾心世界位置
GN      = (-0.235, 0.950, 0.200)      # 盾面法线（朝前、略偏左、上仰 11°）
GBODY   = dict(dz=-0.056, hips_yaw=-10, chest_yaw=-8, chest_pitch=-6, head_pitch=3 …)
```

**改举盾只改这三处，十二条一起变** —— 这是"盾在状态间不跳"的唯一保证。

帧长：idle 108 / walk 26 / attack 22 / hurt 9 / death 32（与旧版同长，引擎的节奏假设不用改）；
guard_raise 14 / guard_idle 108 / guard_walk 26 / guard_attack 24 / guard_hurt 9 /
guard_death 40 / guard_lower 14。

### 1.1 盾和手是"焊死"的（这件的核心）

旧骨架的 `shield` 骨挂在 **`chest`** 下 —— 不是挂在 `hand_L` 下。后果：
摆手盾不跟、摆盾手不跟。旧版待机之所以看着"手扶着盾"，只是静止姿态恰好重叠；
一走起来手甩出去、盾还留在胯上。

不做"两根骨各写一遍"（那必然漂），改成**由盾反推手**：

```
盾的目标位姿 (C, N, U)
   → 盾网格朝向 M = (N×U, N, U)
   → 腕点 wrist = C + M · OFF_WRIST_L        （OFF 在静止姿态下量一次）
   → 手掌朝向 R_hand = M · M0ᵀ · restR_hand
   → P.arm("L", wrist, pole) + P.set_world("hand_L", …) + P.place("shield", T, …)
```

盾是"主动"的、手是"从动"的 —— 物理上就是人抓着盾。`unit_步兵.py` 里：
`shield_target() / weld_shield() / OFF_WRIST_L / M0`。

`M0` 是盾网格在静止姿态下的朝向，用**点云主轴**量出来的（PCA）：

```
e1 = (0.043, 0.135, 0.990)   σ=0.175   → 盾面竖轴
e2 = (0.491, 0.860,-0.139)   σ=0.156   → 盾面横轴
e3 = (0.870,-0.492, 0.030)   σ=0.048   → 法线（取 −e3，指向体外）
```

> 别假设"盾面就是 +Y"：这块盾在静止姿态下法线离 +Y 有 60°，按 +Y 算会把盾摆歪 60°。

### 1.2 举盾姿态的六个判据

1. 盾顶边到**下巴**（`C.z = 1.084` + 半高 0.27 → 顶边 1.35），不许盖住脸 —— 96 px 下脸是识别点；
2. 盾面法线上仰 11°，俯角 40° 看过去才有"一面"而不是"一条线"；
3. 左肩朝前（`hips_yaw / chest_yaw` 取负）、膝盖弯（`dz -0.056`）、重心压在后脚；
4. 剑举在盾后的右肩侧（`rp=-34`，刃尖朝前上），**不抢盾的剪影**；
5. 呼吸 = 盾 8 mm 上下 + 2° 滚转，不是全身一起晃；
6. 盾击 = 盾先回收 4 cm 再前顶 13 cm（有蓄力才不僵硬），盾击命中 f8、剑刺 f15。

## 二、豺狼人斥候：把"叉腰"拆掉

**病根不是"手放太高"，是握点位置错了**：旧 idle 的握点在 `(±0.352, 0.176, 0.986)`
—— x 比肩（±0.272）还外 8 cm、z 在腰线，`P.arm` 解出来的肘只能往两侧张开 →
读成"两手叉腰"。

新语法（三条动作共用）：

| 项 | 前手（右） | 后手（左） |
|---|---|---|
| 握点 | `(0.185, 0.330, 0.905)` 身体中线前方 | `(-0.250, -0.075, 0.870)` 胯侧稍后 |
| 刀身 | `pitch -70`（反手、朝前下） | `pitch -18`（垂在胯后） |
| pole | `(0.42, 0.30, -0.86)` 肘朝下后 | `(-0.42, 0.10, -0.90)` 肘朝下 |
| 基准 | `dz -0.155 / hips_pitch -5 / chest_pitch -12 / head_pitch +13` | 同左 |

判据：**肘的世界 x 不许超出肩关节 x 的 ±0.05**。walk 只给 ±3 cm 反相摆动，
attack 的两个刺仍然从低姿出（右刺握点沿 +Y 走 0.30 m、肩不抬；左撩 `pitch +118` 反手向上）。

## 三、这一轮踩到的坑（都写进代码注释了）

1. **`poselib2.drop_to` 用一个 k 同时插值位置和朝向** —— 武器还举在手上（z≈0.5）、
   朝向已经转到"平躺"时，刃尖会在半空扫过地面，实测扎进地里 **0.26 m**。
   → 新增 `anims_human.drop_layered(P, 骨, T, R, kp, kr)`：**姿态先行、位置后落**。

2. **"躺平"必须给完整目标矩阵**，不能只把骨轴拧平。
   剑的骨轴 = 刃的方向，但**护手垂直于刃**：只拧骨轴，护手会竖着切进地里 15 cm。
   剑要连"刀面朝上"一起给（`unit_步兵.sword_floor_rot()`）；盾要连"法线朝上"一起给
   （`unit_步兵.lay_shield()`，用 `Matrix(((-1,0,0),(0,0,1),(0,1,0)))`）。

3. **倒地别把 `hips_pitch` 和 `hips_roll` 叠着用** —— 第一版 `pitch -62 + roll -74`
   把人揉成一团方块堆。正确写法：**只用一个 `hips_pitch` 让躯干绕胯向后转 0→89°**，
   `dz` 同步沉到 -(胯高-0.16)，脚用 IK 钉在地面（配合 `foot_clear`），腿自然被拉直。
   读起来就是"直挺挺倒下"。

4. **关键帧参数忘了给 = 静默回默认值**。剑脱手只在前两个关键帧写了 `wrot=1.0`，
   后面的帧回到默认 `0` → 位置落到了地上、**朝向又滑回静止**，剑竖着插在地上。
   逐帧 zmin 工具（`docs/_tmp/_zmin_group.py`，会打印最低点属于哪根骨）一眼看出来。

5. **`_ref` 必须先拷一份**。`run_步兵.py` 从 `库/_ref/联盟/方块人_联盟步兵.glb` 读，
   覆盖写 `assets/…`；直接读写同一个文件，脚本挂在中途就没有原稿了。

6. **glb 里那个 Icosphere 不是模型的**：导入后场景里会出现一个 42 顶点的球（z −1..1），
   原资产与导出文件里都没有它，是导入器的产物。所有体检脚本要按名字排除，
   否则 `zmin` 永远是 −1.0。
