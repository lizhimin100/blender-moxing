# Ironbound Legion · 硬边建筑包 v6（Godot 4.7）

九座西幻 / 魔兽争霸三风格的建筑，**硬边几何**：长方体为主，允许楔形 / 棱柱 / 锥台 /
任意角度斜撑，全部平面围合、100% flat shading，零曲面零圆角。
屋面是**薄壳 + 密椽 + 分层瓦**（檐口总厚 0.18 m），每座带 `build / destroy / static`
三条动画、顶点 AO、TC1/TC2 阵营染色。

> 本包只含建筑，不含角色。

## 本轮：箭塔 v1（第九座 · `hip_spire` 攒尖角亭 + 垛口平台 + 弩炮）

`assets/箭塔/` · 图标 `assets/图标/箭塔_图标.png` · 报告 `docs/箭塔/v1/报告.md`

**箭塔是哨塔的升级型，但它是新的模型**：`assets/哨塔` / `wt_model.py` 一个字节没改。
两座的读法故意相反 —— 哨塔"往上叠"（石基 → 两段木塔身 → 两道挑台 → 双坡棚 → 外挂木梯），
箭塔"往上收"（石基 → 收分下段 → **木上层** → 挑出的木战棚 → 垛口平台 → 弩炮 + 角亭）。

- **垛口环**：每面 6 个木垛口（0.56 × 0.34 × 0.50，缝 0.16），**压顶是队色** ——
  水平面染色，俯视角最有效；正/侧视读作"一圈有缺口的墙"，不是一排栅栏。
- **弩炮**：中柱 + 通长弩床 + 近横向弩臂 + 上弦的弩矢 + 绞盘。俯视就是一个 "T" ——
  这是第三次改法（前两版用"侧颊 + 横梁 + 立式扭簧"拼，RTS 尺度上是一堆交叉木条）。
- **挑出的木战棚**：平台 5.40 比塔身 3.68 宽 0.86，底下 12 根斜撑 + 12 个投石暗口，
  撑出的一圈阴影就是"防守位"。
- **望楼角亭**：1.38 见方 + 九座唯一的**四坡攒尖顶**（出檐 0.26，脊尖 15.30）+ 旗。
- **箭塔的细节只做在结构线上**：正面十字箭孔、塔身三层竖箭孔、垛口、箭捆架、
  栏板内侧的箭袋、平台火盆、石弹 / 绳圈 / 弩矢箱。
- 数字：**401 构件；低模 9,470 tri / 687 KB；细分 21,882 tri / 1.60 MB**；
  手游 **9,470 / 4,972 / 3,112**（4 材质）；**CLIP_CROSS 0 / COPLANAR_UP 0 / FLOAT 0**；
  阵营色 **正视 6.52% / 3-4 视 6.09% / 俯视 7.49%**；尺寸 **7.44 × 7.14 × 18.32**。
- 代码 `at_model.py`；体检 `at_align.py`；染色 `at_teamshare.py`；出图 `at_shots.py`；

## 1. 本轮的资产结构（重要）

每座建筑 = **1 个蒙皮网格 + 1 个材质 + 1 个 primitive**，主渲染 1 次 draw call，含阴影 2 次。

```
Armature
├─ stage_00 … stage_12      阶段骨：build 只动这一层
│   └─ chunk_XX_YYY …        碎片骨：destroy 只动这一层
└─ dust_00 … dust_12        扬尘骨：destroy 里 scale 0.001→2.2→0.001
```

- 为什么用蒙皮：工单同时要求“chunk 独立运动”和“draw call ≤2”。普通节点必须一块一 mesh，
  draw call 会等于块数；把全部碎片合进一个蒙皮网格才能两者兼得。
- 节点预算：110–139 / 座（≤140）。
- 块数：87–112 / 座（60–120）。
- **build 与 destroy 不共享通道**：build 动阶段骨，destroy 动 chunk 骨，切换动画不会互相污染。
- `static` 会把所有阶段/碎片骨复位（否则从 destroy 切回 static 会停在废墟姿态）。

### 贴图与 UV

- **UV1 (`TEXCOORD_0`)**：世界空间平铺坐标，保留用于回退/自定义着色。
- **UV2 (`TEXCOORD_1`)**：共享 2048 图集坐标。四个图集：
  `atlas_warband_BC.png` / `_N.png` / `_ORM.png`（RGBA）/ `_E.png`。
- 图集是 **4×4 格、每格 512（504 美术区 + 4 px 边缘复制）**；15 套材质共用，六座 GLB 不重复打包。
- **顶点色 `COLOR_0`**：烘焙 AO + 每盒 ±3% 亮度 / ±2.7% 冷暖扰动。着色器里 `ALBEDO *= COLOR.rgb`。
- ORM 通道：`R = AO`、`G = Roughness`、`B = Metallic`、`A = TC1 主色遮罩`；`E` 是 TC2 描边/自发光。

## 2. 接进 Godot（5 步）

1. 拷贝整个 `assets/_历史版本/万邦_v5/`，保持目录结构：
   `res://assets/_历史版本/万邦_v5/buildings/*.glb` + `res://assets/_历史版本/万邦_v5/textures/*.png`。
   贴图是**相对外链**（`../textures/atlas_warband_BC.png`），少一层目录就丢图。
2. 选中 `.glb` → 导入面板：
   | 项 | 值 | 原因 |
   |---|---|---|
   | Ensure Tangents | ✅ | 否则法线贴图失效 |
   | Generate LODs | 关 | 自动 LOD 会把方块削成斜面 |
   | Animation | ✅ | 三条 clip 在同一个 AnimationPlayer |
   | FPS | 30 | 与导出采样一致 |
3. 打开导入场景，另存为 `PackedScene`，实例化。
4. 根节点挂 `WarbandBuilding.gd`。
5. `set_team(Team.BLUE)` / `build()` / `destroy()`。

### 相机/深度

- 建议 `near 0.1 / far 500`（工单值）。
- 预览台用 `near 0.3 / far 200`；近远比从 4000 降到 667，深度精度提升约 6 倍。
- 共面同向面已在几何阶段剔除/拉开 2.5 mm，不依赖 near/far 掩盖。

### 动画

- `build` 4.80 s、`destroy` 3.80 s、`static` 1.00 s，全部 `LOOP_NONE`。
- glTF 的 translation 是绝对值：`build` 的每个阶段骨都带 `{node: pivot}` 作为 rest；
  `build_buildings.py` 里已处理，手改动画时不要丢。
- `destroy` 的 chunk 骨**没有任何 scale 通道**（硬验收项）；只有 dust / 瓦砾有 scale。
- 末帧废墟高度 3.50 m。
