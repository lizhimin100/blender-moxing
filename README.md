# 方块人 RTS · 单位资产包

面向 RTS 的单位交付资产：**联盟三件**（步兵 / 弩兵 / 农民）、**豺狼人战士 / 斥候**，以及两件野怪武器配件。
全部为 glTF 2.0 二进制（`.glb`），**贴图已内嵌**，不依赖任何外部图片或 `.bin` 文件。

## 贴图内嵌校验

七个 GLB 均逐个解析过 JSON / BIN 块，结论一致：

- `images[].uri` 全部为 `null`，图像数据放在 `bufferViews` 中，位于 GLB 自带的 BIN 块内；
- `buffers[].uri` 全部为 `null`，没有外部缓冲文件；
- PNG 文件头与尺寸校验通过；
- 每个 primitive 都绑定了材质，主体材质均引用内嵌贴图。

校验日期：2026-11-01。可直接拷贝单个 `.glb` 使用。

## 材质与改色

- 联盟：`主体`（贴图）+ `team` / `team_trim`（纯色因子）；
- 野怪：`主体`（贴图）+ `M_eye` / `M_tribe`（纯色因子）。

队伍色只改 `team` / `team_trim` 的 baseColorFactor，不动贴图与 UV；野怪染色键为 `tribe`。
