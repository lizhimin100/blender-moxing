# 地形地块 · 干裂泥地

8 × 8 m 的**可平铺**地块：一整片干裂的泥土，缝是几何做出来的（不是画上去的），
板面上再叠一层更细的裂纹贴图。低模 + 硬边，道具（石 / 碎石 / 枯草）在一角成组。

## 交付物

| 文件 | 内容 |
|---|---|
| `裂纹泥地.glb` | 主版本：9,420 tri / 7 个物体 / 487 KB（地表 6 mm 倒角，道具细分一级） |
| `裂纹泥地_低模.glb` | 低模：3,224 tri / 342 KB（一点不倒角，远景或移动端用） |
| `blender/_源文件/地形/裂纹泥地.blend` | 源文件（材质、道具、贴图都打包在里面） |

贴图在 GLB 里内嵌，来源 `assets/地形/裂纹泥地.png`（512²，无缝）。

## 规格

| 项 | 值 |
|---|---|
| 占地 | 8.03 × 8.02 m，原点在中心，板顶平均高度 ≈ z 0 |
| 高度 | 板顶 −17…+17 mm，缝底 −26 mm，底座底 −130 mm（总高 0.54 m，含草） |
| 板 | 81 个周期 Voronoi 胞元 → 106 块板（跨边界的胞元会被切成多块） |
| 缝宽 | 12 mm（板内缩 6 mm ×2） |
| 材质 | 7 个：`td_plate_a/b/c`（同图三档明度）、`td_crack`（缝壁+缝底）、`earth_dark`（底座）、`td_rock`、`td_dry_grass` |
| 平铺 | 周期 Voronoi，2×2 拼合无缝（`docs/地形/地块/地块_平铺.png`） |

## 用法

- **当底材铺**：8 m 一块，对应 `裂纹泥地.png` 的一张图。直接拼，接缝不会露。
- **当摆件**：整块拖进场景，8 m 见方，建筑压在上面正好（板顶 ≈ z0，不会陷）。
- 只想用干净的地面时，把 `TD-td_rock` / `TD-td_dry_grass` 两个物体隐藏即可 ——
  道具是独立物体，没有和地表合并。
- 远景换 `裂纹泥地_低模.glb`，材质完全一样，切版本不用重传贴图。

## 制作

```bash
blender.exe -b --factory-startup --python blender/bs_v6/td_model.py     # 只是库
blender.exe -b --factory-startup --python blender/bs_v6/td_shots.py     # 出四张图
blender.exe -b --factory-startup --python blender/bs_v6/td_export.py    # 导出 GLB / blend
```

改密度：`td_model.py` 顶部的 `GRID`（格数，9 → 板宽 ≈ 0.89 m）、`INSET`（缝宽）、
`TOP_LO/TOP_HI`（板顶起伏）。改色：`DIRT_FINE`（贴图）+ `m_crack` / `td_rock` 等色值。
