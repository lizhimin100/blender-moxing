# 地形生成工具箱 · 使用说明书

给 Godot 4 3D RTS 生成「双材质硬边过渡」地形图集。进引擎的是**一张遮罩图集 + 两张各自平铺的底材**，
交界全程二选一，不做 alpha 混合。

纯 Python（numpy / opencv / pillow），**不需要 Blender**，一次 8 秒。

---

## 0 · 两条命令

```bash
python 地形生成工具箱/terrain_gen.py      # 出图集 + 高度 + 法线 + shader + LUT
python 地形生成工具箱/terrain_check.py    # 跑 a–f 六项验收，写 report.md
```

环境：`python -m pip install numpy opencv-python-headless pillow`

所有参数在 **`参数配置.json`**，脚本里没有一处写死的数值。

---

## 1 · 新底材（岩石 / 雪地）放哪

放到 **`assets/地形/`**（跟 `草地.png` / `泥土.png` 同级）。规格：

| 项 | 要求 |
|---|---|
| 尺寸 | 512² 起，**必须是 `格像素`（256）的整数倍** —— 要「逐字节等于原图」只能点采样 |
| 格式 | 8bit RGB，无 alpha，sRGB，**必须无缝**（1 tile = 8 m） |
| 数量 | A、B 各一张。三种材质要另开一次，不混在一张图里 |

然后改 `参数配置.json`：

```json
"输入": { "底材": { "A": "草地.png", "B": "雪地.png" } },
"输出": { "名称": "草雪", "目录": "assets/地形/材质/草雪",
          "文档目录": "docs/地形/材质_草雪" }
```

`A` = 遮罩 0 的那一侧，`B` = 遮罩 255 的那一侧。`名称` 会拼进所有文件名（`atlas_草雪_rgba.png` …）。

## 2 · 怎么跑

**前提**：上面那张表，加一个装好依赖的 Python。

**方式一，两条命令**（见 §0）。

**方式二，跟 AI 说一句**：

> 用 `地形生成工具箱` 跑一套双材质图集：A=草地.png，B=雪地.png，名称 草雪，
> 输出到 `assets/地形/材质/草雪`，跑完把 report.md 的 a–f 结果贴给我。

**产出**（落在 `输出.目录`）：

```
atlas_<名称>_rgba.png   2048×1024 RGBA8  R=遮罩 G=有符号距离 B=宽度抖动场 A=255
atlas_<名称>_h16.png    2048×1024 16bit  高度 −12…+8 mm
atlas_<名称>_n.png      2048×1024 RGB8   法线（OpenGL）
atlas_<名称>_rgb.png    2048×1024 RGB8   派生彩色图（只看，不进引擎）
noise_256.png           256² RGB8     抖点噪声（repeat 采样）
preview_3x3.png         1536×1920     过渡块 3×3 平铺 + 单格 2× 近景 + 16 个变体
cell_00…15.png          256² ×16      Texture2DArray 路线备用
godot/terrain_blend.gdshader          可直接拖进 Godot
godot/cell_lut.txt                    16 行 LUT
```

外加 `输出.文档目录/生成记录.json`（本次跑的全部参数 + LUT，校验器读它）和 `report.md`。

## 3 · 想调「边缘粗糙度」改哪个

**`参数配置.json` → `边缘`**，三个数，主旋钮是第一个：

| 参数 | 作用 | 现在 | 往哪调 |
|---|---|---|---|
| **`noise_gain`** | 交界的大尺度起伏幅度 | **0.5** | ↑ 1.6 = 很毛、角点关系看不出来；↓ 0.3 以下接近几何圆弧 |
| `dither_amp` | 交界那 1–2 px 碎点的碎度 | 0.08 | ↑ 0.20 ≈ 3.4 px；1.0 = 溶解 |
| `band` | g 的过渡带宽 | 0.16（1.28 m） | ↑ 交界更钝 |

> ⚠️ **`noise_gain` 和 `dither_amp` 是耦合的**：降 gain 会让 |∇s| 变小，同样的 dither 会把碎点带推宽。
> 只降 gain 会得到「边界干净但碎点变毛」；只降 amp 会得到「边界干净但拐角还是一团斑」。两个一起动。

其它常用：`碎块.目标个数`（沿交界撒的土块密度）、`高度.台面_mm`（两种材质的高低差）、
`噪声.seed`（换一张随机起伏，尺寸/形状不变）。

命令行可以临时覆盖、不写回 JSON：`-- gain=0.9`、`-- amp=0.15`、`-- seed=1`。

## 4 · 接进 Godot

### 4.1 三张图

| 文件 | Compress | sRGB | 说明 |
|---|---|---|---|
| `atlas_<名称>_rgba.png` | Lossless | **关** | R/G/B 都是数据，不是颜色 |
| `草地.png` / `雪地.png` | VRAM 或 Lossless | 开 | |
| `mat_map`（你自己出） | Lossless | **关** | 单通道数据 |

### 4.2 mat_map 要什么格式

| 项 | 值 |
|---|---|
| 格式 | R8（单通道），`filter_nearest`，`repeat_enable` |
| 尺寸 | **(N+1) × (M+1)** |
| 语义 | 1 texel = **1 个格点** = 8 m。texel(i,j) = 世界 (i·8, j·8) 那个**顶点**是不是 B 材质（>0.5） |

就是魔兽争霸 3 那种：**材质存在共享的顶点上，格子渲染时读它四个角**。
一格的四角 = `(i,j) (i+1,j) (i+1,j+1) (i,j+1)`，顺序是 左上→右上→右下→左下。

> 注意是「格点」不是「格子」。如果你手上是「每 8 m 一格一个 id」的旧数据，别硬转：
> 取多数会让孤立格子整片消失，取最大会让 B 区外扩半格。把生成侧改成 (N+1)×(M+1) 的格点图。

### 4.3 接线

1. 把 `godot/terrain_blend.gdshader` 拖进项目，新建 `ShaderMaterial` 挂到地形上。
2. Inspector 里四个槽：`mat_map`、`atlas_rgba`、`tex_grass`、`tex_dirt` 各指一张。
   （`atlas_n` 是可选的图集法线，默认不启用。）
3. `tile_m` 保持 8.0，跟底材的平铺距离一致。
4. 完事。LUT 已经写死在 shader 里，不用你填。

**LUT 是个常量**：它只跟 4×4 德布鲁因环的落位有关，跟底材无关 —— 换岩石雪地**不用改 shader**。

### 4.4 扩展图集（治「大面积极度重复」）

图集分左右两块，各 4×4 格：

```
 ┌──────────────┬──────────────┐
 │ 左 4×4        │ 右 4×4        │
 │ 16 个过渡格    │ 16 个纯纹理变体 │
 │ （四角组合）   │ A × 8 / B × 8 │
 └──────────────┴──────────────┘
```

四角全同（`idx = 0` 或 `15`）时**不走 LUT**，去右边按格号哈希挑一个变体：

```glsl
int v = int(tile_hash(ij) % 8);
ivec2 cell = ivec2(4 + v % 4, (idx == 15 ? 2 : 0) + v / 4);
```

- A 材质占右块第 0–1 行、B 材质占第 2–3 行，每行 4 个 —— 8 个变体正好 8 格。
- 哈希是整数异或链，同一个格号永远得到同一个变体，不会随镜头闪。
- `variant_random = false` 可以关掉，用来 A/B 对比复读感（`docs/地形/材质_草泥/对照_纯色复读_*.png`）。

**变体怎么来的**：底材点采样后做 4 种旋转 × 2 种镜像 + ±1 LSB 噪点，共 8 种。

> ⚠️ **不要靠「调亮度」做变体**。实测哪怕 ±0.5% 的亮度差，在 16 px/m 的中景也会变成
> 一张 8 m 的补丁棋盘 —— 比复读还难看。`参数配置.json → 变体.亮度/对比度` 默认全 1.0（关），
> 真要开先看 `docs/地形/材质_草泥/对照_变体方案.png`。

### 4.5 四个一定要知道的坑

1. **梯度要作用在 `g`（连续坐标）上，不能作用在 `fract(g)` 上。** 否则跨格边那一像素得到假梯度，
   mip 跳到最粗一级，格边出现 1 px 灰线。
2. **`max_lod` 必须夹住（≈5）。** 不夹的话远处一 texel 跨过整格，图集里 16 个格子被平均成灰。
3. **因此用 `textureLod` 而不是 `textureGrad`** —— 效果等价，但后者没法把 LOD 往下夹。
4. **纯色格要把采样中心夹在格内半个 texel**（`uv = clamp(uv, cu+ht, cu+CELL_UV-ht)`）。
   不夹的话，纯 A 格左边挨着过渡格，mip 一混就是一条 25 cm 的暗边 —— 等于每 8 m 画一道网格。

## 5 · 目录

```
地形生成工具箱/
├─ terrain_gen.py                生成器（配置驱动）
├─ terrain_check.py              验收器（只读交付 PNG，不 import 生成器）
├─ 参数配置.json                 唯一参数源
├─ 使用说明书.md                 本文件
└─ 模板文件/
   ├─ terrain_blend.gdshader     shader 模板（含 __CELL_LUT__ 占位）
   └─ cell_lut_样例.txt          当前这套的 LUT（参考；实际由生成器重写）
```

改了 shader 就改 `模板文件/terrain_blend.gdshader`，**不要**改输出目录里那份 —— 它每次生成都会被覆盖。

## 6 · 边界

- 只处理 **2 种**材质。三材质跑两遍，不混在一张图里。
- 32 px/m ⇒ 底材被 2:1 点采样（为了逐字节保色）。0.5 m 的细裂纹会有一半像素断续；
  要 1:1 就把 `尺寸.格像素` 提到 512（图集变 2048²，显存 ×4）。
- 16 格里 `idx=05 / 10` 是对角格，格心是双线性场的**鞍点**，交界那团斑由噪声定，压不掉。
- `idx=00` 是纯 A、`idx=15` 是纯 B —— 大面同材质的区域就靠这两格，不需要过渡格去填内部。
