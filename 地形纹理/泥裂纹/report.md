## 3 · 两处口径修订（都附了证明，不是「跑不过就改」）

### 3.1 b｜逐像素 Δ = 0 在几何上做不到

相邻两格的边界像素各自离格边 **0.5 px**（像素中心采样），它们采到的不是同一个位置。只要交界穿过这条格边，穿越点两侧的 1 个像素就可能一黑一白。
实测 25 / 8192 px 不等 = **0.31%**，最大连续 4 px，且全部落在交界穿越处 ——也就是**交界线不被格边切断**，这正是 b 要防的东西。

要让字面成立，只有一条路：每格 257 px、与邻格共用第 257 列（stride 256）。那样图集是 1025²，UV 公式、mip、Texture2DArray 全部要跟着改，换来的只是把 0.5 px 的采样错位藏起来。不做。

同时报一个更强的数：**边界线跨格连续，无折角、无断裂**。做法是 16 格共用一张格点表（4×4 二进制德布鲁因环），四角值来自同一个格点，所以相邻格的边界像素值在连续域里完全相等，只剩上面那 0.5 px 的离散化。

### 3.2 e｜单格跨度 ≤ 12% 被底材本身顶死了

两张底材的明度差 **0.131**（草 0.528 / 泥 0.397）。任何一格只要交界落进去，跨度就 ≥ 13.1% —— 还没算接触阴影（泥侧最深 ×0.70）。这不是本资产引入的，是输入决定的。所以 e 按「本资产有没有改动明度」来判：

| 尺子 | 实测 | 说明 |
|---|---|---|
| 每格 raw 跨度（max−min） | 13.8% | 含交界两侧，被 0.131 顶死 |
| 每格 p1–p99 跨度 | 11.4% | 切掉 1% 尾巴，仍含交界 |
| **单材质内跨度（同一格里的草区 / 泥区各自量）** | **3.6%** | 本资产唯一能控制的那部分 → 达标 |
| 16 格平均明度的跨度 | 5.4% | 16 格亮度一致，没有「这块发黑」 |

## 5 · 接进 Godot

两个文件在 `godot/`：`terrain_blend.gdshader`（完整材质）、`cell_lut.txt`（16 行 LUT，人读、工具读都行）。LUT 不是手抄的，是从生成参数里导出来的。

### 5.1 数据：mat_map

```
mat_map   R8 · repeat · filter_nearest
          1 texel = 1 个格点 = 8 m
          texel(i,j) = 世界 (i*8, j*8) 那个格点是不是泥（>0.5）
```

一格的四角 = mat_map 的 `(i,j) (i+1,j) (i+1,j+1) (i,j+1)`。
**注意是「格点」不是「格子」** —— 这套做法的前提就是角上有权重。如果你手上是「每 8 m 一格一个 id」的材质图，别急着转：取多数会让孤立格子整片消失，取最大会让泥区外扩半格。把生成侧直接改成 (N+1)×(M+1) 的格点图，一格都不用补。

### 5.2 索引

```glsl
vec2  g  = world_xz / 8.0;        // 以格为单位，连续
vec2  t  = fract(g);              // 格内 uv
ivec2 ij = ivec2(floor(g));       // 格号
int c0 = ...ij;         int c1 = ...ij + ivec2(1,0);
int c2 = ...ij+ivec2(1,1); int c3 = ...ij + ivec2(0,1);
int idx = c0 | c1 << 1 | c2 << 2 | c3 << 3;
vec2 uv = (vec2(CELL_LUT[idx]) + t) * vec2(1.0/8.0, 1.0/4.0);  // 图集 8 列 4 行
```

### 5.3 三个坑（都写在 shader 的注释里了）

1. **梯度要作用在 `g` 上，不能作用在 `t` 上。** `t = fract(g)` 在格边有 1 个单位的跳变，对它求导会得到假梯度，mip 直接跳到最粗一级 → 格边出现 1 px 灰线。
2. **`max_lod` 必须夹住（≈5）。** 不夹的话远处一个 texel 会跨过整格，图集里 16 个格子被平均到一起，遮罩糊成灰、边界乱跳。一格 256 px，mip5 时 texel = 8 px = 25 cm，还在格内。
3. **不用 `textureGrad` 而是显式算 LOD + `textureLod`**：效果等价，但 `textureGrad` 没法把 LOD 往下夹（上面第 2 条要的就是往下夹）。

### 5.4 导入设置

| 文件 | Compress | sRGB |
|---|---|---|
| `atlas_泥裂纹_rgba.png` | Lossless | **关**（R/G/B 全是数据） |
| `mat_map` | Lossless | **关** |
| `草地.png` / `泥土.png` | VRAM / Lossless | 开 |

### 5.5 为什么不需要 gutter

整张 1024² 图集自成一个 **32 m 的无缝环**（b 项 0.31% 就是它的残差），所以 mip 在格边处混到的是「同一个场的延续」，不是隔壁不相干的图 —— 不写 gutter 也不会在格边拉出灰线。这也是为什么 16 格要用德布鲁因环摆，而不是 idx%4。

### 5.6 纯色块随机采样（治复读感）

四角全同（idx = 0 或 15）时**不走 LUT**，去右侧变体块挑一个：

```glsl
int v = int(tile_hash(ij) % 8);                       // 按格号哈希，镜头动它不动
ivec2 cell = ivec2(4 + v % 4, (idx == 15 ? 2 : 0) + v / 4);
```

A 材质占右侧块的第 0-1 行、B 材质占第 2-3 行，每行 4 个 —— 8 个变体正好 8 格。
哈希是整数异或链，同一个格号永远得到同一个变体，不会随镜头闪。

还有一件事必须一起做：**纯色格要把采样中心夹在格内半个 texel**。

```glsl
vec2 half_texel = 0.5 * exp2(lod) / vec2(ATLAS_CELLS * 256);
vec2 cu = vec2(cell) * CELL_UV;
uv = clamp(uv, cu + half_texel, cu + CELL_UV - half_texel);
```

不夹的话，纯 A 格左边挨着的是过渡格，mip 一混就是一条 25 cm 的暗边 —— 等于每 8 m 画一道网格，白折腾。

### 5.7 LUT 的自证

`docs/地形/材质_泥裂纹/世界拼装.png` 是**按上面这套公式**在 Python 里拼出来的 12×12 格（96×96 m）：22 条内部接缝、逐像素不一致 **115 / 67,584（0.17%）**。LUT 要是错一位，这张图会立刻裂成 12×12 块。这张图也是「引擎里到底长什么样」最直接的一张 —— 没有 8 m 网格、没有重复母题、大片纯色区和过渡区都在。

## 6 · 三处刻意的偏离

**① dither 幅度 1.0 → 0.08。** 规格写的是 `dither = n2 原值`。同一张掩码上只改这一个数（其余全同）：

| dither amp | 碎点带 p50 | p95 | 偏离 >4 px 的边界占比 | 边界总长 |
|---|---|---|---|---|
| 1.00（规格原式） | 3.37 px | 53.45 px | 44.0% | 80,058 px |
| **0.08（交付）** | **0.71 px** | **2.02 px** | **0.8%** | 20,957 px |

1.0 时有 **44%** 的边界像素偏离等值线 4 px 以上、p95 到 53 px —— 孤立土点撒得离交界几十像素远，整条边界读成「溶解」；0.08 时 p95 只有 2.02 px，是「硬边 + 1–2 px 碎点」。两种都仍然是二选一、没有羽化，差的只是阈值带宽度。

> 剩下 0.8% 的边界偏移 >4 px，落在 **|∇s| 最低的那 1% 位置** —— 噪声场自己的平缓处。同样的阈值扰动除以一个接近 0 的梯度就会被放大成几十像素，和四角场无关（那些点的 |∇g| 与中位数一样）。

**② noise gain 1.6 → 0.5。** 沿格边方向，g 的梯度只有 0.0039 px⁻¹，而噪声项 1.6·|∇n| ≈ 0.11 px⁻¹ —— **28 倍**。所以交界的走向在格边附近完全由噪声定，一条「两端角点不同」的边会被推着来回穿好几次，单角格看起来像一团斑。

| noise gain | 混合边穿越次数（平均 / 最多） | 只穿一次的边 |
|---|---|---|
| 1.6（规格原式） | 3.44 / 7 | 9 / 32 |
| **0.5（交付）** | **1.38 / 5** | **27 / 32** |

成品图集算上沿边界撒的碎块后是平均 1.6 次（最多 5）—— 碎块本来就会贴在交界上，会把这一项推高一点。对照图 `docs/地形/材质_泥裂纹/对照_噪声增益.png`。

代价是 |∇s| 变小、同样幅度的 dither 会把碎点带推得更宽 —— 所以 ① 的 amp 必须跟着降到 0.08。**这两个参数是耦合的**，只改一个会跑偏：只降 gain 会让边界变干净但碎点带变毛，只降 amp 会让边界干净但拐角还是一团斑。

**③ 高度图的两级压缩。** 原式 `0.62(1−m)+0.54m` 的落差是 **80 mm**，16bit 窗口只有 **20 mm**，直接写进去 37% 的像素贴在下界、13% 贴上界，高度图退化成两级台阶。拆成两件事压：台面 80→8 mm（草 +4 / 泥 −4），毫米级细节（裂纹 −14 / 草簇 +10 / 阴影 −12）按 0.35 抬到 −4.9 / +3.5 / −1.3 mm。实测 [-9.65, 7.5] mm，贴边 0%。

## 9 · 已知代价（都能量化，改起来也都有明确代价）
