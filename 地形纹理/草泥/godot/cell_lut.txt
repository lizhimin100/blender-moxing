# cell_lut.txt —— idx → 图集格子位置
#
# idx = c0 | c1<<1 | c2<<2 | c3<<3
#   c0 = 左上   c1 = 右上   c2 = 右下   c3 = 左下   （1 = 泥，0 = 草）
# 图集 4×4 格，一格 256² = 8 m。col/row 从 0 起，row 从上往下（图片坐标）。
#
# 这张表是 4×4 二进制德布鲁因环的落位（16 个组合一个不少），不是 idx%4。
# 用 idx%4 摆会拼出 16 条笔直台阶 —— 原因见 terrain_blend.gdshader 头注释。
#
# idx  col  row   c0c1c2c3   泥面积
   0    3    2    0000     0.0%   纯草
   1    3    1    1000    15.7%   
   2    0    2    0100    15.4%   
   3    2    1    1100    50.1%

   6    0    1    0110    50.2%   
   7    0    0    1110    84.7%   
   8    2    2    0001    15.4%   
   9    2    3    1001    50.2%   
  10    3    0    0101    50.5%   
  11    1    1    1101    84.8%   
  12    0    3    0011    49.8%   
  13    2    0    1011    84.6%   
  14    1    3    0111    85.0%   
  15    1    0    1111   100.0%   纯泥
#
