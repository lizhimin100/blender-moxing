## 2. 三个实施决定（都有代价，写在这里备查）

### 2.1 门洞是真挖的，不是贴片

前墙拆成三块：左块、右块、门洞上方的拱形块。三块的轮廓都按"五边形减拱洞"算，
斜边严格落在屋面斜线上（`z = RIDGE − SLOPE·|x|`），拼起来无缝、也不与屋面打架。

```
左块  (-4.60,0) → (-1.10,0) → (-1.10, zroof(1.10)) → (0, RIDGE) → (-4.60, EAVE)
右块  镜像
上块  (±1.10, 3.95) → (±1.10, zroof(1.10)) → (0, RIDGE) → 沿拱弧回到起点
```

**踩到的坑**：上块的顶点顺序一开始写成了顺时针，法线朝内，渲染出来是"屋脊往下垂的一个黑三角"。
这种错误只能用射线反查定位（`ray_cast` 从相机打到 (0, 3.2, 9.0)，命中 `mass_front_T`），肉眼看只会以为"那是阴影"。

### 2.2 门厅抬到 0.60，石台在门洞处断开

参考图的建筑坐在高台上。做法：
- 石台在 x ∈ [-1.72, 1.72] 断开，让三级台阶进来；
- 门厅地板补一块 0.60 高的石台（2.34 × 0.96），门洞地面与石台同高；
- 台阶三级：0.34 / 0.47 / 0.60（每级踏面 0.32）。

不这么做的话，要么门洞被石台堵死，要么整座建筑没有台基。

### 2.3 训练棚是开放棚，只留 1.2 m 矮墙

第一版给棚做了 3.2 m 的实心后墙，从正面看就是一个"方盒子"（用户视角里完全读不出"棚"）。
改成：后墙只做 1.2 m 高（上面开一个小方窗透光），四根柱子撑单坡顶，棚下放兵器架 ——
现在从正面能看到"柱 → 暗 → 兵器"三层。

## 3. 体检（`blender/bs_v6/br_align.py`）

口径与铁匠铺 v9 完全一致：**CLIP**（BVH 面相交）/ **CONTAIN**（包围盒整个埋入）/ **COPLANAR**（同向面距 <4 mm）/ **FLOAT**（悬空）。

```
ITEMS 464    CLIP_CROSS 388    CONTAIN 83    COPLANAR 191    FLOAT 0
```

**388 条 cross 全部是结构性叠压**，逐条核对过：

| 类别 | 对数 | 说明 |
|---|---|---|
| 石台 / 地坪 ↔ 落地道具 | ~120 | 桶、箱、假人、围栏桩埋入 0.1–0.2 |
| 墙身 ↔ 窗框 / 拱券石 | ~90 | 窗与拱券必须嵌墙 |
| 墙身 ↔ 半木构 | ~60 | 立柱 / 横梁嵌墙 0.05–0.10 |
| 老虎窗 ↔ 屋面板 | ~20 | 窗座埋入坡面 0.30 |
| 棚柱 ↔ 基座 / 矮墙 | ~40 | 柱脚埋入 |
| 纹章 / 金边 ↔ 盾面 | ~50 | 贴附装饰 |

**COPLANAR 191** 里 90% 是 z = 0 的朝下底面（基座 / 墙体 / 立柱底面互相重合），不可见；
其余是"前墙与后段墙在 y=2.50 的内部接缝"，也被外墙挡住。

**FLOAT 0**：柴堆的六根原木一开始全部悬空（间距 0.30 > 直径 0.26），改成叠压 0.01 后贴实。

## 7. v2 改形制（按第二轮反馈）

> 反馈：屋款要和铁匠铺不一样；主体用**平顶带垛口**；中央门不是重点；
> 训练场要用栏杆半包、不能小；草靶/武器架/桶箱/盔甲架要更多更精致；阵营色要更多更大。

### 7.1 形制：双坡 → 平顶垛口

v1 的"对称双坡 + 左右前突"确实和铁匠铺同属"坡屋顶"家族，剪影区分度不够。v2 整座重做：

| | v1 | v2 |
|---|---|---|
| 屋顶 | 双坡 42° + 老虎窗 | **平顶 + 四面女儿墙 + 垛口** |
| 天际线 | 山墙尖 | **锯齿垛口 + 前右角楼 + 两根旗杆** |
| 体量 | 9.2 × 7.2 | **12 × 9**（更方正，要塞感） |
| 门 | 拱门 + 三级台阶 + 长矛束 + 雨棚 | 拱门 + 一级门槛 + 门套壁柱（简化） |
| 楼梯 | — | 屋顶楼梯间（外挂楼梯做了一版，从 3/4 看会从屋顶后翘出一块，删了） |

### 7.2 训练场：19.2 × 11.6，10 类道具

场地面积比 v1 大 68%。道具从 7 个增加到 19 个个体、10 个类别：三具草靶假人、
两座武器架（含四矛两剑）、一座盔甲架（胸甲/肩甲/头盔/腿甲/**阵营色披风**）、
两个圆靶（阵营色同心环）、两处长矛堆、一处盾堆、两个草垛、两根练剑木桩、桶箱沙袋。

围栏改成**板式**（竖板 + 两道横梁 + 立柱 + 四棱锥帽），因为参考图的围栏是实心木板墙，
不是"桩 + 杆"。前面留 3.6 m 开口 + 两根门柱。

### 7.3 阵营色：6.55% → 13.75%

v1 靠"两面垂旗 + 两个盾"凑，用户说"不能只靠旗帜"。v2 换成**大块面 + 少数量**：

| 手段 | 面积（正视投影） |
|---|---|
| 女儿墙下整圈饰带（高 0.44，通长） | ~4.6 m² |
| 前墙两幅大横幅（2.30×2.70 / 1.50×2.60） | ~10.1 m² |
| 侧墙两幅 + 后墙一幅横幅 | （侧墙不计入正视） |
| 门套壁柱 ×2 | ~2.2 m² |
| 盾 ×5（门楣/角楼/侧墙/屋顶） | ~3.6 m² |

结果：**正视 13.75%、3/4 6.01%**，比 v1 翻倍。

### 7.4 这一轮踩的两个坑（都是"轴"的问题）

1. **`cyl()` 默认轴是 Y**。练剑木桩写 `cyl("pell", …, 1.80)`，结果是一根 1.8 m 长、
   **横躺在地面上 0.9 m 高处**的圆木（体检里 FLOAT 报出来的）。要竖直得传 `axis="Z"`。
2. **`lathe()` 的 rings 是 (r, h, cx, cy)，h 从 0 起**。屋顶的桶传了 `z0=H2`，
   但只用在"桶箍"上，桶身仍从 z=0 造 —— 于是屋顶的桶在地基里，和 `plinth_a` 相交 24 对。

**结论**：所有"带高度偏移"的封装函数（barrel / crate / 旋转体），都要把 z0 传进几何本身，
不能只传给配件。这两处都是"看着对、体检才发现"的类型。

## 8. v3 重定尺（第三轮反馈）

> 反馈：① 垛口要做成"2 个或 4 个一组"的拼接；② 和铁匠铺比，兵营占地太大；
> ③ 训练场和建筑像分开了，没有有机组合。

### 8.1 垛口：从"密排锯齿"改成"组"

v2 的 `merlon_row` 是等距排（0.95 垛 + 0.80 缝，每 1.75 m 一个），全楼一个节奏，
读起来就是一圈碎齿。v3 改成成组：

| | v2 | v3 |
|---|---|---|
| 组型 | 无（等距） | **只有 2 个 / 4 个两种组型** |
| 垛宽 / 组内缝 / 组间缺口 | 0.95 / 0.80（等距） | **0.72 / 0.12 / 1.70** |
| 压顶 | 每个垛一段 | **每组一条通长压顶** |
| 前墙 / 侧墙 / 后墙 / 角楼 | 7 / 5 / 6 / 3 个单垛 | **2×2 / 2×2 / 2×4 / 1×2** |

两组之间 1.70 m 的缺口是"探身 / 架弩的位置"，组内 0.12 m 的缝被通长压顶盖住，
所以 4 个垛读成"一整段垛墙"，而不是 4 个独立的齿。

**踩的坑**：`n = int((length + gap) // (unit + gap))` 在整除时会因为浮点误差少算一组
（6.70 / 4.30 算成 1 而不是 2），侧墙一度只剩中间一组。加 `1e-6` 修掉。

### 8.2 体量：19.2 × 14.5 → 11.16 × 14.97

| | v2 | v3 | 铁匠铺 v9 |
|---|---|---|---|
| 主体 | 12.0 × 9.0 | **10.0 × 7.6** | — |
| 含场地包围盒 | 19.20 × 14.48 | **11.16 × 14.97** | 10.03 × 11.80 |
| 建筑本体高 | 12.60 | **10.30** | 11.05 |

宽向与铁匠铺持平（11.16 vs 10.03，多的是围栏板），深向多 3.2 m —— 那正好是训练场的进深。
平面面积 167 m² vs 铁匠铺 118 m²（**1.41 倍**，v2 是 2.4 倍）。

### 8.3 训练场与主体咬合（这一版改得最多的地方）

v2 的问题：场地从 y = 7.00 起，而主墙在 4.50 —— 中间 2.5 m 什么都不长，
围栏四面自成一圈，建筑和场地是两个物体摆在一起。

v3 的六条改动：

1. **围栏长在基座上**：左右围栏的起点在 `x = ±5.30`（基座外沿）、`y = 4.14`，
   立柱埋进石台 0.14。建筑前墙就是场地的第四面，成了真正的"半包"。
2. **同标高**：场地顶面从 0.22 抬到 **0.40**，基座 0.48，只差一级踏步。
3. **门前石广场**：6.2 × 2.24，从门槛铺出来，把门 → 场地 → 围栏开口串成一条轴线。
4. **场地铺装分格**：横 4 道 + 纵 2 道石缝，破掉"一整块灰板"。
5. **墙根一列道具**：门左 4 支立矛、门右 3 面立盾、左墙根盔甲架 + 木箱、
   右墙根武器架 + 长矛堆 —— 道具与墙接触，读成"建筑带出来的院子"。
6. **围栏挂旗**：门柱两面、靠建筑的立柱两面，把场地"染"成建筑的延伸。

### 8.4 体检归零

| | v2 | v3 |
|---|---|---|
| CLIP_CROSS（跨系统真相交） | 538 | **0** |
| FLOAT（悬空） | 0 | **0** |
| CONTAIN（整体埋入） | 33 | 31（全是围栏/门/基座内部） |

要把 CROSS 打到 0，先得把"角色件穿建筑"这类真错位找出来挪开：
- 武器架 `wrack_a/b` 原本在角楼体量里（角楼占掉场地右上角 x 2.55–5.00 / y 3.80–5.80）
- 草垛、桶、木箱挤在盾墙和角楼之间
- 假人站台盘（新加的 0.92 m 圆盘）压进基座
- 围栏端头与门柱、场地铺装与角楼基座

剩下的白名单只有物理上必须叠压的（围栏板钉进柱、门扇在框里、基座包墙脚、木构嵌墙）。

### 8.6 面数策略的一次修正

v2 的两个版本（10,640 / 24,824）之所以差 2.3 倍，是因为 `add()` 的 `sub` 默认是 0，
而 `finalize` 直接把 `sub` 传给 `L.finalize` —— 实际上**两版都没做曲面细分**，
差别只在倒角段数和平滑着色。v3 把这件事写清楚：

- 低模：倒角 1 段，**< 8 mm 的装饰件不倒角**（游戏里看不出来），全平面着色
- 圆角版：倒角 2 段 + auto-smooth，**不做 Catmull-Clark**

不做 CC 的理由：637 个构件各叠一层 CC 会到 30 万面（实测 301,208 tri），
和"资产不重"冲突。铁匠铺 v6 的 CC 版是 148k，从 v8 起就改成同一策略。

### 8.7 这一轮踩的三个坑

1. **`bslib.cyl(axis="Z")` 直接返回 None**（只实现了 X/Y）。`add(None)` 混进 items 后
   在 `finalize` 崩在 `ob.modifiers`。竖直圆柱改用本地 `vcyl()`（四边侧面 + n-gon 端盖，
   比 `revolve` 的三角扇省一半面）。
2. **压顶的 `abs(d[0]) / abs(d[1])` 写反**：cap 变成一条 3.3 m 长的板，从女儿墙里朝外伸出，
   在正视图里读成"屋顶上悬着一块板"。四类体检都查不出来（它不与任何东西相交），
   只有出图能看见。
3. **门正上方的木构**：两根 `post`（x ±0.42）竖穿门楣盾，一对人字撑横穿盾的下半 ——
   近景里盾被切成两截。门楣位置必须留空给纹章。

- `cz` 在函数签名与注释里明确成"底边"；
- 平台旗：`sz = 0.50`，`cz = 旗顶 − 0.60`（该区间旗面净高 0.665–0.708）；
- 角楼旗：`sz = 0.40`，`cz = 旗顶 − 0.50`（净高 0.52）。

**验证**：写了点-多边形测试，把两处徽记的每个顶点投到旗面 2D 轮廓里点数 ——
越界顶点 **0**，四边余量 2.6–10.9 cm。

### 12.6 这一轮的两条教训

1. **参数语义必须在函数名/注释里钉死**。"cz 是中心还是底边"这种歧义，尺寸算得再准也会错，
   而且错法是"整体上移半个高度"，看起来像"尺寸没调好"，实际是坐标系问题。
2. **同一个 bug 会在不同函数里重复**：v3.1 修过 `win2` 的"实心窗框挡住玻璃"，
   v3.4 又发现 `tw_win_frame` 是同一个写法。**凡是有"框"的地方都要检查是不是四条边。**
