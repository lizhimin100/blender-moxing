> 接手对象：Blender 作业 Agent（bpy 脚本 + 手工精修）。

## 1. 方向

### 1.1 三句话

1. **一栋建筑只讲一件事。** 远看是剪影，近看是构造。中间尺度（3–30 cm 的装饰）一律砍掉。
2. **屋顶是薄壳 + 密椽，不是厚板。** 所有屋面边缘的可见厚度必须 ≤ 0.22 m（茅草 ≤ 0.48 m）。
3. **大体量整，小构件碎，中间不啰嗦。** 允许一栋楼有 12 个大面，也允许有 400 个 5 cm 的椽头；不允许有 40 个 20 cm 的无意义凸起。

### 1.2 硬边（本工单的第一原则）

风格是**硬邦邦**：一切转折都是明确的平面交汇，没有一处软过渡。

- 通篇 **flat shading**。除倒角用 weighted normal，不允许任何平滑着色。
- 允许斜面、楔形、锥台、旋转的斜撑 —— 只要是**平面围合**。
- 禁止曲面、细分、圆角（>3 mm）、布料模拟、毛发、任何"柔和"的东西。
- 材质靠**明度块面对比**建立体积，不靠渐变。

一句话判定：**把模型旋转 360°，任何一个角度都应该是"切"出来的，不是"长"出来的。**

### 1.3 职责优先

每座建筑必须有一个**职责构件**，它在正视角剪影中占 **≥12%** 面积：

| 建筑 | 职责构件 | 现状问题 |
|---|---|---|
| 铁匠铺 | **炉罩 + 炉口橙光** | 炉口被雨棚遮住，烟囱喧宾夺主 |
| 伐木场 | **立式锯框** | 锯片藏在台面下，正面完全看不见 |
| 兵营 | 垛口天际线 | 基本可用 |
| 农场 | 筒仓 | 可用 |
| 哨塔 | 外扩方冠 | 可用 |
| 城镇大厅 | 门廊 + 钟楼 | 可用 |

## 2. 几何语言（替换 v3 的"只有轴对齐长方体"）

### 2.1 允许

- 长方体（主力，占比 ≥ 70%）
- **楔形 / 棱柱 / 锥台**：屋面、坡道、烟囱收分、塔顶
- **任意角度的斜撑**：木构的斜撑、支撑、拉杆，绕单轴旋转
- **阶梯近似圆弧**：8 / 12 / 24 边（筒仓、水轮、锯片、桶）
- **倒角**：细部 1.5–3 mm，大体量转角 15–40 mm，段数 ≤ 2

### 2.2 禁止

- 曲面、NURBS、Subdivision Surface
- 圆角 > 3 mm（会立刻变成"网游感"）
- 平滑着色、软阴影过渡、渐变材质
- 布料、绳索的物理模拟（绳用直的方条）
- 有机形态：藤蔓、树根、不规则岩石

### 2.3 面数预算

| 项 | 上限 |
|---|---|
| 三角面 / 座 | 150,000 |
| 节点 / 座 | 140（含 armature 与骨骼） |
| 材质 / 座 | 1（图集），最多 2 |
| draw call | 2（含阴影） |

超预算时的处理顺序：先砍中间尺度装饰 → 再降阶梯边数 → 最后才砍大构件。
**不许靠合并网格来"压"面数**，那会毁掉 chunk 动画。

## 3. 通用构造标准（六座共用，必须逐条落地）

这一节是"细看观感"的全部来源。屋顶厚薄、椽头露不露、石缝深浅，都写死在这里。

### 3.1 坡屋顶（城镇大厅 / 农场 / 铁匠铺 / 伐木场 / 披屋）

**分层，从下往上：**

| 层 | 尺寸 | 说明 |
|---|---|---|
| 椽 rafters | 0.10 × 0.14，间距 **0.55**，沿坡向 | 檐口出挑 **0.35**，椽头端面可见 |
| 望板 boarding | 0.03 厚 | 贴在椽上，不外露 |
| 瓦 shingles | 每皮高 **0.22**、露明 **0.16**、厚 **0.05** | 每皮向外挑 **0.03**，缝错开，每 3 皮错一次 |
| 脊 ridge | 脊木 0.16 × 0.20 + 脊瓦 0.24 宽 | 脊瓦高出两侧瓦面 0.04 |
| 封檐板 fascia | 0.12 × 0.22 | 沿檐口通长，与椽头平齐 |

**总厚度（檐口处）≈ 0.10 + 0.03 + 0.05 = 0.18 m。这是硬指标。**

**必须解决的"透空"问题**：瓦是薄壳，下面是空的。禁止用"实心楔形"填满 ——
在屋面内侧、内缩 **0.10 m** 处做一个**封闭的阁楼体块**（材质 plaster 或 wood_dark，
不参与外观），把空腔挡住。这样从外面永远看不穿，但屋檐边缘仍是 0.18 m 的锐利薄边。

**山墙**：木板封边（barge board）0.12 厚，沿坡度通长，两端出头 0.10。

### 3.2 茅草屋顶（农场谷仓）

茅草**本来就厚**，问题不在厚度，在没有形。

- 总厚 **0.42**，分 **3 层叠压**：每层向外挑 0.08、向下压 0.06
- 檐口出挑 **0.55**，切口**切成斜面**（45°），露出一层层草茎断面
- 脊部 **3 级阶梯收头** + 一道压脊木（0.18 × 0.16），用交叉木钉住
- 山墙端用木板压边，草不封山墙

### 3.3 墙体

- 石墙：每皮高 0.30，错缝，转角用**交错角石**（quoins，每块 0.45 × 0.30 × 0.36，交替长短）
- 勒脚（plinth）：外放 **0.06**，高 0.35，材质 stone_dark
- 半木（half-timber）：立柱 0.14 × 0.14，间距 0.9–1.1；斜撑 45°，截面 0.12 × 0.12，
  **必须真的顶到柱子和梁**，不许浮空
- 灰泥面内凹 **0.02**（相对木构），让木构有投影

### 3.4 木构连接（"木头没粘在一起"的根治）

所有木构件必须满足三条之一，否则判不合格：

1. 端面**顶到**另一构件表面（间隙 ≤ 2 mm）
2. 与另一构件**穿插** ≥ 30 mm
3. 通过一个**连接件**（榫头、铁箍、螺栓块）过渡

禁止：两根木头之间有明显空隙、横档浮在柱子外侧、梁端悬在半空。

### 3.5 铁件

- 铁箍：截面 0.10 × 0.06，包住构件一圈，四角闭合
- 门铰：0.08 宽 × 0.02 厚，铰页做成**阶梯 2 级**
- 铆钉：φ0.03，**只在近景构件上放**（门、铁箱），墙面不放

### 3.6 阵营色（不变）

- 只在结构线：檐口、腰线、垛口压顶、柱箍、栏板、门楣、箍带、旗、垂幅
- 可见占比 **6–9%**，低 / 中 / 高三档都要有
- 徽记：单色平涂几何剪影，尺寸 = 旗宽 0.45，位于旗面**上 1/3**

## 4. 逐座设计

### 4.1 铁匠铺 —— 重做（当前 13.98 m → **11.0 m**）

**问题诊断**：烟囱 13.6 m，比屋脊高 5.6 m，和建筑等高 —— 这是工厂烟囱，不是铁匠铺。
炉口被布篷挡死，真正的职责构件没露出来。工作区散落，没有"火—砧—水"的动作线。

**新形体**：

| 部件 | 尺寸 |
|---|---|
| 主体 | 7.6 × 5.4，檐口 5.6，单坡脊 7.4（落差 1.8） |
| 炉膛凸出体量 | 宽 3.2 × 深 2.4 × 高 4.6，从正立面**凸出 1.6** |
| 炉口 | 1.60 宽 × 1.15 高，内凹 **0.60**，下沿抬 0.35（炭台） |
| 炉罩 | 从 3.2 收分到 1.4，高 1.8，**4 级阶梯** |
| 烟囱 | 1.40 × 1.40 收分到 1.15，顶 **11.0**（高出脊 3.6） |
| 烟帽 | 四面出挑 0.18 + 两块叠板 |

**布局（从正面看）**：炉膛偏左，烟囱在炉罩正上方偏左；**正门偏右**，门宽 1.2，两级石阶。
雨棚改**木瓦小雨棚**（不是布），出挑 2.0，两根 0.14 方柱，柱脚落在石墩上。
雨棚高度必须高于炉口 0.8 m，**不许挡住炉口**。

**工作区（动作线：火 → 砧 → 水）**：

- 铁砧 ×2：墩座 0.5³ + 腰 0.34³ + 砧面 0.62 × 0.20 × 0.28，前端做**锥形角**（三棱台）
- 淬火桶：12 边形 φ0.62 × 0.72，两道铁箍，水面用 `window` 材质
- 磨石：φ0.9 立轮 + 木架 + 脚踏
- 煤堆：两级方堆，靠炉膛侧墙
- 工具墙：两道横档 + 5 件工具（锤 / 钳 / 锉 / 凿 / 铁条），挂在炉膛外侧面

**识别顺序**：炉口橙光（唯一自发光点）→ 炉罩收分 → 烟囱 → 铁砧。

**禁止**：任何坡屋顶、任何高于 11.2 m 的构件、布篷。

### 4.2 伐木场 —— 重做（当前 8.54 m → **8.2 m**）

**问题诊断**：锯片 φ1.2 藏在台面下，正面看不见；龙门吊抢了剪影；原木堆在棚后。
整座在说三件事，结果一件没说清。

**新形体**：

| 部件 | 尺寸 |
|---|---|
| 敞棚 | 7.2 跨 × 6.0 进深，6 柱，檐 5.2，脊 6.6 |
| **立式锯框** | 2.80 高 × 2.20 宽，置于敞棚**正中偏前**，正面完全开敞 |
| 锯条 | 1.90 长 × 0.10 宽 × 0.06 厚，**齿**：每 0.12 一个 0.06 深的方齿，交替左右偏移 |
| 锯框 | 上下夹木 0.16 × 0.18 + 两侧立柱 0.14 × 0.16 + 两根拉杆 |
| 原木（在锯上） | φ0.46 × 3.4，卡在滑车上，**端面朝外**，3 圈年轮 |
| 滑车 | 2.4 × 0.9 × 0.35 + 4 个阶梯八边形轮 |
| 龙门吊 | 移到**棚后**，跨原木堆，柱高 7.8，横梁 8.0 |
| 原木堆 | 金字塔 3-2-1，单根 φ0.46 × 3.4，端面年轮 |
| 锯末 | 锯框下方 3 处不规则方堆 + 散落 6 块 |

**关键**：锯框是**独立于棚体的第二重剪影**，从正面看，锯框的矩形 + 中间的锯条
把棚口的黑腔切成三块。这是"一眼认出是锯木厂"的唯一办法。

**识别顺序**：锯框 → 原木端面年轮 → 龙门吊。

**禁止**：把锯片做成圆盘（那是近代工厂）；把锯藏进棚深处。

### 4.3 城镇大厅 —— 屋顶重做（高度保持 **17.5 m**）

**问题**：阶梯屋面每一级是一块 0.39 m 厚的板，近看是"厚积木"，不是瓦。

**做法**（按 §3.1 通用标准）：

- 主屋顶：双坡 45°，**薄壳 0.18**，椽头出挑 0.35
- 交叉山墙：改 **阶梯山墙（crow-stepped gable）**，每级 0.40 高 × 0.50 深，
  每级压 **stone_dark 压顶 0.10 厚**，压顶两端出头 0.04
- 钟楼：缩到 2.2 × 2.2，石台 0.30 高；四柱 0.20；百叶 4 道夹在柱间；
  顶为 **3 级阶梯锥顶** + 金球 φ0.22
- 门廊：5 级石阶（宽 4.2），两侧矮墙 0.22 厚 + TC1 压顶 0.12
- 阁楼体块：内缩 0.10 的封闭体，材质 plaster，**不外露**

**禁止**：实心楔形屋面、任何一级台阶厚度 > 0.06 的瓦。

## 7. 出图（Blender）

- 相机：**正交**，方位 45°，俯角 **38°**，取景让主体占 62–70%
- 主光：Area 灯，5500 K，左上前方 45°，软阴影
- 补光：右侧弱冷光，只提暗部，**不产生第二组阴影**
- 环境：灰阶渐变 HDRI（上亮下暗），强度 0.8–1.0
- 渲染：Cycles 256 采样 + denoise，或 EEVEE 64 + AO
- 输出：2048² PNG，sRGB，**与 Godot 的色调对齐**（别出现"Blender 好看、进游戏发灰"）
- 每座另出：正立面、侧立面、俯视三张正交图（1024²，白模 + 硬光）

## 10. 禁止

1. 不要用曲面或细分"救"形体。硬边是风格，不是限制。
2. 不要为了高度数字给建筑加无用的塔或烟囱。
3. 不要把屋顶做成实心楔形。薄壳 + 内阁楼体，是唯一解。
4. 不要让任何一个职责构件被雨棚、布、其他体量遮住。
5. 不要在中间尺度（3–30 cm）上堆装饰。
6. 不要改阵营色的分布规则。
