# 蒸汽车坊 v2 · 设计报告（第八座）

> 任务：v1 被否 —— "门口的展示部分全部去掉"、"形状重做，要长长的、屋头部是三角形，
> 类似魔兽争霸人族车间"、"增加蒸汽元素"、"同一风格、同一美术画面"、"先 low poly 再曲面细分"、
> "俯视角下达到小品 RTS 手游 / 独游的品质"、"装饰与细节符合这套审美、资产不重、
> 任何部位不许错位、不许穿模"。

## 一、v1 为什么被否

| v1 | 问题 |
|---|---|
| 门前"龙门吊 + 半成品蒸汽车 + 木车" | 是**展示**不是建筑：占了半个院子，建筑反而退成背景；删 |
| 屋顶做成"三级采光盒"逐级后退 | 三条玻璃带叠在顶上，像现代办公楼 / 温室；整个形体读不出"车间"；删 |
| 本体外的铁烟囱（11.95 m + 爬梯 + 斜撑） | 又细又高，和"小巧精致"相反；改成砌体烟囱，10.04 m |
| 锅炉房 + 立式锅炉贴在墙外 | 这一条保留并加强：它是这座唯一的"蒸汽叙事" |

## 二、v2 的形体：一条长屋 + 一个三角头

| 段 | 尺寸 / 标高 | 作用 |
|---|---|---|
| 石台 + 压顶 | 0–1.06 / 1.06–1.20 | 与前七座同一套台基节拍 |
| 车间主体 | **7.20 × 12.00**，墙 1.20–5.18 | 长:宽 **1.67**，是八座里最"横"的封闭体量 |
| 正面山墙 | 7.20 宽 × **3.60 高**（5.18–8.78），45° | "屋头部是三角形"就是这一块 |
| 屋面 | 45° 双坡，脊 **9.006**，前后出檐 0.22、两侧 0.42 | 八座里唯一的长坡山墙（`long_gable_head`） |
| 锅炉房披屋 | 2.25 × 7.00，屋面 4.55 → 3.45（19.6° 单坡） | 近侧一层低体量，把长墙压出层次 |
| 立式锅炉 | φ1.40，从 0.58 穿出屋面到 5.38（汽笛 5.86） | 全座唯一的"圆"，中和方盒子 |
| 砌体烟囱 | 1.02 见方，**10.04** | 最高点；两道队色箍 |
| 吊装梁 | x = 1.95，z = 5.60，外挑到 y = 7.43 | 车间叙事：货物从山墙吊进阁楼 |

占地含场地 **12.16 × 14.48 × 10.04**，高:宽 **0.69**（农场 0.74 / 伐木场 0.46 / 哨塔 3.0）。

**为什么长轴走 Y（进深）而不是 X**：
① 山墙朝 +Y 才能在 3/4 视角里正对相机 —— 三角形读得最完整；
② 屋面长 12.4 m 沿进深铺开，俯视时是一条**长脊**，与农场的横向单坡、伐木场的敞棚
   在俯视剪影上完全不同；
③ 近侧（+X）能挂一整条锅炉房披屋 + 锅炉 + 烟囱，形成"三角头 → 长屋面 → 机器"
   由近及远的三个层次。

## 三、蒸汽元素：全部长在建筑上

| 部位 | 做法 | 为什么 |
|---|---|---|
| 立式锅炉 | φ1.40 铆接锅筒 + 三道铜箍 + 压力表 + 汽笛 + 安全阀，**从披屋屋面穿出来** | 嵌在墙里只剩"一堵有管子的墙"；穿出来才有"这台机器在给整座作坊供气"的体量 |
| 砌体烟囱 | 1.02 见方、两级压顶、黑喉、两道队色箍 | 最高点定在 10.04，比脊高 1.03；远景第一眼是"工厂" |
| 蒸汽主管 | 沿外墙一条 φ0.26 铁管 + 4 只抱箍 + 2 只铜接头，高 2.96 | 把炉膛 / 锅炉 / 烟囱串成一条线；也是外墙上唯一的横向结构线 |
| 炉膛 | 凸出墙面的铸铁火箱（0.40 深）+ 关着的炉门 + **发光炉栅**（4 根竖铁条压着火） | 关着门比开着门干净；一条橙光在 RTS 距离上是"这里在烧火"的信号 |
| 蒸汽管进车间 | 锅炉 → 车间墙 φ0.23 铁管 + 法兰 + 铜阀门轮 | 说明"蒸汽进车间驱动机械"，不是摆设 |
| 烟道 | 锅炉背后 → 烟囱的 φ0.40 铁管（被锅筒挡住大半） | 结构关系成立即可，不抢戏 |
| 天窗 | 近坡 3 + 远坡 2，平嵌（铁框 + 玻璃 + 0.12 m 边框） | 俯视时两坡都有节奏；也是车间"要采光"的功能件 |
| 吊装梁 | 山墙外挑 2.03 m，斜撑 + 滑轮组 + 6 环铁链 + 吊钩 | 比 v1 的龙门吊小一个量级，但叙事完整 |

**刻意没做的**：蒸汽白烟（静止的白烟团在低模里读成"棉花"）、飞轮 / 皮带（会和伐木场的
锯轮撞语义）、任何地面车辆（v1 的教训）。

## 四、明度秩序与材质

```
夯土场地 → 中灰台基 → 亮压顶 → 亮石墙 → 近黑压梁 / 檐口 → 石板瓦（roof）
→ 铁 / 铜机器 → 队色点睛
```
一条"中 → 亮 → 中 → 近黑 → 亮"的节拍，每层只做一件事：
- **墙**只有一种材料（`stone_light`），靠 5 条深木（压梁 / 门柱 / 山墙木构 / 檐口封板 /
  椽头）切出层次，不靠加材质；
- **门**是唯一真开洞（墙拆成左右墩 + 拱上一块），洞内一个 1.3 m 深的门厅：
  左扇内开 55°、右扇关、地上三块火炭 + 铁栅；
- **屋面**一片干净石板（不加瓦垄）：八座里铁匠铺的屋面也是干净的，
  加三道亮脊会读成"金属条纹板"（试过，删了）。

材质仍是图集里那 22 个，**没有新增**（`fire_core` 想做火心，最后改用已有的 `flame_in`，
免得动 `ATLAS_ORDER`）。

## 五、队色（6–9% 规范）

只染五条"结构线"，没有一块是"随便贴上去的"：

| 位置 | 面积 | 说明 |
|---|---|---|
| **屋脊压条**（0.34 × 12.4） | 4.2 m² | 俯视唯一通长的水平染色；对标伐木场的蓝色檩条 |
| 山墙垂旗 + 金流苏 | 2.1 m² | 正立面最醒目的一块 |
| 烟囱双箍（0.54 / 0.26 高） | 1.2 m² | 远景的"队色旗杆" |
| 门扇踢脚板 ×2 | 0.7 m² | 读作"刷了漆的门"，不是窗 |
| 压梁下饰带 + 披屋檐口压条 | 1.1 m² | 两条细线 |

实测：**正视 7.34% / 3-4 视 4.99% / 俯视 4.17%**。
俯视这一档靠的就是屋脊压条 —— 立面上的染色在 58° 俯角下会被压扁（神秘圣地踩过）。

## 七、这一座踩到的新坑

1. **山墙三角形的高度写错一次**：`PC_Z1 - 0.06`（墙脚 1.14）当成了山墙底边 ——
   整块 7.2 × 7.6 的"山墙"把门洞糊死，正面读成一堵没有门的白墙。山墙底边必须是 `WZ1`。
2. **锅炉半径被两道边界夹住**：主檐封板外沿 x=4.06 / 披屋墙内表面 x=5.59，净空 1.53 m。
   一开始 φ1.84 的锅筒同时穿主屋面和檐口封板（CLIP_CROSS 20 处）→ 收到 φ1.40。
3. **封檐板必须盖住屋面端头的断面**：屋面端头是竖直面、正对相机，受光后是一条**白色亮带**，
   在正面像给屋顶描了一条银边。把封檐板下移 0.08、加厚到 0.25 才压住。
4. **压梁 / 横梁不能超出山墙的斜坡**：5.10 宽的横梁在 6.34 高处比三角形宽 0.2 m，
   两头戳进屋面；所有横向木构都要按该高度的可用宽度重算。
5. **立面上的大橙板 = 假**：门厅里 0.72 × 0.56 的整块 `ember` 读成"贴了一张橙色便利贴"；
   改成三块大小不一的火炭 + 铁栅 + 石槛才像火。
6. **蓝色脊帽的高度决定它像不像塑料管**：0.26 宽 × 0.13 高时是一条圆管；
   压到 0.34 宽 × 0.065 高，才读成"油漆过的脊压条"。
7. **`cyl(axis="Z")` 返回 None**（bslib 只支持 X / Y）—— 桶盖必须走 `vcyl`。
8. **后山墙百叶只做四根浮条**：没有框与背板时，四根铁条在背面像"贴在墙上的百叶碎片"。
