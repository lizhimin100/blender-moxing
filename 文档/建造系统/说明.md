# 通用建造工地系统 v2 · 世界 Z 显影

> **v2 的核心改动：建筑本体不再缩放、不再切层、不加骨、不加动画。**
> "从下往上长出来"由**世界 Z 遮罩**完成 —— 引擎侧一个 uniform（显影高度，米），
> 0% 只露地基、50% 露到墙身、100% 完整。脚手架独立、随建随升、完成时拆掉。
>
> 交付：`assets/<建筑>/<建筑>_建造.glb`（clip `build`）+ `<建筑>_图标.png`
> 预览台 `建造系统.html`（HTTP）· 工具 `blender/bs_v6/cs_*.py` · 出图 `docs/建造系统/v2/`

## 0. 一句话对比 v1

| | v1（等比缩放） | v2（世界 Z 显影） |
|---|---|---|
| 施工中看到什么 | **完整建筑的缩小版**（大脚手架 + 小建筑） | **被剖开的半成品**：地基 → 半截墙 → 未封顶 |
| 建筑本体 | 切 9 层、绑 `band_root`、scale 0.10→1.0 | 不切、不绑、不动；几何与源资产逐三角一致 |
| GLB 里建筑有几根骨 | 10 | **0** |
| 显影控制量 | 根骨的 scale | `reveal_height`（世界 Z，米） |
| 九座体积 | 18.8 MB | **11.9 MB**（-37%，切层拆出来的顶点没了） |
| 代价 | 零穿帮、无需 shader | **需要引擎侧一行 shader**（见 §3） |

v1 的问题就是用户说的那句："大脚手架 + 小建筑"。缩小版无论怎么打光都读作"离得远的完整房子"，
读不出"没盖完"。

## 1. 系统契约（新增一座只填这 4 + 1 项）

`docs/建造系统/契约/<建筑>.json`（**不再放进 assets**）：

| 字段 | 含义 | 说明 |
|---|---|---|
| `footprint` | 占地 `[W, D]`（米） | 场地外轮廓，含院子 / 台阶 / 围栏 |
| `height` | 总高（米） | 剖到最高点（含旗杆 / 箭饰） |
| `yaw` | 朝向（度） | 0 = 正面 +Y（导出后 −Z） |
| `attach` | 挂点表 | `hoist`（悬臂吊杆）、`banner`（挂旗） |
| `body` | 四边外沿 `[x0,x1,y0,y1]` | 由 `cs_rig.measure` 量一次写回，只决定脚手架贴墙位置 |

## 2. 建造表现：一条时间轴，四段

以箭塔（6 步架 / 5.77 s）为例：

| 阶段 | 时间 | 发生什么 |
|---|---|---|
| 放线备料 | 0.00–0.46 | 放线框、12 桩 + 麻绳、石垛 / 原木捆、水桶 / 砂浆槽、悬臂吊杆 —— **全部从地表顶出** |
| 显影施工 | 0.46–3.82 | 建筑**遮罩高度线性上移**（1.00 → 17.46 m）；脚手架第 k 层在作业面到达前 0.20 s 立起 |
| 撤架 | 3.82–4.60 | 从上往下，每层 0.09 s：Z 向收拢 + 抽到地下 |
| 清场 | 4.60–5.77 | 吊杆 → 料堆 → 桶 / 槽 → 绳 → 桩 → 放线框，依次退回地里 |

**显影高度公式（引擎与预览台必须用同一个）：**

```
reveal_height(t) = z0 + (H - z0) * clamp01((t - t0) / (t1 - t0))
```

`z0 / t0 / t1` 每座不同，全部写死在 `docs/建造系统/参数/<建筑>.json` 的 `reveal` 段：

```json
"reveal": { "axis": "z", "z0": 1.0, "z1": 17.46, "t0": 0.46, "t1": 3.82 }
```

- `z0 = clamp(H × 0.10, 0.45, 1.00)` —— 0% 露到台基顶，**只露地基**，不露一层窗。
- 线性映射（不是缓动）：引擎从动画时间直接算高度，不需要曲线采样，不会和预览走形。

## 3. 引擎侧实现（全部契约就这一行 shader）

> **Godot 4 的完整接入步骤、可直接用的着色器与驱动脚本，见 `Godot接入.md`。**
> 这一节只讲原理和最小代码。

GLB 里的建筑处是**原始尺寸、原始几何**，没有任何 transform 动画。
每帧把 `reveal_height` 塞进材质，丢弃高度超过它的片元。

**高度取的是「模型自身坐标的 Y」**（模型原点在占地中心的地面上）——不是世界坐标。
这样整栋楼搬到地图任何位置、绕 Y 转任何角度都不用改参数。

```glsl
// Godot 4 spatial shader（最简版，完整版在 godot/build_reveal.gdshader）
shader_type spatial;
render_mode cull_disabled, depth_prepass_alpha; // 双面看内壁 + 阴影也裁

uniform float reveal_height = 100.0;   // 米；>= 建筑高 = 完整
uniform float jag = 0.034;             // 剖口毛边幅度（0 = 激光切）
uniform vec3  raw : source_color = vec3(0.60, 0.57, 0.50);

varying vec3 v_local;

void vertex() { v_local = VERTEX; }    // 物体空间，Y 就是高度

void fragment() {
    float n = sin(v_local.x * 7.3) * 0.5 + sin(v_local.z * 9.1 + 1.7) * 0.35
            + sin(v_local.x * 23.0 + v_local.z * 17.0) * 0.25;
    float y = v_local.y + n * jag;
    if (y > reveal_height) discard;
    // 剖口往下 0.42 m 铺一层生料：截断面读作"未完工"，不是"平屋顶"
    ALBEDO = mix(ALBEDO, raw, smoothstep(reveal_height - 0.42, reveal_height, y) * 0.58);
    if (!FRONT_FACING) ALBEDO *= 0.40;  // 内壁压暗
}
```

> 轴：**Godot 是 Y-up，glTF 也是 Y-up，导入不用转**，所以高度一律是 `.y`。
> 只有 Unity 的 `mesh.vertex` 走 `.y`、three.js 的 `worldPosition` 也是 `.y`——三者同轴，
> 唯一例外是 Blender 的 Z-up，只在建模期用。

预览台的完整实现见 `build/build_site_shell.html`（`injectClip()`）；three.js 写法：

```js
shader.vertexShader = shader.vertexShader.replace('#include <begin_vertex>',
  `#include <begin_vertex>
   vWClip = (modelMatrix * vec4(transformed, 1.0)).xyz;`);
shader.fragmentShader = shader.fragmentShader.replace('void main() {',
  `void main() {
     float y = vWClip.y + jagNoise(vWClip.xz) * uJag;
     if (y > uCut) discard;`);
```

**阴影要一起裁**：three.js 侧另给 `mesh.customDepthMaterial` 打同一段 discard
（预览台就是这么做的）；Godot 侧靠 `depth_prepass_alpha`。

### 为什么必须放引擎侧

glTF 动画只能驱动 transform / morph / 贴图，驱动不了 shader uniform。
把"任意高度剖切"烘成几何 = 每帧一个网格，体积翻几十倍；烘成 morph = 顶点被压到
剖面上会糊成一坨。所以 **GLB 只负责"实体 + 套件动作"，遮罩是运行时的一行 shader**。

### 不想写 shader 的退路

按部件分段（地基 / 墙 / 屋顶 / 装饰）逐段显隐，观感是台阶式的（每 2 m 跳一下），
但**绝不缩放**。要这条退路就按 `参数/<建筑>.json` 里的 `z0` 与 `H` 等分设阈值即可 ——
库里没做，因为 shader 方案已经在用了。

## 4. 工地套件（cs_kit）

| 件 | v2 规则 |
|---|---|
| 放线框 | 本体外扩 1.55 m，木梁 0.14×0.10，四角压石，正面留 1.9 m 门 |
| 桩绳 | 一圈 12 根桩（0.075×0.60，白灰带 + 铁帽），麻绳 0.032、垂弧 0.075 |
| **脚手架** | 本体外扩 0.30、四面围合、步高 2.20、**3–6 步**（`clamp(round(min(0.8H, 13.4)/2.2), 3, 6)`）；**随作业面逐层立起**，比作业面早 0.20 s；**每层都有脚手板 + 挡脚板**（作业面随建随升），护栏只在顶层（否则成笼子挡住建筑） |
| 料堆 / 桶 / 槽 | 门外石垛 + 原木捆，门内水桶 + 砂浆槽 |
| 吊装 | 场地后左角悬臂吊杆（0.26H，2.6–3.4 m）+ 绞盘 + 吊索石块 |
| 队色 | 顶层立杆挂旗 + 正面右角挂幡，随顶层脚手架出现、撤架前收 |
| 基座扬土 | 一圈压扁土块（本体外 0.16），显影开始时顶出、清场时退回 |

**动作语汇（v2 收紧）**：

1. **场件一律"从地表顶出 / 退回地里"** —— 平移，不是缩放。
2. **脚手架"Z 向从底面立起"** —— 每层的骨在层底，`scale.y 0.02→1.05→1.0`，读作木架被立起来。
   （这不是建筑缩放：架子本来就是一根根接起来的。）
3. **拆架 = Z 向收拢 + 抽到地下**，从上往下每层 0.09 s。
4. **没到时刻的层搬到 500 m 以外** —— 只把 Z 压到 0 的话，几何还在，会变成半空中的
   一片黑平面（这台机器上踩过）。
5. **建筑本体一个关键帧都没有**：`BODY_RIG = 0` 是硬指标（见 §6）。

- `BODY_RIG`：建筑本体有父级 / 有骨架修改器 / 有动画 → 1。**必须 0**，这是"不许缩放"的机器判据。
- `BODY_TRIS`：本体三角数与顶点数和源资产逐项比对，不一致 → 1。**必须 0**，证明几何没被动过。
- `BVH_CROSS`：套件与建筑的真实三角形相交（满场帧）。
- `BOX_TALL`：收尾帧地面以上还剩多少有面积的三角形。
- `SCAF_OVER`：脚手架顶高 − 建筑高（队色旗杆不算）。归零 = 架子不抢剪影。

## 8. 已知限制

1. **剖面没有封盖**：建筑是壳体，剖开后是从上方看进内部（内壁已压暗）。真"切面盖板"要
   逐帧生成几何，不做。剖口靠 0.42 m 生料带 + 3.4 cm 毛边读作"未完工"。
2. **高屋顶的建筑 50% 会落在屋顶段**（铁匠铺 / 伐木场 / 蒸汽车坊）—— 截断面比墙身大。
   这是线性映射的必然结果；要改就调 `reveal_z0`，但会让"0% 只露地基"变味。
3. **脚手架只搭到 80%H**（上限 13.4 m），顶盖段没有架子 —— 故意的，架子高过屋顶会抢剪影。
4. 施工音效 / 粒子扬尘未做；扬土是几何体。
