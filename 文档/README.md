## 目录约定

```
docs/
  00-使用手册/     面向"人"：怎么用、怎么提需求、全流程
  10-规范/         面向"执行"：硬规则、验收口径（改之前先读）
  20-经验/         面向"下一次"：踩坑复盘、改进清单
  审美/            风格对照台 + 风格档案（"说不清"的时候用这个）
  建造系统/        契约 json、参数 json、说明、Godot 接入
  <资产>/v1/       该资产的档案：报告、体检、交付图（脚本自动写，别手改）
```

`<资产>/` 这一层故意不放进编号目录：它是**产物**，路径被脚本写死（`dl_align` / `dl_shots` /
`dl_quick` / `dl_cs` 都往这里写），一挪就断。要看档案直接按名字找。

## 三条最容易忘的

1. **`assets/` 里只放能直接进引擎的东西。** GLB + 图标。`.blend`、`图集/`、中间 json 一律不进。
2. **改资产树不用改脚本。** 所有脚本走 `blender/bs_v6/assets_path.py` 的 `asset_path("名字")`，
   只认资产名，不认层级。加了新分类只影响那一个文件。
3. **改完必须重跑体检。** `CLIP_CROSS / COPLANAR_UP / FLOAT` 三个 0 + `grounded` + `front_ok`，
   少一个都不算完。
