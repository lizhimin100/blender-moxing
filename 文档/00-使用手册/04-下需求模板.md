# 下需求模板

> 同一句话，"做个地牢"和"做个下沉式石台，台顶一座掀了顶的方塔"，
> 我交出来的东西差三倍工作量。这份模板是**最少信息量**，不是免责声明。

---

## 一、一句话骨架

```
【类型】一座 <什么用途> 的 <建筑/场景/道具>，属于 <阵营/世界观>
【占地】<W> × <D> m，高约 <H> m（可以给范围）
【识别点】一眼认出它靠 <一件事物>
【氛围】<3 个形容词>，参照 <游戏/画师/截图>
```

例：

> 【类型】一座"人族前线补给站"，属于联盟
> 【占地】10 × 9 m，高 8–9 m
> 【识别点】外挂的木梯通到一座半塌的望楼
> 【氛围】紧凑、粗粝、有人住过，参照《帝国时代 4》的营地

---

## 二、五个必答项（答不出就先别开工）

| 问题 | 为什么必须 |
|---|---|
| **它服务什么玩法？** | 生产 / 防御 / 装饰 决定尺度与复杂度上限 |
| **玩家从哪个角度看到它？** | 俯视 45° 为主 → 屋顶和台面最重要，立面次要 |
| **旁边站着谁？** | 决定色温、明度、队色占比（不能比同级建筑更亮） |
| **它有几处"人迹"？** | 火 / 箱 / 旗 / 晾衣 / 脚印 —— 0 处就是"展品"不是"场景" |
| **哪件事绝对不能出现？** | 否定式约束最有效："不要圆顶""不要绿色" |

---

## 三、可选但有奇效的四句

1. **"我要一个错误的决定"** —— 比如"塔是歪的""楼梯只修了一半"。
   废墟类资产加一句这个，立刻不呆板。
2. **"这块留给玩家看"** —— 指一个位置（比如台面中央），我会把细节密度堆在那儿。
3. **"像 <某张图> 的第 3 张"** —— 比任何形容词都准。
4. **"先给我四张对照"** —— 说不清的时候，让我出方向图，你只负责指。

---

## 四、描述"造型"的八个词（别用形容词，用轴）

不要写"好看""高级""有质感"。写这八个里的几个：

```
体量比 / 主次 / 剪影 / 面的软硬 / 明度阶梯 / 色数 / 装饰密度 / 破损度
```

对照表在 `../审美/如何描述.md`。最省事的写法：

> 体量比 3（正好），主次 4（分得不够开），剪影 3，面的软硬 2（太圆了），
> 明度 4（太平），色数 3，密度 5（太闹），破损 2（太新）

八个数，我照着调，一轮就能对。

## 五、反面例子（这些说法我要追问三轮）

| 说法 | 我需要追问 |
|---|---|
| "做个哥特一点的" | 哥特是 12 世纪法国还是 19 世纪复兴？尖拱/飞扶壁/玫瑰窗要哪个？ |
| "细节丰富一点" | 丰富 = 增加构件数，还是增加单个构件的转折？这两件事视觉结果相反 |
| "和之前那个一样，但不一样" | 一样的是材质/比例/语言，不一样的是布局/高度/装饰？ |
| "参考这个图"（只给图） | 参考的是它的配色、体量、还是构图？ |
| "随便，你决定" | 可以，但我会按"最保守"的方案做 —— 保守方案的返工率最高 |

## 六、改版时说什么

改版比新建更容易说错。三句话结构：

1. **"第 X 版的问题是 ___"**（现象，不是感受）
2. **"我想让它 ___"**（目标，可测量：更高/更暗/更碎）
3. **"其余不要动"**（默认我会保守，但明确说了更安全）

例：

> v2 的问题是塔心和井壁一个颜色，"深"没读出来。
> 我想让井底压到接近黑，井壁保持现在的灰。
> 其余不要动。
