每个资产目录**只有**：`<名>_图标.png` + 若干 `.glb`。

| 文件名 | 什么时候用 |
|---|---|
| `<名>_手游_近.glb` | **默认用这个**。图集 + 4 材质，同屏几十座不卡 |
| `<名>_手游_中.glb` / `_远.glb` | 视距切换档，省的三角面 |
| `<名>.glb` | 曲面细分版，宣传图 / 端游画质 |
| `<名>_低模.glb` | 硬边低模，引擎里做风格化或再加工 |
| `<名>_建造.glb` | 建造动画（世界 Z 显影 + 脚手架），只有建筑有 |

## 1. 拖进 Godot

1. 整个 `assets/` 拷进项目（建议 `res://assets/`）。
2. Godot 4 会自动生成 `.import`；模型是 **Y-up、原点在占地中心、脚底 y=0**，
   直接 `instantiate()` 放到地形上即可，不用手动抬。
3. 材质是 4 个：`主体`（图集）/ `team` / `team_trim` / `自发光`。
   **换阵营只改后两个**，别动 `主体`。
4. 火想要会呼吸：把 `godot/vfx/fire_fx.gd` 挂到建筑根节点，默认参数就行。

> 单位（`assets/单位/`）是带骨骼的 `.glb`，动画已内嵌，拖进去直接有 `idle/run/attack` 等。

## 3. 改模型（只有一条路：改代码）

模型不是手捏的，是**几何即代码**。改 `blender/bs_v6/<x>_model.py` 里的参数/构件，
重新跑一遍导出链，不要打开 .blend 手动改 —— 那会和代码脱钩。

### 常用五条命令

```bash
BL="D:/360安全浏览器下载/blender.exe"

# ① 看形体（快，只出两张 480px 图）
echo dg_model > blender/bs_v6/_target.txt
$BL -b --python blender/bs_v6/dl_quick.py

# ② 体检（错位 / 穿模 / 共面 / 悬空 / 贴地 / 朝向）
$BL -b --python blender/bs_v6/dl_align.py

# ③ 导出低模 + 细分
$BL -b --python blender/bs_v6/dl_export.py

# ④ 图集 + 手游三档
$BL -b --python blender/bs_v6/export_mobile.py

# ⑤ 建造动画
$BL -b --python blender/bs_v6/dl_cs.py
```

一次全套（改完一定要跑全套）：

```bash
for s in dl_align dl_export export_mobile dl_cs dl_shots icon_shots; do
  $BL -b --python blender/bs_v6/$s.py
done
python blender/bs_v6/icon_post.py
```

### 老九座另有一套入口

`export_<name>.py`（如 `export_arrowtower.py`）是早期单座导出，仍然可用；
新资产统一走 `dl_*`。两者都读同一份 `bslib.PALETTE` / `bs_atlas`。

## 4. Blender 桥接（可选）

想在已打开的 Blender 里直接执行脚本（不重启）：

```bash
"D:/360安全浏览器下载/blender.exe" --python build/start_bridge.py   # GUI 模式，端口 9876
python build/bl_act.py ping
python build/bl_act.py act blender/bs_v6/dl_quick.py
```

**后台模式（`-b`）不加载桥接插件**，所以自动化链路一律用 `-b --python`。

## 5. 出图（报告用）

```bash
$BL -b --python blender/bs_v6/dl_shots.py     # 主图 / 正面 / 侧面 / 俯视 / RTS / 近景
$BL -b --python blender/bs_v6/icon_shots.py   # 图标原图（1280²，写 docs/_tmp）
python blender/bs_v6/icon_post.py             # 合成 512 图标，直接落进资产目录
```

`docs/_tmp/` 是一次性的，链路跑完可以整个删掉。
