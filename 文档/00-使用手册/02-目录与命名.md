# 目录与命名

## 1. 三层分工

| 目录 | 放什么 | 判据 |
|---|---|---|
| **`assets/`** | 能直接拖进引擎的东西 | 只有 `.glb` + `_图标.png`。多一个文件都算错 |
| **`blender/`** | 生成资产的源码 | `*_model.py`（几何）、`*_quick/_align/_shots`（工具）、`_源文件/`（不该进资产的 .blend） |
| **`docs/`** | 判断依据 | 报告、体检、规范、经验 |

一条硬规矩：**`assets/` 里出现 `.blend` / `图集/` / `_tmp` 就是事故。**
清理脚本 `build/clean_assets.py`（干跑）/ `--apply`（真删，先打包进 `_bak/`）。

```
assets/
  建筑/
    联盟/        铁匠铺 兵营 城镇大厅 哨塔 箭塔 农场 伐木场 神秘圣地 蒸汽车坊 酒馆内部
    失落帝国/     地牢 地下城入口
    通用/        营火 火把 火炬 火堆
  单位/
    联盟/        剑士 农民 弩兵 矮人火枪手 联盟步兵
    野怪/        豺狼人/豺狼人战士 · 豺狼人斥候
  地形/          底材 png + 地块 glb + 材质图集
  资产索引.json
```

**分类只有两层，第三层就是资产名。** 加新族（比如"亡灵"）直接在 `建筑/` 下开目录，
不需要改任何脚本 —— 见下面第 3 节。

## 3. 为什么改目录不会弄坏脚本

整个工程只有一个地方知道资产树长什么样：`blender/bs_v6/assets_path.py`。

```python
from assets_path import asset_path

asset_path("箭塔")            # assets/建筑/联盟/箭塔
asset_path("剑士", "图集")     # assets/单位/联盟/剑士/图集   ← 后缀当子路径
asset_path()                  # assets
```

它在启动时扫一遍 `assets/`，把"目录名 → 路径"建成索引（同名的优先选含 `.glb` 的、层级浅的）。
所有导出 / 体检 / 出图 / 建造脚本都只写资产名，不写层级。

**所以：**
- 想把"酒馆内部"从 `联盟/` 挪到 `通用/`？`mv` 一下即可，脚本不用动。
- 想加一层"版本"？也不用动脚本。
- 只在一种情况下要动它：**两个资产不同路径但同名**（那本来就不该发生）。

索引可以随时重新生成：

```bash
python blender/bs_v6/assets_path.py     # 打印几个样例 + 重写 assets/资产索引.json
```

## 4. 命名（改动前先看，改名 = 改所有引用）

| 对象 | 规则 | 例 |
|---|---|---|
| 资产目录 | 中文全名，与文档/报告一致 | `蒸汽车坊` |
| 低模 | `<名>_低模.glb` | `地牢_低模.glb` |
| 细分 | `<名>.glb` | `地牢.glb` |
| 手游三档 | `<名>_手游_{近,中,远}.glb` | `地牢_手游_近.glb` |
| 建造动画 | `<名>_建造.glb` | `地牢_建造.glb` |
| 图标 | `<名>_图标.png`（512²） | `地牢_图标.png` |
| 源模块 | `<代码前缀>_model.py` | `dg_model.py`（DG）、`uc_model.py`（UC） |
| 构件名 | `<分区前缀>_<构件>`，如 `gt_` 门楼、`tw_` 塔、`pd_` 台基 | `gt_merlon`、`tw_cap` |
| 材质 | 见 `bslib.PALETTE`，**只能追加到末尾** | `ancient_pale` |

**版本号只出现在 `docs/` 和 `CHANGELOG.md` 里，不进文件名。** 资产文件永远覆盖同名。

## 5. 中间产物的去处

| 中间产物 | 去哪 | 谁清 |
|---|---|---|
| `.blend` | `blender/_源文件/<资产>/`（不进 assets） | 手动，或一直留着 |
| 图集源图 `主体.png / ORM.png / 自发光.png` | `docs/_tmp/图集/<资产>/`（已打包进 GLB） | 链路跑完删 `docs/_tmp` |
| 图标原图 `_raw_<名>.png` | `docs/_tmp/图标原图/` | 同上 |
| 体检 txt / 交付图 / 报告 | `docs/<资产>/v1/` | **保留**（这是档案） |
| 快速看片 `quick_*.png` | `docs/<资产>/v1/` | 交付前删 |

> 2026-11-04 起，`export_mobile` 与图标链已经改成写 `docs/_tmp`，
> 跑完不会再在 `assets/` 里留下 `图集/` 和 `图标/`。

## 6. 改版怎么归档

改任何一座之前：

```bash
cp -r "assets/建筑/联盟/箭塔" "assets/_历史版本/箭塔_v1"   # 旧 GLB 留一份
```

旧报告不要覆盖：`docs/<资产>/v1/` 留着，新版本开 `v2/`。
`CHANGELOG.md` 记一行"改了什么、为什么"。
