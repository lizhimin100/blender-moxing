## 2. 屋面构造（六座共用，`build/roofs_hs.py`）

檐口处法向总厚 = 椽 0.10 + 望板 0.03 + 瓦 0.05 = **0.18 m**：

```
瓦      每皮高 0.22 / 露明 0.16 / 厚 0.05，每皮外挑 0.03，每 3 皮错缝
望板    0.03，贴椽上，不外露
椽      0.14 宽 × 0.10 高，间距 0.55，檐口出挑 0.35，椽头端面可见
封檐    0.12 × 0.22，与椽头平齐
脊      脊木 0.16 × 0.20 + 脊瓦 0.24 宽，高出两侧 0.04
阁楼    内缩 0.10 的封闭体块，挡住薄壳下的空腔（不参与外观）
```

茅草（农场谷仓）：总厚 0.42，3 层叠压、每层外挑 0.08、檐口 45° 切口、脊部 3 级收头 + 压脊木。

## 4. 判定口径（`check_hardsurface.py` 头部的注释即规范）

| # | 项目 | 口径 |
|---|---|---|
| 1 | 硬边 | 相邻三角形法线夹角落在 **(0.5°, 8°)** 的边数 = 0。共面（0°）与硬转折（≥8°）都不算曲面；只有"用一排小转折逼近圆弧"才会落进这条缝 |
| 2 | 倒角 | 只统计 `role="bevel"` 的构件，宽度 ≤ 3 mm（细部）/ 40 mm（大转角） |
| 3 | 着色 | 每个三角形三个顶点法线互相重合，且与几何法线 |dot| ≥ 0.999 |
| 4 | 屋厚 | 取 `role="roof"` 构件面积最大的面作基准，找反向平行面的平面距；实心楔形会直接暴露 |
| 5 | 职责 | `role="duty"` 在正视剪影中的像素占比 ≥ 12%；**天际线型**（垛口）改判"是否定义最高轮廓" |
| 6 | 透空 | 屋面（roof/rafter/attic）单独三向投影，内部连通背景块面积 = 0 |
| 7 | 木接 | 木构件**端面对端面**、2 mm < 缝 < 50 mm 的对数 = 0（用真实三角形距离，不用 AABB） |
| 10 | 剪影 | 六座两两**轮廓带** IoU < 40%（实心面积 IoU 对同尺度建筑群天然偏高，不作判据） |

## 5. 已知残余（不掩盖）

1. **兵营职责占比 2.6%**：垛口天际线是"线"不是"面"，面积口径对它不适用。
   脚本按"定义最高轮廓"放行，并在报告里单独标出；若必须凑到 12%，
   只能加无意义的实墙 —— 违反工单 §10.2，故不做。
2. **木接缝残余：伐木场 8 / 兵营 3 / 铁匠铺 1 处**（农场、哨塔已 0）。
   `snap_wood.py` 已机械补齐 92/36/24/104/86/27 处；残余是"斜撑端面顶在斜面或端点上"、
   按盒延长会改变构件的朝向，需要改起止点，下一轮逐根处理。
3. **城镇大厅交叉山墙与主屋面的交接**：409 px 透空（把屋面单独投影后测到），
   根因是两片薄壳相交处没做布尔切口。正/侧视不可见，俯视能看到一条 3–4 cm 的缝。
   修法明确（把交叉山墙的屋面裁到主屋面交线、再补一圈封边），但要写一个平面裁剪，
   不在本轮硬凑。

## 7. 与 Blender 的关系（诚实说明）

- **几何来源**仍是 `build/buildings.py` 的参数化描述 —— 它是唯一能同时满足
  "1 材质 / 1 primitive / 骨骼动画 / 图集 UV" 与"≤140 节点"的管线，
  换成"在 Blender 里手工摆物体再导出"会直接撑爆节点预算与 draw call。
- **Blender 承担**：`.blend` 工程（可在 GUI 里继续精修）、六座正式出图、白模正交图。
- 出图脚本 `blender/render_asset.py` 通过插件通道执行（`build/bl_rt.py` 是这条
  HTTP 通道的本机客户端，与插件工具 `blender_rt_do` 同一条 `/act` 路由）。
