# 地形底材 · 制作报告（草地 / 泥土）

> 目标一句话：**让地面退到建筑后面去**。九座建筑的读感靠剪影与明暗秩序，地面一旦
> 有高频细节或强对比，俯视时整张图就会"花"，建筑的体量被底板吃掉。

## 一、判据（先定验收，再动手）

| 判据 | 口径 | 结果 |
|---|---|---|
| 无缝 | 跨缝差 ÷ 缝内侧紧邻差，≈1 才算接得上；>2.5 会看出线 | 草地 1.03 / 0.99，泥土 1.00 / 1.03 |
| 平涂 | 只有低频色块，没有高频噪点（3×3 邻域极差 99.5 分位） | 草地 0.054，泥土 0.022（对比：草簇边缘 0.08） |
| 克制 | 单张图的明度总跨度 ≤ 10% | 草地 0.4127–0.5046（9.2%），泥土 0.3747–0.4104（3.6%） |
| 不抢戏 | 进场景后建筑仍是第一眼 | `docs/地形/地形_*_兵营.png` |
| 可观感 | 512² 8bit RGB、无 alpha、sRGB | 两张均符合（PNG chunk 只保留 IHDR/sRGB/gAMA/cHRM/IDAT/IEND） |

## 二、无缝：把 UV 映射到 4D 圆环

Blender 的 Noise / Voronoi 都有自己的坐标空间，UV 在 0/1 处不连续 —— 直接拿 UV 采
样，平铺时必然有一条接缝。三种常见做法都试过：

- **offset 混合**（采样 3×3 偏移再按距离加权）：边缘会出现一条对比度变浅的带，
  草簇这种小东西在带里变成"幽灵"。
- **镜像**：能接上，但图案变成对称的，肉眼一眼看出是"镜像拼的"。
- **Wrap 到格子里做 Voronoi**：胞元在边界被切断，接缝处出现一条笔直的裂缝，
  平铺后就是一张方格网。

最终走**圆环映射**：

```
u → (R·cos2πu, R·sin2πu)      v → (R·cos2πv, R·sin2πv)
R = 1/(2π) → 圆环弧长 = 1 = 一个 tile
```

喂给 Noise 的 `Vector(x,y,z)` + `W`（4D 模式）。圆环局部等距于平面（没有拉伸），
4D 噪声切在它上面就是一张各向同性的二维噪声，而且**输入本身以 1 为周期**，
所以输出天然对齐 —— 不需要缝合，也不会在边界留下一圈"处理过的痕迹"。

好处之二是参数变直白：`Scale` 直接等于"一个 tile 里有几个周期"。

> 坑：`noise_dimensions` / `voronoi_dimensions` 默认是 3D，不显式设成 4D 的话
> `W` 是**静默忽略**的 —— 图照出，缝照有。Voronoi 的 4D 支持不是所有教程都提，
> 这次实测 Blender 5.2 的 Voronoi 支持 1D/2D/3D/4D，且 `DISTANCE_TO_EDGE` 可用。

## 三、节点链

两张图是同一套骨架，只是草地用"阈值斑块"、泥土用"Voronoi 边缘"：

```
UVMap → torus(4D) ─┬→ Noise(scale 4.6, detail 1.0) → normalize → ColorRamp 三阶色块
                   ├→ Noise(scale 7.5, detail 0.5) → ±2.6% 明度微调
                   └→ Noise(scale 16,  detail 1.0) → 顶端 4% → 草簇 + 光晕
                                                        ↓
                                              Emission(1.0) → Output
```

| | 草地 | 泥土 |
|---|---|---|
| 主色块 | Noise 4.6 / detail 1.0 / distortion 0.28 → ColorRamp 三阶 | Noise 5.2 / detail 1.0 → ColorRamp 三阶（跨度只有 3.6%） |
| 中频微调 | Noise 7.5，±2.6% | Noise 9.0，±1.3% |
| 结构 | 草簇：Noise 16 阈值切顶端 4%，加一层 0.22 强度的"光晕" | 干裂：Voronoi 4D `DISTANCE_TO_EDGE`，scale 10.5，先被低频噪声揉过 |
| 裂纹 | — | `d<0.024` 压暗 55%（线宽 ≈ 3 px），板心 `d 0.10→0.45` 提亮 16% |
| 色阶 | #747E48 / #7A834C / #858D56 / 簇 #626B3E | #73614A / #78664E / #7D6B53 / 裂 #655440 |
| 节点数 | 33 | 35 |

**为什么色块用 ColorRamp 不用 MapRange+Mix**：两个同色相邻色标天然就是"平顶段"
（平涂），中间的斜坡就是软边；调参时拖色标即可，不用反推归一化阈值。

## 四、标定：先把噪声的实际分布量出来

Blender 的 FBM 噪声不是均匀分布 —— detail 1.0 时值集中在 **0.56–0.86（sRGB 口径）
/ 0.31–0.69（线性口径）**，而且随 Scale/Detail/Roughness 变。凭感觉写 0.5 切一刀，
结果是**整张图被夹死在一个颜色上**（第一版草地就是这个毛病：明度 0.353–0.487，
其实是同一个色 + 草簇）。

做法：`tr_tex.py -- calib` 把每一层场渲成灰度图，量 p2/p98，写进 `NORM`；
之后所有阈值都在**归一化空间**里按面积比例写（例如"暗块占 26%"）。
实测值存在 `docs/地形/calib.json`。

> 坑：标定读到的是 PNG 里 **sRGB 编码后**的像素，而节点里的场是**线性**值。
> 拿 sRGB 的 0.74 当线性阈值，等于把整层往高处抬了 0.25 —— 大半个画面被夹到 0。
> 现在 calib 里直接换算成线性再打印。

## 五、草簇：圆点永远是"胡椒粒"

第一版用"抖动格点 + White Noise 哈希"撒圆点，调了四轮都不对：

| 做法 | 问题 |
|---|---|
| 普通 Noise 当逐格哈希 | 相邻格心只隔 1/N，噪声在那里是连续的 → 抖动量几乎相同，退化成**规则网格** |
| 换 White Noise 哈希 | 位置随机了，但**圆点本身**读成"波点布 / 胡椒粒" |
| 揉距离场让边毛 | 团块内部被揉出环形亮斑，像"月坑" |
| **改用高频噪声阈值斑块** | ✅ 轮廓不规则、大小不一、成组分布 |

A/B 的三张对照留在 `docs/地形/_试验/`（A 格点团 / B 斑块 15 / C 斑块 24）。
最终取 B 的尺度（16）+ 顶端 4% + 一层 0.22 强度的光晕 —— 光晕让草簇"长在土里"，
而不是贴上去的贴纸。

覆盖率：核心约 4%，含光晕约 12%。这个量在 8 m tile 下等于每 64 m² 有 ~45 团、
每团 10–15 cm。

## 六、6 m → 8 m：重复感是"尺度"问题，不是"对比"问题

第一版 tile 定 6 m。进场景（40 m 视野）后，地面出现明显的**格子节奏** ——
不是接缝，是同一个色块每 6 m 出现一次，眼睛会自动把它连成网。

1. 先把重复感归因到"大色块尺寸 ≈ tile 尺寸"：一块拼图里只有一个完整色块，
   它就成了地标。把色块 scale 从 2.0 提到 4.6（一个 tile 里 4–5 片）后缓解一半。
2. 再把 tile 抬到 8 m：512 px → 64 px/m，特征尺寸同比放大 33%，重复周期拉长。
3. 泥土更极端：它的色差本来就小（3.6%），任何"形状"都会被眼睛抓住。所以泥土的
   大色块进一步压到 ±1.5%，结构全部交给裂纹网络（scale 10.5，胞元 ≈ 0.76 m）。

## 七、8bit 与色带

泥土的明度总跨度只有 7/255，8bit 量化会把柔和渐变压成**宽 40–70 px 的色带**。
实测：加抖动前全图只有 8 个亮度级、最长同色连续 69 px。

解法是标准做法：输出前加 **±0.5 LSB 的随机抖动**（固定种子，可复现）。
幅度 0.4%，肉眼不可见，但把色带边界打散成 1 px 的过渡。加后唯一色数
泥土 26 → 94、草地 143 → 279，色带消失。

> 注意：渲染器的 `dither_intensity` 要设 0（它会自己乱抖），抖动只在我们自己的
> 后处理里做一次，幅度可控。

## 八、渲染管线

| 项 | 设置 | 为什么 |
|---|---|---|
| 相机 | Ortho，ortho_scale 2.0，位置 (0,0,4)，旋转 (0,0,0) | 绝对垂直的 Top View，1 个 tile 正好铺满画面 |
| 地面 | 6×6 平面，**UV 从 −1 到 2** | 画面只取中间 2×2；边缘像素的滤波会采到"外面一圈"，UV 是周期延拓的，所以既不会采到黑底（第一版的暗边），又保持 u=0/1 精确对齐 |
| 光照 | 无灯、世界纯黑、材质 Emission 1.0 | 输出 = 节点颜色，没有阴影可烘，引擎可二次打光 |
| 色彩管理 | Standard / look None / exposure 0 / gamma 1 | AgX 会压暗部、抬饱和，渲出来的颜色就不是节点里的颜色了 |
| 采样 | Cycles CPU 16 spp @1024²，Blackman-Harris 1.5 → 2×2 盒式降采样到 512 | 16×4 = 每输出像素 64 个样本，专治草簇/裂纹的锯齿；同时整体略微柔化，符合"手绘" |
| 输出 | PNG 8bit RGB，compression 30 | 无 alpha；事后剥掉 eXIf / oFFs（有引擎会把 oFFs 当真，图会错位） |

- 只交 Albedo。要更强的立体感得加法线/粗糙度，或在引擎里叠一层细节法线。
- 两张图各自独立，没有"草地↔泥土的过渡带"；混合靠引擎的 splat / 顶点色 /
  贴花，或者另做一张过渡图（下一份工作的自然入口）。
