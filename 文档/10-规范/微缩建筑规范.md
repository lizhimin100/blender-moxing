# 微缩建筑规范 · 联盟通用锚点（1 m 格）

> 这是《战争原岛》联盟建筑的**第二条线**，和 `建模规则.md` 里那批 6 m 级
> "真实尺度"建筑**不共用零件、不共用验收口径**。混用会得到两种比例的怪物。
> v2（2026-11-23）：队色改成染色系统，城镇大厅三档重做，面数区间改为按星级递进。

---

## 0. 一句话

**一格 1.0 m 的沙盘摆件**：底座就是棋盘格，建筑是摆在格子上的小玩具。
判据不是"像不像房子"，而是"缩到 96 px 还能不能一眼认出是哪座"。

## 1. 硬约束（不许商量）

| 项 | 值 | 说明 |
|---|---|---|
| 坐标系 | Z 上、+Y 正面 | 导出后 glTF 正面朝 **−Z**（Godot/three 的约定） |
| 原点 | 底座**底面**正中心 | z=0 必须严格贴地，不许有负 z |
| 底座 | 1.000 × 1.000 × 0.080 | 带倒角，只倒竖边 + 顶边（底面倒角会让建筑"离地"） |
| 主体 | ≤ 0.960 × 0.960 | 含台基、屋檐、旗杆、**台阶**的全部投影 |
| 面数 | 1★ 1000–1450 / 2★ 1450–1900 / 3★ 1900–2450 | 三档递进（**已被 2026-11-24 全局规范覆盖，见 1.1**） |
| 材质槽 | 4 个：`主体` / `team` / `team_trim` / `自发光` | 顶点色驱动，**无 UV、无贴图、无图集** |
| 平滑 | 按角度 32° + Weighted Normal | 倒角面走平滑，大平面保持硬 |

**为什么顶点色而不是色板贴图**：一格建筑 4 个 draw call 已经够低；色板贴图在
mipmap 高层会把所有格子混成一坨平均色，而顶点色在任何距离都是准的。

**面数为什么改了**：旧口径"800–1500 一刀切"的后果是 3★ 反而做不动细节 ——
钟塔、钟室、城垛、门廊一起上就超。三档是同一栋的成长，预算也应该跟着长。
2450 tri / 4 draw call 对同屏主建筑仍然极低（6 m 线那座是 23k）。

### 1.1 面数与槽数：2026-11-24 全局规范覆盖

新的全局锚点（兵营起执行）把两条都收紧了：

| 项 | 新口径 | 说明 |
|---|---|---|
| 面数 | **800–1500 tri / 栋**（城镇大厅放宽到 2000） | 不再按星级递增；三档靠"少而大"而不是"多而碎" |
| 材质槽 | **恰好 2 个**：`Mat_Neutral` / `Mat_TeamColor` | 金/铁烘顶点色；没有自发光槽 |

于是现在有两套并存的资产口径，**别混用**：

| 资产 | 面数 | 槽 | 状态 |
|---|---|---|---|
| 城镇大厅_微缩（v2） | 1,324 / 1,864 / 2,388 | 四槽 | 3★ 超新规 388 tri，列入返工欠账 |
| 兵营_微缩（v1） | 1,214 / 1,466 / 1,454 | 两槽 | 合新规 |

1500 硬线下的造型纪律：**只给承剪影的大体量倒角**（44 tri），箱/靶/人头/石牙一律素盒（12），
重复的竖向件优先砍（3★ 的两座角塔 −228 tri → 垛口端墩 +24 tri）。

### 1.2 两槽制怎么落地（`B(twoslot=True)`）

- `mkit.SLOTS2 / ROLE2 / PAL2_HEX / materials2()` 是新通道，`twoslot=False` 仍走四槽；
  `th_*` 那批资产一个字节没动。
- `Mat_TeamColor` **不接** Color Attribute，队色件顶点色一律写**纯白 1.0**。
  这样 Blender 预览 = GLB 乘完 `COLOR_0` 的结果，换阵营只改一个 `baseColorFactor`。
  代价：队色件没有"瓦暗/瓦亮"的明度微差，屋面层次只能靠瓦垄台阶与光照。
- 3★ 的"微发光"由金脊 / 盾徽 / 桅顶承担，**不做灯**。
- 体检新增第 ⑩ 项：逐个顶点验队色件的顶点色是否为纯白。

## 2. 色板

明度秩序固定：**底座 → 台基 → 墙裙 → 墙 → 压顶 → 木 → 屋面(队色) → 金**，每层只做一件事。

| 角色 | 值 | 用在哪 |
|---|---|---|
| 底座 | `#6D6355` | 棋盘格底座（最暗一档，把建筑从地面抬起来） |
| 台基 | `#8E8371` | 台基、台阶 |
| 石 | `#CFC6B3` | 墙体、塔身（暖白石灰岩） |
| 石亮 | `#E4DCC9` | 压顶、拱券、隅石、钟亭身 |
| 石暗 | `#8C8374` | 墙裙、檐口阴影线 |
| 深橡木 | `#6B4A30` / `#3A2A1C` | 门、梁、博风板 |
| 米白灰泥 | `#E8DFCB` | 山墙、二层 |
| 洞口 | `#221D18` | 窗、门洞（不挖真洞，贴 9 mm 薄板） |
| 冷铁 | `#5A6470` | 灯架 |
| 自发光 | `#FFC173` | 壁灯玻璃 |

### 2.1 队色 = 染色系统（不是"一种蓝色"）

`team` / `team_trim` 两个槽的**顶点色只存灰阶明度遮罩**（0.86–1.0），
真实色相来自**材质的 baseColor**。所以：

- 换阵营 = 改两个材质的颜色（或 GLB 里的 `baseColorFactor`），**模型不重建**；
- 队色只能有一个来源。队色槽**不接** Color Attribute —— 接了就是"顶点色 × 材质色"，
  蓝 × 红 = 泥，换阵营必翻车。

| 阵营 | team | team_trim |
|---|---|---|
| 联盟（默认） | `#2554A8` | `#E4B455` |
| 失落帝国 | `#743A2E` | `#A99578` |
| 中立 | `#4C6B58` | `#B9A87A` |
| 霜誓 | `#2F6F86` | `#CBD6D8` |

整套写进 `assets/建筑/联盟/城镇大厅_微缩/阵营色.json`，预览页 `预览_微缩建筑.html`
底部有四个阵营色按钮可以直接点着换。

**金为什么不是真金属**：metallic 0.82 在弱环境下会把 `#D9A441` 读成脏棕。
微缩件一律走"漆金"——metallic 0.32 / roughness 0.46 / `#E4B455`。

队色面积 **10–22%**（屋面本身就是队色，所以比 6–9% 高）。

## 3. 星级递进（城镇大厅）

高度是**含底座**的总高，必须落在区间内。

| 星 | 高度 | 语法 | 该有什么 |
|---|---|---|---|
| 1★ | 0.60–0.80 | 单一体量 + 脊上钟亭 | 蓝瓦顶、拱门、钟面、一对挂旗、公告板 |
| 2★ | 0.90–1.10 | 加前凸体量，塔穿屋顶 | 竖脊山花 + 盾徽、钟塔、扶壁、隅石 |
| 3★ | 1.20–1.50 | 双层退台 + 城垛露台 | 门廊山花、钟室（看得见钟）、金尖顶、灯 |

**市政身份只有四件东西撑得住：钟面、拱门、蓝瓦、挂旗。**
1★ 可以小，这四件一件都不能少 —— 少了就是民房。

**递进必须改语法，不是加零件**：1★ 是"一栋房子 + 脊上的亭"，2★ 是"前凸体量 + 穿顶的塔"，
3★ 是"两层退台 + 露台 + 塔"。三档放在一起缩到 96 px 也要能排出顺序。

## 4. 面数账（背下来再动手）

| 件 | tri | 备注 |
|---|---|---|
| 素盒 | 12 | 装饰条、垛口、台阶、门扇 |
| 倒角盒（1 段） | 44 | 只给"承剪影"的体量：墙、塔身、台基、角楼 |
| 倒角盒（2 段） | 108 | 只在主角件上用，一般不用 |
| 四边板 | 12 | 窗、箭孔、贴面 |
| 拱板（6 段） | 32 | 门洞（**只有主角建筑的入口值这个钱**） |
| 八边柱 / 锥 | 28 / 16 | 角楼、尖顶 |
| 叠瓦（一道） | 12 | 每坡 4–5 道，共 96–120 |

一栋 1800 tri 的房子大约 = 10 个倒角体量 + 60 个素盒 + 8 个窗 + 1 个门 + 10 道瓦。

## 5. 零件库 `blender/bs_v7/mkit.py`

```
B.base()                    # 1.0×1.0×0.08 底座（只倒竖边+顶边）
B.plinth(w,d,h,z0)          # 台基
B.box(name,w,d,h,z0,role,bevel,mode)   # 通用盒，mode: all/no_bottom/top/vertical
B.cyl / B.cone / B.pyramid  # 棱柱 / 锥 / 方锥
B.roof_tiled(w,d,z0,z1,n)   # 瓦垄屋顶：三棱柱 + 每坡 n 道叠瓦（top_gap 让给脊压顶）
B.roof_gable / roof_gable_y / roof_hip
B.plate(pts,thick,axis)     # 任意多边形挤出
B.disc(r,at,axis)           # 正多边形盘（钟面）
B.slab4(pts,thick)          # 四点单坡（披屋 / 坡道）
B.beam(p0,p1,w,t)           # 两点方料
B.cornice(w,d,z0,grow,h)    # 檐口：一级暗影 + 一级亮压顶
B.quoin(w,d,z0,h,t)         # 隅石（四角竖条）
B.arch_plate(w,h,thick)     # 拱形薄板（门洞/钟窗）
B.window(w,h,at,lintel,sill)
B.steps(w,n,z0,z1,y0,y1)    # 正面台阶，**从台基边往前长**
B.clock(r,at,axis)          # 钟面：金圈 + 米白盘 + 两根指针
B.bell(r,h,z0,at,sides,sub) # 钟（钟口在下），sub=1 走细分
B.lantern(at,z)             # 壁灯（唯一暖光点）
B.timber(...)               # 半木构
B.banner / shield / flag / merlons
B.part(..., sub=1)          # 低模控制笼 + Catmull-Clark 一级（只给回转件）
```

兵营起补的组件（都在 `bk_model.py`，不在 mkit 里，避免污染四槽线）：

```
log_hall / stone_hall    原木营房 / 石砌体量（可关台基、墙裙、隅石）
watch_top(w,d,z,at=)     望楼顶：木挑台 + 石垛口（**必须传 at**）
mast                     旗桅 + 长三角军旗（替代尖顶的竖向度）
rack / dummy / tent      武器架 / 训练木人 / 蓝白帐篷
banner / wall_banner     立旗 / 墙面挂旗
plaque                   金剑盾牌匾（盾在下、剑穿盾、护手横心）
door(detail=0/1)         门洞 / 门扇 / 暗石门框 / 铁箍
```

`B.info` 记录每个零件的包围盒、槽位、面积、细分标记；`join()` 之后仍可体检。
`B.team_area()` / `B.soft_ratio()` 直接给队色占比与细分占比。

**细分只给该圆的地方**：钟、顶饰、木桶这类回转件走 `sub=1`；墙、屋面、
石板一律硬边。低模线里全身上细分 = 面团。占比硬指标 ≤ 20%。

## 6. 验收（`th_check.py` 九项 / `bk_check.py` 十项，不靠截图）

① `grounded` min z == 0　② 主体 ≤0.48 半径　③ 总高在星级区间　④ 面数在区间
⑤ `COPLANAR_UP`：两个零件的**朝上受影面**同高且 XY 重叠 > 4 mm²（斜构件不算）
⑥ `FLOAT`：零件与所有其他零件的 AABB 都不接触（2 mm 容差）
⑦ `TEAM_AREA` ≥ 10%　⑧ `SOFT_RATIO` ≤ 20%　⑨ 材质槽恰好 4 个

两槽制的 `bk_check` 把 ⑨ 换成"恰好 2 槽：Mat_Neutral / Mat_TeamColor"，并加 ⑩ 队色顶点纯净。

导出后还要验 GLB：`COLOR_0` 存在、材质名与槽数对、三角面数与体检一致、
队色 `baseColorFactor` 等于阵营色（`th_export.py` / `bk_export.py` 直接解 GLB 的 JSON 块）。

## 7. 这一轮踩出来的坑

1. **AABB 取景会多留 20% 空白**。取景和图标裁切都要用**真实顶点**。
2. **`merlons()` 忘传 `at`** → 整圈垛口全落在原点。
3. **13 cm 的二层会被 5 cm 出檐整个吃掉**（36° 俯角下）。层级靠"体量差"，不靠"多切一刀"。
4. **锥顶小塔离墙角 0.1 m 就变"杆子"**。角楼要么咬进转角 6 cm，要么别做。
5. **浅石墙 + 浅背景 = 建筑消失**。图标地面压到 0.36 反照率，建筑才浮出来。
6. **卡牌上的硬地平线会让建筑"悬空"**。改成舞台光池（无分界线）+ 铺满底座的投影。
7. **门廊用横脊双坡会读成"斜雨棚"**。必须用竖脊 + 三角山花。
8. **贴面件中心必须在墙面之外**：盾徽挂到门廊后面等于没做。
9. **glTF 正面朝 −Z**。预览机位放 +Z 会看到背面。
10. **`shade_smooth_by_angle`** 在 Blender 5.2 可用；配合 Weighted Normal 的 `keep_sharp`。
11. **台阶全被台基埋掉**。`steps()` 的每一级必须**从台基边往前长**；
    以中点居中会让最前一级多探出 `tread*(n-1)/2`，直接顶出 1 m 底座。
    台基还要比台阶**浅**，否则整段楼梯在实体内部，只剩一条白线。
12. **指针埋进钟面里 = 一个黑洞**。指针必须画在盘面**之前** 6 mm；盘面用米白、
    指针用近黑 —— 深盘 + 金针在 512 px 上读不出来。
13. **挂旗中间折一道会读成纸飞机**。1 m 尺度上布不需要褶，需要干净的梯形 + 底边金边。
14. **方条屋脊在 45° 屋面上必然两端翘起**：它的底边是水平的，屋面在往下走。
    脊压顶必须做成**与屋面同坡**的小三棱柱；瓦垄还要在脊前 5.5% 收住，
    把最后一段让给压顶。
15. **metallic 0.82 的金 = 脏棕**。弱环境下金属没有可反射的东西，改"漆金"。
16. **细分面数要算真账**：`B.info` 里的 tri 是控制笼的，`B.actual` 才是细分后的；
    体检必须用后者，否则 SOFT_RATIO 会少算四倍。
