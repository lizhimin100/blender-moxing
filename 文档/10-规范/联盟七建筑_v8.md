## 0. 一句话

**在 1 m 见方的棋盘格上，用 800–1500 个三角面，做出一眼能认出阵营与功能的微缩要塞。**
判据不是"像不像房子"，而是三张图：96 px 缩略、512 图标、3/4 俯视同框。

## 1. 五条硬约束（体检逐条判）

| 项 | 值 |
|---|---|
| 底座 | `1.000 × 1.000 × 0.080`，原点在底面正中心，只倒竖边 + 顶边 |
| 主体 | 非底座零件 `|x|,|y| ≤ 0.470`（0.94 见方） |
| 高度 | 非塔 1★ 0.58–0.74 / 2★ 0.74–0.90 / 3★ **0.85–1.10**；塔 1★ 0.90–1.05 / 2★ 1.08–1.24 / 3★ **1.25–1.45** |
| 面数 | 800–1500 / 栋（城镇大厅 3★ 放宽到 2000） |
| 材质槽 | 恰好 2 个：`Mat_Neutral`（顶点色）/ `Mat_TeamColor`（baseColor） |

**队色面积**：非塔 ≥7%，塔 ≥4.5%，上限 34%（可见面积口径，见 §5）。
数字偏低不等于做错 —— 平顶军事建筑（兵营 1★）天生只有屋顶和旗能上色。

## 2. 星级递进：只准变宽变厚

用户点名的病是"2★→3★ 把中间方块拔高，比例失调"。这一版把它写成可执行的规矩：

| 星 | 占地（线性） | 高度增量 | 语法变化 |
|---|---|---|---|
| 1★ | 0.60–0.72 | — | 单一体量 + 一个母题 |
| 2★ | 0.78–0.85 | +0.10 ~ +0.22 | **加翼楼 / 角楼 / 半层**，材质从木到石 |
| 3★ | 0.90–0.94 | +0.08 ~ +0.14 | **加第二、第三体量**，垛口 / 塔 / 徽章 |

实测七座（占地 = 非底座零件的 XY 跨度）：

| 建筑 | 1★ | 2★ | 3★ | 3★ 高 |
|---|---|---|---|---|
| 城镇大厅 | 0.75 | 0.83 | 0.92 | 0.989 |
| 兵营 | 0.75 | 0.80 | 0.93 | 0.966 |
| 农场 | 0.70 | 0.82 | 0.92 | 0.955 |
| 铁匠铺 | 0.70 | 0.82 | 0.92 | 0.970 |
| 伐木场 | 0.70 | 0.82 | 0.90 | 1.012 |
| 哨塔 | 0.64 | 0.72 | 0.86 | 1.368 |
| 箭塔 | 0.66 | 0.76 | 0.86 | 1.386 |

**3★ 只在 1★ 基础上高 0.28–0.37，宽度涨 0.22–0.26。**
换句话说：3★ 的体积增长里，约 2/3 来自占地，1/3 来自高度。

## 3. 两槽制：队色是"染色系统"，不是"一种蓝"

- `Mat_Neutral` 走**顶点色**（无 UV、无贴图）：石 / 木 / 灰泥 / 金 / 铁 / 麦 / 炉火。
- `Mat_TeamColor` 走 **baseColorFactor**，默认 `#2554A8`，**不接** Color Attribute。
  队色件顶点色一律纯白（`T100`），否则换阵营时会"蓝 × 灰 = 泥"。
- 换阵营 = 改一个 `baseColorFactor`，模型不重建。四套阵营色见各资产目录的 `阵营色.json`。

**队色只能出现在这五处**：屋瓦、旗帜、盾面、遮阳棚/门棚、徽章底板。
不许把石头刷蓝 —— 那不是队色，是把建筑变成蓝精灵。

## 4. 七座的语法（一座一种，不许混）

### 城镇大厅 — 从市政厅到四方围合城堡
`市政厅 → 主城 Keep → 城堡`
1★ 半木构 + 厚蓝瓦顶 + 石阶门廊 + 脊上矮钟亭；2★ L 型石砌 + 前左角楼 + 竖脊门楼；
3★ 四角塔 + 幕墙 + 中央大厅 + 门楼 + 金脊。
**市政四件**：钟面、拱门、蓝瓦、挂旗。1★ 可以小，四件一件不能少。
3★ 的四塔用**矮锥顶**（高 0.076 / 底 0.21 = 1:2.8）：锯齿垛口 ×4 会连成一排白牙。

### 兵营 — 重型石砌拱门要塞
`木石营棚 → 石砌营房 → 皇家要塞`
**正立面永远没有三角屋顶**，只有"墙 + 拱门 + 垛口"。
1★ 矮营棚 + 夸张的半圆拱（0.24 宽）+ 平顶垛口 + 木栏；
2★ 石砌 + 拱门两侧阶梯扶壁 + 后半层蓝瓦军械库；
3★ 双层城门楼 + 双哨堡（蓝锥顶）+ 铁栅 + 金交叉剑盾徽。
**门洞必须比窗大三倍**；前庭**留空**（空地才是演武场）。

### 农场 — 大坡谷仓 + 筒仓 + 风车叶
`农舍 → 谷仓农场 → 风车农场`
3★ 的最高点必须是**风车塔**，不是筒仓。风车四叶是 96 px 的识别件，叶宽 ≥0.04。

### 铁匠铺 — 炉火 + 烟囱 + 铁砧
`敞棚铁铺 → 石砌铁铺 → 大师工坊`
识别件优先级：**橙红炉口 > 烟囱 > 铁砧徽章**。炉口必须做在正面明处，
周围压一圈炭色 —— 两槽制没有自发光，炉火的"亮"靠满饱和的 `#FF6A20` 对撞深炭。

### 伐木场 — 圆锯片 + 原木堆
`敞棚锯木 → 石基磨坊 → 吊木工场`
**圆锯片直径 ≥0.15、露出的面积 ≥半个圆**，挂在正面挑出的木架上。
吊木扒杆放侧后，别挡正立面 —— 挡了就读成脚手架。

### 哨塔 — 木构瞭望，越往上越轻
`木构哨塔 → 石基哨塔 → 石砌哨塔`
**栏杆、立柱、地板三件必须能看见**。屋顶只做四坡矮顶、出挑 ≤0.03，抬高到栏杆之上，
否则整座塔读成"桌子 + 大帽子"。3★ = 石塔 + 挑石垛口 + 木构瞭望室 + 矮四坡顶。

### 箭塔 — 全石矮壮 + 斗堡 + 弩炮
`石砌箭塔 → 双耳箭塔 → 皇家箭塔`
**斗堡进深 ≤0.05、高度 ≤0.11、必须有 3 根斜撑**，否则读成"挂在墙上的木箱"。
3★ 的四角小塔必须**外挑**（带托石），放在垛口里面会变成"平台上的四顶帽子"。

## 5. 验收（`a_check.py` 十三项，不靠截图）

① 落地 min z=0　② 底座 1.000×1.000×0.080　③ 主体 ≤0.470 半径
④ 高度在窗口内　⑤ 面数 800–1500（城镇大厅 3★ ≤2000）
⑥ `COPLANAR_UP`：两个零件朝上受影面同高且 XY 重叠 >4 mm²
⑦ `FLOAT`：与所有其他零件 AABB 都不接触（2 mm 容差）
⑧ 队色可见面积 7%/4.5%–34%　⑨ 恰好 2 槽
⑩ 队色件顶点色全白　⑪ 细分占比 ≤20%
⑫ 同建筑 1★<2★<3★ 严格递增且每档 ≥0.04　⑬ 3★ 占地 ≥1★ + 0.12

**队色面积用"可见面积"口径**：排除朝下的面。v7 的 `team_area()` 把底座 1 m² 的
底面也算进分母，平顶建筑天生只有 7%，看不出问题出在算法还是造型。

导出后再验 GLB：`COLOR_0` 全存在、材质名恰好两个、三角面数与体检一致、
`Mat_TeamColor` 的 `baseColorFactor` 等于阵营色（`a_export.py` 直接解 JSON 块）。

|---|---|---|
| 素盒 | 12 | 垛口、台阶、门扇、栏杆 |
| 倒角盒（1 段） | 44 | 只给承剪影的体量：墙、塔身、台基、角楼 |
| 拱板（7 段） | 24 | 拱门洞 / 拱圈 |
| 六边盾 | 20/面 | 3 件一套 ≈56 |
| 瓦垄一道 | 12 | 每坡 3–5 道 |
| 锥顶 / 四坡 | 6 / 8 | 角塔、筒仓 |
| 塔身（带基/腰/托/垛） | 116 | 角塔的完整一套 |

**1500 硬线下的三条纪律**：
1. 只给承剪影的大体量倒角；
2. 看不见的背面不做装饰（后墙不挂旗、后角不做隅石）；
3. 被别的体量完全遮住的墙，不做台基/檐口（兵营 3★ 的后营房省 160 tri）。

## 8. 这一轮踩出来的坑

1. **`ob.location` 改完不 update 视图层** → `matrix_world` 还是旧的，三阶同框的取景
   按"三座都在原点"算，结果一座被切掉、右边一大片空。必须 `view_layer.update()`。
2. **相机在 +X/+Y 侧时，+X 是屏幕左边**。同框要"从左到右 1→2→3"，1★ 得放 +1.5。
3. **垛口转角共面**：相邻两面的垛宽取到段长的 56% 时，顶面在转角相交。
   取 44%，缝留出来，剪影还更"齿"。
4. **拱心石与拱圈顶点共面**：拱圈是多段折线，最高那条横棱是水平面；
   石顶必须比它高 8 mm。
5. **窗板悬空**：调用方传"墙面 + 8 mm"、板厚只有 9 mm，背后空 3.5 mm。
   把偏移收进 `win()` 内部，对外只暴露"墙面"一个概念。
6. **`pyramid_roof` 的檐板顶面 = 塔顶面** → 共面。檐板要比塔顶低/高 2 mm 以上。
7. **`mkit.cyl` 只能立着长**：`rotz` 转的是截面多边形，不是轴。
   横放原木必须自己放样（`log_axis`，28 tri）。
8. **风车叶不能用"建完再转 obj.matrix_world"**：只有最后一片被转到。角点直接在
   平面里算。
9. **铁栅后面没有木门扇 = 窗棂**。深洞 + 规则铁格，人眼只会读成窗。
10. **平顶建筑队色天生低**：底座 1 m² 的中性面积把比例稀释掉一半。
    要么用可见面积口径，要么认账（下限 7%），别把石头刷蓝。
11. **兵营的正面一旦出现三角屋顶就变民房**，加多少长矛都救不回来。
12. **斗堡（木构射击廊）进深超过 0.05 就变"挂在墙上的木箱"**。
13. **角塔放在被屋顶挡住的后角 = 白做**。2★ 的角楼必须站在正立面这一侧。
