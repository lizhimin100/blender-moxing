## 1. 升级态：**"不是砍掉，是还在长"**

统一配方（`st_upgrade.py::run_upgrade`）：

```
旧等级主体 → 按世界 z 截断（逐件 ±0.10 抖动）→ 断口补"生料面" → 碎料 + 露明梁
          → 静态工地套件（cs_kit 几何固定摆好）→ 少量新等级暗示件（hint_*）
```

四条硬经验：

1. **截断位置要落在"结构层"上**，不是随便一个高度。哨塔切在 10.55 —— 上段木构的腰上
   （8.16–11.16 的中段）。切在挑台上沿会得到一个"桌面"，读成"屋顶被拆了"；
   切在木构腰上才有"这根柱子还要再长一截"的意思，断口也是木头的生料色。
2. **断口必须补面**。不补 = 从 38° 俯角一眼看到地面（空心建筑没有深度线索）。
   `st_kit._cap_face` 在每个构件的切口补一张 n 边形（生料材质），
   `st_kit.interior_deck` 再在断口下方 0.38 补一块暗楼板，`cap_joists` 压一排露明梁。
   大厅升级1 第一版没有梁，8 m 的封面读成"平屋顶"；加上梁之后俯视立刻变成"结构外露"。
3. **脚手架围到断口之上一点点**（那是下一步的作业面），但绝不高过原建筑总高。
   层数 = `clamp(round((截断+1.2)/2.2), 3, 6)`，矮建筑手降到 2 步。
4. **暗示件只做一处**。哨塔是"下一等级的屋面骨架"（四根不等高角柱 + 脊梁 + 两面坡的椽，
   队色漆线一道）；大厅是"塔楼底座 + 半砌的女墙"；帐篷是"加长的脊杆 + 卷起的帆布"。
   一多就变成"另一座建筑"，看不出是同一座在建。

**不做箭饰**：工单原写"哨塔顶部露箭饰暗示"，第一版照做了一根铁箭，实际读作"已经装好的冠饰"，
和"还在施工"矛盾，按最新意见撤掉，改成屋面骨架（`docs/状态资产/哨塔_升级/` 里有那一版的历史）。

## 2. 训练态：**门开着 + 门里有灯 + 一个识别效果**

- **门扇绕自己的铰链轴转**（`st_fx.open_doors`）：左右扇按 x 的正负分组，铰链取该扇
  包围盒的外侧竖边，整体转 108–118°。不是"换一扇新门"，门与门框的销子那条边因此保留。
- **门内自发光**走 `自发光` 材质槽（图集里的 `door_light` 格，强度 2.10，
  比 `glow` 亮一档 —— 用 `glow` 在白天光下读成"一块浅色漆板"）。
- **门口光斑**是 2 cm 厚的一片自发光板，压在门槛石上。**不做体积光**：
  glTF 里没有可靠的体积散射，引擎侧不认，烘成几何又会让面数翻倍。
- 各座的识别效果：
  | 建筑 | 门 | 识别效果 |
  |---|---|---|
  | 城镇大厅 | 双开木门 112° | 门洞整片暖光 + 门槛光斑 + 门套一对灯笼 |
  | 兵营 | 双开木门 118° | 武器架两道灯笼 + 四支矛尖亮点 + 架下光斑 |
  | 神秘圣地 | **不转门板**（门是一整块发光门） | 台阶上的光斑 + 两侧灯柱（队色顶） |
  | 蒸汽车坊 | 双开铁门 108° | 门洞暖光 + 门内光斑 + 阀轮转 90° |

> 圣地的"门"不是门扇，是 `portal_glass` 一整块发光门 —— 强行转门板会把它撕成两半，
> 所以训练态改成"门前台阶被照亮"。这条写进代码注释了。

## 3. 科研态：**一根骨架 + 一条 clip**

- 只给运动件绑骨（火焰 / 烟 / 锤 / 锯轮 / 锯条 / 原木 / 锯末），其余顶点不进任何骨；
  一根骨架 = 一条 Action = **一条 clip**（多对象各挂一个 Action 会被导出成
  `research`、`research.001`…，引擎侧还要自己拼）。
- clip 规格：`research`，30 fps、60 帧 = 2.0 s，**首末一致**。
  判据在 `st_kit.glb_clips`：直接读 GLB 的 JSON + 二进制块，逐通道比首末采样值；
  旋转按"同一朝向"判（q 与 −q 等价，`|dot| ≥ 1−1e-3`），其余按数值相等。

| 建筑 | 骨 | 动作 |
|---|---|---|
| 铁匠铺 | flame / smoke0–2 / hammer | 火焰 scale 0.55→1.06 呼吸；三团烟错相位上升（两端 scale 0 归位）；锤子两次敲砧（抬 −34°→落） |
| 伐木场 | saw_wheel / saw_blade / beam / dust0–3 | 锯轮匀速 2 圈（每 45° 一个键，四元数才不走近路）；锯条上下 2 个往复；原木推进 0.24 m 再退回；锯末 4 粒分两班落下 |

粒子 / 辉光（火星、烟尘的柔边）走引擎侧，与 `docs/建造系统/Godot接入.md` 的分工一致。

## 4. 二本城镇大厅（`keep_model.py`）

- **为什么不是"v3 加高一层"**：v3 高:宽 = 1.39（窄高市政厅 + 钟塔），二本 0.66（压扁加宽的戍堡）。
  两座摆在一起，俯视一眼分得出"升级了"。
- 形体：11.20 × 8.60 主体；石砌 0.55–5.95 / 木框 5.95–9.20（竖挺 + 石角柱）/
  女儿墙 9.40–10.42（成组垛口）/ 中央方塔 4.80 见方到 12.55 + 两级截头金字塔到 **15.71**；
  两座前角楼 2.44 见方、跨在转角上，各带两级小金字塔顶（12.84）。
- 门：2.70 宽、拱顶 4.60、门廊出挑 1.55，双扇铁包木门 + 门楣铁箍 + 闸门齿。
- **屋顶语法**：两级截头金字塔（全项目第一次）。第一版做过 4 级阶梯台，
  在 RTS 距离上读成"婚礼蛋糕"（每级一条水平亮线），换掉。
- 落地：`_低模.glb` / `.glb` / 手游三档 / `.blend`（4 材质，贴图已打包）/ `_建造.glb` / 图标。
- 改高度必须重测：阵营色（队色只染门楣横带 + 塔身女儿墙一道 + 门套壁柱 + 两幅垂旗）。

## 6. 这一轮踩到的坑（写进 `docs/10-规范/建模规则.md` 候选）

1. **`matrix_world` 是上一帧的缓存**。`beam()` / `taper_box()` 造的构件"网格在原点、
   靠 transform 摆位"，刚建完读 `matrix_world` 还是单位矩阵 —— 按它烘平移会把斜撑按原点烘平，
   截断时它们"整根保留"，最后 4 根山墙斜撑原封不动穿在断面上。
   **动刀之前先 `bpy.context.view_layer.update()`**。
2. **凸包封面会盖出"平屋顶"**。空心建筑截断后，每个构件的凸包封面加起来是一整块平面；
   必须在断口下补暗楼板 + 压露明梁，否则读成"这栋楼是平顶的"。
3. **绕世界原点转 = 甩到地下**。阀轮辐条绕原点转 90°，z 直接 −3.77，grounded 判失败。
   要绕"零件自己的中心"转，中心从该组顶点算。
4. **骨位必须在 finalize 之前算**。finalize 会 join 掉 items 里的对象，之后读包围盒
   就是 `StructRNA removed`。
5. **矮建筑的脚手架**：一步架 = 2.75 m，比 2.30 m 的初级帐篷还高。`cs_kit` 现在对
   H < 2.9 的建筑不接顶层 0.55、不加护栏、挡脚板下压 6 cm（`SCAF_OVER` 0.015 → 0）。
   这条判据用 **H** 而不是"是否顶层"，否则多层架的中层挡脚板会整体下沉 12 cm。
6. **状态档用独立图集**（`st_atlas.STATE_LAYOUT`，5×8 / 512² / 内缩 22，39 格）。
   不往 `bs_atlas.ATLAS_ORDER` 末尾追加，是因为建筑图集 45 格只剩 2 格，
   加 10 个材质要扩行 → 按规则 N120 必须"重生成图集 + 重导 GLB"成对执行，
   等于把九座已交付资产全部重出。状态档自己一份 PNG，旧图集一个字节没动。
7. **导入器会造一个 Icosphere 占位件**（不在 GLB 里，z −1..1）。回查时只统计
   "有材质的网格"，否则 grounded 永远失败。
