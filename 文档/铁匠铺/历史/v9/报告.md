# 铁匠铺 v9 · 错位 / 穿模清理与门廊翼重定尺

> 反馈两条：①图一里 y 轴的旗帜和部分建筑重叠，x 轴看还是重叠；②图二那处还是错位或穿模。
> 这一轮不加新特征，只把"看起来不对"的地方按结构修掉，并给出一套可复跑的体检口径。

---

## 0. 一句话结论

两处反馈都是**同一个毛病：构件被放进了别的构件的体积里**，不是精度问题，是尺寸算错。

| | v8.9 | v9 |
|---|---|---|
| 旗帜 | 旗杆在封檐板厚度内（y 与板心重合、z 在梁里） | L 形铁吊架吊在梁下 0.375 m，布面外移 0.13 m |
| 门廊翼窗楣 | 1.34 m 宽放在山墙只剩 0.50 m 宽的高度 → 两端悬空 | 收到 0.82 m、降 0.76 m，落在三角形内 |
| 烟囱胸墙 | 5.28 **低于**坡棚板后端 5.58 → 屋面从墙顶冒出 | 5.72 + 压顶，彻底盖住 |
| 悬空构件 | 7 处 | **0 处** |
| 可见共面（z-fighting） | 4 类 | **0 类**（余下为朝下/朝内的叠放面，不可见） |

## 1. 两条反馈的根因

### ① 旗帜"和部分建筑重叠"（两个轴都重叠）

v8 的 `banner()` 把旗杆画在 `anchor.z + 0.16`，而檐梁中心在 `can_z(CAN_Y1) − 0.16`、梁高 0.28：

```
梁底 3.72 ────────────────
旗杆 3.635–3.705  ← 整根埋在梁里（只露出两端各 0.1 m）
旗布顶 3.72       ← 与梁底共面
封檐板 5.965–6.115（y 方向）
旗布 5.93–5.99    ← 整幅嵌在封檐板里
```

所以正视看到的是"旗从蓝色檐带里长出来"，侧视看到的是"布和板在同一空间"——**两个轴都重叠**，因为它在 y 和 z 两个方向都嵌进去了。

另外左旗 x 从 −1.98 起，而门廊翼的坡屋面到 −1.78 —— 布的左缘扎进翼屋面 0.20 m。

**修法**：改成 L 形铁吊架（竖杆 0.25 + 横臂 0.28），旗杆吊在臂端，布面比封檐板前表面外 0.155。
旗顶 3.345、梁底 3.72，中间露出 0.375 m 的木梁与铁件 —— 这才读得出"挂着"。

### ② 图二那块"蓝片"：一块悬空的窗楣

**定位过程**（这轮新增的手段）：先按截图机位渲一张，再用 `ray_cast` 从像素反算世界射线，命中对象：

```
(540, 440) → wing_win_lintel  at (3.60, 5.46, 5.37)
```

`wing_win_lintel` 是门廊翼山墙窗上的阵营色过梁，宽 1.34 m、中心 z 5.32。
而门廊翼山墙是个三角形：底 2.46 m、脊 5.78、坡度 2.03 ——

```
山墙在 z=5.32 处的半宽 = (5.78 − 5.32) / 2.03 × 1.23 = 0.25 m
窗楣半宽 = 0.67 m   →  两端各超出山墙 0.42 m，悬在坡面之外
```

同一高度上的**窗拱圈**（外径 0.60）也超出（山墙半宽 0.25），只是被窗楣挡住没看见。

**修法**：窗从 0.92×0.86 收到 0.56×0.62（拱圈顶 4.44），窗楣从 1.34 收到 0.82 并降到 4.56，
山墙在 4.56 处半宽 0.72，窗口、拱圈、窗楣三者都落在三角形内，两侧各留 0.36 m 石墙。

**顺带挖出第二个 bug**：`extrude("wing_win", …, origin=(cx, 0.0))` —— origin 的 v 传了 0，
整块窗玻璃一直贴在地面上（窗洞里永远是石墙，所以 v8 的门廊窗是暗的）。改成 `(cx, wz)` 之后窗才透光。

### ③ 附带：门廊翼与主屋面的"相切"

翼脊 5.78，主屋面在 x=2.93 处也正好 5.78 —— 两个坡面**相切**，视口里会闪。
把翼脊抬到 6.02，成为明确的 cross gable（凸出主屋面 0.24），交线变清楚。

## 2. 这轮新增的体检口径（`blender/bs_v6/bs_align.py`）

| 检查 | 判据 | 抓什么 |
|---|---|---|
| **CLIP** | 两构件的三角形相交（BVH.overlap） | 常规穿模 |
| **CONTAIN** | A 的世界包围盒整个落在 B 内（留 5 mm） | **完全埋进去**（BVH 查不出，比如旗杆埋在梁里） |
| **COPLANAR** | 同向轴向面、平面距 < 4 mm、投影重叠 > 0.02 m² | z-fighting / 闪面 |
| **FLOAT** | 构件包围盒与其它任何构件都不相交（5 mm 容差、排除落地件） | 悬空件 |

结果（v9 最终）：

```
ITEMS 512      CLIP_CROSS 422     CONTAIN 76     COPLANAR 231     FLOAT 0
```

**422 条 cross 相交全部是结构性叠压**，逐类列在 README 第 5 节：道具落地、半木构嵌墙、瓦垄压屋面、
铁箍套筒身、烟管穿棚、楼阁底座埋入屋面、cross gable 封边压坡面、纹章贴附。
判据是"能不能从外面看见两个面互相插进去"——看不见就不算错位。

**COPLANAR 231** 里绝大多数是**朝下或朝内**的叠放面（基座底面/楼层之间/墙内），不可见。
这一轮修掉的是 4 类**朝外可见**的共面：

| 共面 | 修法 |
|---|---|
| `collar` ↔ `vent_post`（都在 y=2.985 前表面） | 立柱前移 10 mm |
| `wing_mass` ↔ `wing_roof`（都在 y=5.44 山墙前表面） | 屋面端面缩进 20 mm |
| `bay_wall` ↔ `bay_face`（都在 y=5.30 龛正面） | 侧墙端面缩进 20 mm |
| `yard_band` ↔ `yard_joint`（差 2 mm，石缝整个被盖住） | 石缝抬到 0.287，压在石带之上 |

## 6. 第二轮反馈：同一处还错位 + 屋顶上那块橙色

### 6.1 那处"错位"到底是什么

第一版把翼脊抬到 6.02（比主屋面高 0.24），想做 cross gable。但翼的坡度是 2.03、主屋面是 1.0125，
两条斜线的交点离翼脊只有 0.08 m：

```
翼屋面  z = 6.02 − 2.03·|x − 2.93|
主屋面  z = 8.75 − 1.0125·x
交点    x = 2.853（左） / 3.165（右）  →  凸出宽度 0.077 / 0.235 m
```

**凸出来的不是"山墙"，是 0.08 m 宽的一条刀刃**。再加上翼屋面与主屋面同材质，交界处就是
"一块板插进去又翘起来"的观感 —— 看起来像错位，本质是"凸得太薄"。

### 6.2 改法：让翼屋面根本不进主屋面

主屋面的前檐在 y = 3.34（YF + OV）。翼屋面原来从 y = 2.90 起，于是它在 2.90–3.34 这 0.44 m 里
和主屋面叠在一起。把翼屋面改从 **y = 3.40** 起步 —— 两者**完全不重叠**，没有穿插，也就没有刀刃。

留下的 0.06 m 缝用一条与翼屋面同色的填缝条（`wing_gutter`，沿翼坡走向、随坡旋转）填实。
不填的话缝里会露出翼体块的石顶 —— 一条白线，仍然像错位。

### 6.3 顺带：两块屋面同色，交界线读不出来

翼屋面原本和主屋面同为 `roof`，3/4 视角下两个体量糊成一片。改成：

| | 材质 | 读法 |
|---|---|---|
| 主屋面 | `roof` #363B46 | 大屋顶 |
| 翼屋面 | `roof_edge` #232730（深一档） | 前廊的小屋顶 |
| 翼屋面的瓦垄 | `roof`（浅一档） | 小屋面上能看出瓦 |
| 作业坡棚 | `roof_wood` #7A5B3C | 作坊的木板棚 |

三个屋面三种色，交接处还有木封边（`wing_barge`）压着。

### 6.4 屋顶上那块橙色：是"排烟天窗"的发光顶盖

v8.9 为了俯视识别，在炉子正上方开了 1.04 × 0.86 的铁框天窗，内膛用 `ember` 发光。
正面看就是一块橙板 —— **分不清是铁还是火**，这个细节失败了。

改成 **铁制排烟口基座**：铁框 0.88 × 0.78 × 0.22 + 暗底（`coal`）+ 四角铆钉，烟管从中间穿出，
不发光。另外给 2.1 m 长的黑烟管加了两道铁箍，让它读成"烟囱"而不是"一根杆"。

> 代价：俯视角少了一个橙色高光点。但炉口、砧面锻件、门缝都有暖光，识别不缺这一个。

## 7. 还没有做的

1. **主屋面没有真的给 cross gable 开洞**。用的是"y 向错位避让"：翼屋面从 3.40 起、主屋面前檐到 3.34，
   两者不重叠，再用一条同色填缝条填掉 0.06 的缝。从俯视能看到那条填缝条（一条比翼屋面略亮的窄条），
   不是洞口的泛水。真要开洞得把主屋面切成非矩形。
2. **翼山墙的窗偏小**（0.56 × 0.62）。这是山墙三角形在 5.0 以上只剩 0.5 m 宽的硬约束下能做的最大的窗；
   想放大就得把翼的坡度放缓，那是形体级改动。
3. **旗帜仍然是"垂直面"**，45° 俯视下会被压扁成两条竖线。阵营色的俯视识别靠檐口压条和烟囱箍承担。
