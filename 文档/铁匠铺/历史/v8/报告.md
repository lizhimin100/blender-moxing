# 铁匠铺 v8 · 本轮交付说明

> **这一轮只解决一件事：让它在 RTS 俯视角里一眼是"铁匠铺"，而不是"带烟囱的民房"。**
> 做法仍然是"几何即代码"：Blender 里跑 Python 参数化建模 → 低模 / 曲面细分两版 → **一个导出出口**。
> 全程不依赖贴图（16 个纯色 PBR 材质 + 2 个阵营色材质），但**拓扑与 UV 按可上贴图的标准做**。

## 2. 屋顶：从"一个双坡"到"一组屋脊构件"

### 2.1 轮廓上现在有四层

```
                 ▲ 脊端铁砧立饰（铁, 0.72 m）
        ┌────────┴────────┐
        │  脊上楼阁        │  ← 四面百叶排烟阁 + 铁压顶 + 尖顶（脊上 +1.9 m）
    ────┤  主山墙 45.4°   ├────          山墙内：木构 + 大百叶通风口
        │                  │  ← 屋脊 8.75 m
   ┌────┴───┐  ┌───────────┴────┐
   │ 门廊翼  │  │ 独立作业坡棚 27° │  ← 4.16 m 宽 / 3.0 m 出挑 / 前檐 4.06 m
   │ 5.78 m │  │ 板顶 + 露明椽条  │
   └────────┘  └───────┬────────┘
                       │ 黑铁排烟管（穿出坡棚 → 7.0 m）
              ┌────────┴────────┐
              │  炉膛石拱 + 火塘  │  ← 拱顶 3.90 m，拱券石 + 拱上阵营色檐带
              └─────────────────┘
```

**为什么这样分**：民居的识别特征是"一个完整的双坡 + 一个平齐的檐口"。只要在檐口下再插一层**独立出挑的坡棚**，天际线就一定会断成两段；再把屋脊用**楼阁 + 铁压条 + 立饰**压出节奏，观感就从"农舍"跳到"作坊"。

### 2.2 脊上的每一件都"有用"
- **铁压条**（0.21 × 0.05 m 通长）：把两片屋面"锁"在一起，远看是一条硬横线。
- **脊上楼阁**：1.02 m 高、四面各 3 道百叶，是**排烟通风口**，不是装饰塔。
- **铁砧立饰**：脊端一尊 0.5 m 铁砧剪影。
- **山墙尖没有十字**：v6 的两处金十字在小尺寸下会被读成教堂，已删。

### 2.3 屋面分两种材质
| | 主屋面 | 作业坡棚 |
|---|---|---|
| 基材 | `roof` #363B46 板岩 | `roof_edge` #232730 深色板顶 |
| 表面 | 11 道横向瓦垄（0.26 m） | 8 道细密板缝（0.125 m） |
| 读法 | 屋顶 | **棚顶** |

## 5. 入口与炉火

- 门洞 **1.85 m 宽、拱顶 2.28 m**；石拱圈 + 拱心石 + 双开门（铁箍 + 竖板缝 + 门环）+ 门缝暖光。
- 炉膛：Ø1.6 火塘 + 炭床 + 9 块碎炭 + 3 道炉栅 + **排烟罩（1.64×1.34 → 0.80×0.70）+ 黑铁烟管**（穿出坡棚到 7.0 m）。
- 火焰三层：**后层暗红火体（3）+ 前层亮黄火舌（4）+ 炭床暖光**。
  迭代中修掉的三个坑：内焰被外焰包住 → 前移 0.30 m 做独立亮舌；点光塞在火里 → 移到火焰前上方 1 m；
  自发光反照率过高 → 压到近黑、镜面归零，颜色只来自自发光。

| 项 | 规范 | 当前实测 |
|---|---|---|

## 8.5 俯视角识别（第三轮反馈）

45° 俯视时，**屋顶占了大半屏幕**，垂直面的盾/旗被严重压缩。所以"这是铁匠铺"必须靠**屋顶上的东西**说：

| 手段 | 做法 | 为什么管用 |
|---|---|---|
| **两个屋面两种颜色** | 作业坡棚改用新的 `roof_wood`（暖木瓦 #7A5B3C），主屋面保持冷板岩 #363B46 | 俯视时是"深色大屋顶 + 暖色小屋顶"两个色块，一眼读出"主屋 + 作坊"的双体量，而不是一整片屋顶 |
| **屋面排烟天窗** | 炉子正上方的坡棚上开一个 1.04 × 0.86 的铁框天窗，内膛 `ember` 发光 + 三道铁压条 | 俯视时唯一的高饱和橙色点 = "这里在烧火"，是全图最亮的焦点 |
| **檐口阵营色压条** | 主屋两侧檐口顶面加一条 `team_trim` 压条（0.20 m 宽） | 45° 下水平面才吃得到颜色；这是唯一"在水平面上"的阵营色 |
| **高烟囱 + 楼阁** | 烟囱 11.0 m（1.26× 屋脊）、八角收分 + 铁烟罩；脊上楼阁 1.02 m | 剪影上两个"戳破屋脊"的体量，是民居没有的 |
| **前场大铁砧** | 1.0 m 砧身 + 1.1 m 砧角 + 红热锻件 | 俯视时院子里的最大物件，且带一个橙色高光 |

> 一句话：**垂直面负责"阵营"，水平面负责"建筑类型"**。上一版把两头都压在垂直面上，所以俯视读不出来。

## 9. 渲染与导出的边界（重要）

**渲染做了**：`bs_shots.py` 用 EEVEE 渲 7 张（主 / 正 / 侧 / 背 / 近景 / RTS 45° / 低模对照），
1200 px、64 samples、AgX + Punchy、曝光 0.35，输出在 `docs/bs_v8/`。

**导出不带渲染**：GLB/FBX 只承载 **几何 + 材质参数 + UV + 自发光强度**。
导出时 `export_lights=False / export_cameras=False`，所以：

| 会进 GLB | 不会进 GLB |
|---|---|
| 网格、法线、UV、材质（base color / roughness / metallic / emissive strength） | 灯光、相机、世界环境、色彩管理、EEVEE 设置、AO、阴影 |

**工程文件因此拆成两份**：

| 文件 | 内容 | 谁生成 |
|---|---|---|
| `blend/bs_v8/blacksmith_v8.blend` | **展示场景**：模型 + 3 盏面光 + 3 盏点光 + 世界渐变 + 相机（含正交近景机位） | `bs_shots.py` |
| `blend/bs_v8/blacksmith_v8_geo.blend` | **纯几何**：只有模型与材质，导出用 | `export_blacksmith.py` |

> 上一版只有一个文件、且被导出脚本最后覆盖，所以打开后没有灯和相机、视口一片灰 —— 现在两条线分开了。

**要在引擎里复现渲染观感**：用 `blacksmith_v8.tscn` 里预置的 `ForgeLight` / `DoorGlow` 两盏点光；
或等有 UV 了以后烘一张 AO / lightmap（UV 已备好）。

## 11. 已知限制（接手前先看）

1. **没有在 Godot 里真跑过**（本机无 Godot）。`.tscn` / `.gd` 静态检查过，未过引擎编译。
2. **3/4 视角阵营色 5.29%**，低于 8–12% 口径；要提就加宽侧墙横幅，别加小点位。
3. **背立面出图偏暗**（主光在正面），属布光问题不是模型问题。
4. **UV 会让文件变大**：低模 446 → 583 KB、细分 1.19 → 1.54 MB。不做贴图时可以关 `CONFIG["unwrap"]`。
5. **n-gon 只做了"平面端盖"级别的规范**（98 个），没有强制全四边面；若要严格全四边，得给回转体端盖加扇形三角化。
6. **没有 LOD 自动生成**：低模版（8.8k）可直接当 LOD1。
7. **火焰是几何 + 自发光**，没有半透明/体积；引擎里的"跳动"要用自发光强度动画。
8. **烟是 VFX，不进 GLB**。
9. **阵营色占比**是"正视 + 3/4"两个正交机位的测量值，不是任意机位统计。
