# 城镇大厅 v2 · 报告（入口 / 主体 / 屋面重做）

> 第三座（前两座：铁匠铺 v10、兵营 v4）。同一套材质、同一枚徽记、同一套目录与验收口径。
> 代码 blender/bs_v6/th_model.py；体检 th_align.py；出图 th_shots.py；
> 导出 export_townhall.py / export_mobile.py / export_blend.py。
> 上一版 v1 已归档在 docs/城镇大厅/v1/ 与 assets/_历史版本/城镇大厅_v1/。

v1 已交付，但用户这次点名的三件事是硬伤：

1. **入口那块不该往前突出** —— v1 的钟塔从正立面往前凸 1.0 m，再接一块独立门廊台，俯视像兵营的营门；
2. **主体应是"主楼 + 钟楼 + 附楼"的组合，但仍是一整个主体，中轴不能丢**；
3. **屋顶怪、丑、没有美感、没有把"城镇大厅"的职责讲出来** —— v1 是四坡大金字塔 + 前突钟亭，钟塔从屋面正中穿过去，接缝处堆三角墙，远看是一顶黑帽子。

v2 不是修修补补，是把这三条在体量层面重做。

## 1. 设计

### 1.1 入口：塔压回立面，没有外挂体块

v1 的门楼是"门 + 塔 + 门廊台"三段外凸；v2 把塔的**前脸压到与主墙同一个平面**（Y=3.60），只在塔角做 60 mm 的石作壁柱。门洞是塔身里 **0.55 m 深的拱门**，门扇、扇形窗、铁艺、壁灯全在凹进的门洞里；门前的三级踏步落在前庭台上。

- 塔前脸与主墙的接缝用两根 300 mm 壁柱压住，读成"塔身"，不是"贴上去的门楼"；
- 中轴：拱门 → 门楣徽记 → 塔身百叶 → 钟面 → 钟亭 → 尖顶 → 旗；
- 前庭：铺石台（0.42 m）+ 中央仪仗道 + 三级主踏步 + 前庭外三级台阶 + 两侧矮墙/端柱。踏步、旗杆、火盆、公告板、木桶木箱都在中轴两侧，入口不再靠一个凸块强调。

### 1.2 主体：主楼 9.6×7.2 + 钟塔 3.6×3.4 + 后附楼 6.4×3.58，同一块石台

- **主楼**：9.6 × 7.2，两层。0.72 m 石台、墙裙、腰线、石檐口（齿饰）、四角隅石。
- **钟塔**：3.6 × 3.4，前脸与主楼同面，从地面贯通到 19.19 m。塔身过屋面处由上段屋面"咬"进去，塔两侧的屋面各自收边；塔顶是钟座（3 面钟）+ 露台女儿墙 + 四面石墙的拱形钟亭（铜钟）+ 修长尖顶 + 旗。
- **后附楼**：6.4 × 3.58，贴主楼后墙，墙顶 4.58 m，四坡顶到 6.30 m；后墙三扇拱窗 + 中央圆窗；屋面后坡上立一根石烟囱。附楼与主楼共用石台、共用后墙、共用同一条腰线高度，俯视是一个"T"形连通的体块，不是另起一座小房子。
- 一条**阵营色带（4.78–5.35）**环着主楼一整圈，在塔前脸处由塔身腰线接上；塔身上部（10.72–10.90）再走一条窄色带，把塔和主楼绑在一起。

### 1.3 屋面：两段式孟莎四坡，钟塔从"冠"里长出来

v1 的屋面有三个具体问题：整块近黑四坡面、没有檐口/瓦垄/脊线；钟塔从屋面正中穿过，塔两侧留下两块三角石墙；前突钟亭的"冠"和主楼屋面没有关系，职责只剩一个尖顶。

v2 的屋面：

| 部位 | 做法 |
|---|---|
| 下段 | 57° 陡坡，檐口 7.82 → 折脊 9.22，四坡 + 四条戗脊 |
| 折脊 | 一圈铅压条（0.10 × 0.07），把上下两段"折"出来 |
| 上段 | 30° 缓坡，折脊 → 正脊 10.98；正脊在塔背两侧各留一小段 |
| 檐口 | 石线脚 + 齿饰 + 0.18 m 封檐板；檐口出挑 0.30 |
| 瓦垄 | 通长细瓦垄（0.065 × 0.05），顺坡向；不是满铺小瓦盒 |
| 塔 | 塔身从两段屋面里穿出，塔脚由挑檐（10.95–11.10）压住；塔顶钟座 11.10–12.95、钟亭 13.35–15.06、尖顶 15.10–18.15 |
| 职责 | 三面钟 + 铜钟 + 尖顶 + 旗，全部压在一条中轴上；钟面高过屋脊，俯视第一眼就是"镇中心的钟" |

钟亭不是四根孤柱撑一个盖：四面石墙 + 拱形开口，后墙是实墙 + 内侧深色衬板，铜钟（0.48 m 半径）挂在里面；上沿一圈石枋，四角四根石柱；尖顶两道铅箍。

### 1.4 风格色卡

和另两座同一套：石（stone_light / mid / dark）、深板岩（roof / roof_edge）、暖木、铁、金、阵营蓝 + 金、炉火橙、玻璃冷青。没有新增材质，没有贴图细节，颜色只靠大色块 + 光分层；阵营色集中在腰带、门、旗、盾、塔身窄带。

## 3. 体检（684 构件）

th_align.py 口径与 bs_align / br_align 一致：CLIP 跨系统真相交、COPLANAR 同向共面、FLOAT 悬空。v2 的构件系统扩到：

base / wall / roof / tower / window / annex / gate / herald / prop

结构性相交全部写进白名单（每条有物理理由）：塔从主墙/两段屋面里长出来；后附楼与主楼共用后墙/石台；附楼屋面压在附楼墙与主楼后墙上；烟囱穿过附楼屋面；窗/圆窗/百叶嵌进墙；门套/门扇/扇形窗/壁灯在塔的门洞里；腰带/盾/垂旗/徽记是贴附件；瓦垄/戗脊/折脊铅条压在屋面上；塔座挑檐只向塔前/两侧出挑，后缘压在塔背里。

结果：

~~~text
ITEMS 684
CLIP_CROSS 0
COPLANAR_UP 0
FLOAT 0
COPLANAR 234（全为异向接触面 / 被外层挡住的隐藏面）
CONTAIN 21（钟面盘在环内、门扇在门套内、灯芯在火盆内、纸条在公告板内 —— 设计包含）
~~~

v2 修掉的 8 类真实问题：

1. **瓦垄没进模型**：rib_quad() 创建了梁却没有 add 进 items —— .blend 里 31 根瓦垄、GLB/图集里没有，交付文件出现"有缝的屋顶"和"5 个材质"。已改成返回对象、Model.rib() 统一 add。
2. **扇形窗黑楔**：arch_profile(w, 0.0) 底边有重复点，三角化出黑楔；改成手写半圆。
3. **钟座挑檐穿后坡**：挑檐环后缘越过塔背，和上段屋脊/瓦垄相交；后缘收到塔背里。
4. **钟亭顶面与石枋共面**：侧墙顶、后墙顶降到 15.06/15.04，上枋 15.06–15.10。
5. **钟亭铜钟太小、被挡**：铜钟半径 0.40 → 0.48，钟口上移，钟亭后墙加深色衬板。
6. **主楼窗台压墙裙压顶**：下窗抬到 1.62，窗台落在压顶上方；压顶/窗台不再相交。
7. **后墙窄条窗撞隅石**：后墙两侧只有 1.6 m 宽，窗框+隅石放不下；删窗，改后墙中央圆窗。
8. **入口/腰带净空**：拱脚 3.50→3.40，拱顶 4.50，色带 4.78 起；拱心石降到 4.38–4.68，不再切进蓝带。

## 5. 风格：不是"三渲二"

与 v1 同一个结论：低模硬表面 + PBR 平涂色块 + AgX 影调的写实化卡通风，不是 cel / toon。明暗连续、没有描边、金属保留高光/反射；"像 2D"来自低模 + 大色块 + 硬边，不来自 toon 着色器。v2 的修改全在体量、屋面、檐口、瓦垄、钟亭这些几何层，没有换材质/着色器；要改三渲二会废掉图集/换色这一套。

## 7. 已知限制

1. **后附楼在 −48° hero 里只是一条低翼**：它被主楼挡住大半，完整轮廓在侧面/背面/俯视/三座对照里；这是"一整个主体"的代价，不是漏做。
2. **侧墙后段（附楼上方）留白**：主楼侧墙 y≈−2.4..−3.6、z 4.6..7.56 是一块素石面；加小窗会撞后角隅石/后窗框，暂不加。若以后要补，建议 0.6 m 宽窄窗，放 y=−2.80。
3. **钟亭内部极近景有 EEVEE 采样噪点**：石墙/地板在暗部；远景/中景无影响。
4. **COPLANAR 234 对**：全是异向接触面或外层挡住的隐藏面；验收口径 COPLANAR_UP 0 已达成。
5. **阵营色正视 10.68%**：规范写 6–9%，但这一套的交付口径是"一条粗色带 + 门 + 盾 + 旗"，v1 实测 14.08/9.38，v2 已收窄到 10.68/6.08；3/4 在规范内。不要为了数字再加蓝色。
6. **正面/后墙比例**：v1 用 1.6 判"正面"，v2 有后附楼，前场仍比后侧长（9.84 vs 7.85 = 1.25）；导出检查改 1.2，并在 export_townhall / export_mobile 里写明原因。
