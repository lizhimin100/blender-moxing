## 1. 设计：为什么是"一座塔 + 一层台"

要求里有三条互相拉扯：**不能做多座分开的建筑**、**要像基地**、**要简洁不杂乱**。  
所以不做"主楼 + 钟楼 + 附楼"的组合，只做**一座连通的建筑**，靠三件事立住：

| 手段       |   | 具体做法                                           | 为什么                                                            |
| -------- | - | ---------------------------------------------- | -------------------------------------------------------------- |
| **一条中轴** |   | 钟塔（前突 1.0 m）→ 拱门 → 三级踏步 → 铺石广场 → 落地石阶，全压在同一条线上 | RTS 俯视时"入口在哪"一眼可读，秩序来自重复的中轴而不是装饰                               |
| **一顶冠**  |   | 四坡屋面 + 开放钟亭（4 柱 + 通口 + 钟）+ 尖顶 + 旗              | 屋面类型定为 **crown_eave**，与铁匠铺 `gable_cross`、兵营 `flat_crenel` 两两不同 |
| **一层台**  |   | 建筑坐 0.72 m 石台，前接**同材质**铺石广场（与基座共用面）            | "基地"= 建筑 + 它的前场；广场不是另立的一座台，是从石台上切下来的一块                         |

体量：主体 **9.6 × 7.2**，含台与广场 **10.76 × 14.84**，总高 **16.19**。  
兵营 10.96 × 14.63（高 10.3）、铁匠铺 10.03 × 11.80（高 11.0）—— 摆在一起宽深一致，  
城镇大厅只在高点上高一截（钟塔），正对"镇中心"的读法。

### 立面的分层（自下而上）

```
0.00–0.72   石台（深色 + 压顶）          —— 把建筑从地面"抬起来"
0.72–1.68   墙裙（stone_mid）+ 深色压顶
1.90–3.78   一层半圆拱窗（玻璃 / 窗台 / 中梃）
4.45        腰线（细石线）
4.65–5.35   阵营色带 0.70 + 金线         ← 全身最醒目的一条横色，与兵营同一高度逻辑
5.72–7.67   二层高窗（石套 + 十字棂）
8.10–8.55   檐口（0.22 出挑 + 深色滴水线）
8.50–11.80  四坡屋面（薄壳 0.18 + 8/4 道通长瓦垄 + 四条戗脊）
10.15–12.40 钟亭（4 柱通口 + 铜钟）
12.52–15.00 尖顶（四坡锥台 + 3 道瓦圈 + 4 条戗脊）
15.30–16.19 旗杆 + 联盟旗（徽记贴回布面）
```

钟塔前脸从下到上：拱门（扇形窗 + 双开蓝门）→ 门楣盾 → 阵营色带 → 铜圈钟面 → 塔身色带  
→ 塔檐口 → 钟亭 → 尖顶。**塔身中段不塞窗**：3.1 m 宽的面上再开小窗，在 30 m 外只是噪点。

### 广场：只放读得懂的

- 深色石界（0.30 宽）框住整块铺石，浅色仪仗道 3.30 宽正对台阶 —— 这是俯视时的"秩序线"。
- 公告板（任务板）、一对火盆（门口唯一的暖光）、两只木桶 + 一只木箱、两支旗杆。
- 二层窗两侧的 **0.24 m 木百叶**：另两座都有一大片暖木（兵营的二层木构、铁匠铺的坡棚），    
  这一座是石材主体，用百叶补一条竖向的木色节奏，色温才不会掉出这套资产。
- **删掉的东西**：广场中心的十边"徽盘"（俯视像井盖）、长凳（RTS 尺度是一块棕色板）、    
  屋面老虎窗（两版都读成烟囱，见 §4 第 6 条）。

## 2. 与另两座的同与不同

**同（不动的东西）**

- 材质色卡、墙裙 / 腰线 / 檐口 / 阵营色带 + 金线的分层逻辑；
- 徽记：**直接继承 `br_model.Model`** 的 `crest / emblem / kite / wallbanner / barrel / crate`，    
  与兵营、铁匠铺是**同一段代码**（王冠三尖三宝石 + 盾形七段折线，零曲线）；
- 旗帜零件：木杆 + 金端头 + 吊环 + 流苏 + 徽记；墙面用挑杆、塔顶用旗杆；
- 尺度：1 unit = 1 m，正面 −Z，原点占地中心，`finalize()` 最后沿 X 镜像一次。

**不同（这一座的识别点）**

|     | 铁匠铺         | 兵营          | 城镇大厅                    |
| --- | ----------- | ----------- | ----------------------- |
| 屋面  | cross gable | flat crenel | **crown_eave（四坡 + 冠亭）** |
| 主色块 | 坡棚木瓦 + 炉火   | 女儿墙 + 垛口    | **中轴钟塔 + 拱门**           |
| 前场  | 木构雨棚 + 工作台  | 夯土训练场 + 木栅栏 | **铺石广场 + 石界 + 旗杆**      |
| 高度  | 11.0        | 10.3        | 16.2（全包最高）              |

## 4. 这一座新踩的坑（写进流程，别再犯）

1. **`bslib.arch_band` 只做朝 ±Y 的拱**。侧墙的拱窗直接套它，会得到一块     
   **1.45 × 1.45 × 0.73 的横躺方墩**从侧墙里顶出来（兵营侧窗其实一直有这个错，     
   RTS 距离看不出来）。这一座新增 `arch_band_x()`：拱在 YZ 平面、沿 X 拉伸。
2. **`lathe()` 的 z 是"绝对于地面"，不是相对偏移**。火盆的火焰照抄兵营的写法，     
   忘了加 `z`，整条火焰长在广场地面上（体检里表现为 `plaza_bed <-> braz_flame` 相交）。
3. **塔身不要做"与檐口同高的分节线"**：那条环正好落在屋面檐口上，横穿封檐板与檐口，     
   体检直接报 3 组 cross。删掉之后塔身的空白交给"色带 + 钟面 + 塔檐口"三段解决。
4. **旗上的徽记要贴+ Y 一侧**。旗布 0.035 厚，徽记中心写 `cy − 0.012` 会贴到**背面**：     
   正视图上旗面是一块纯蓝，正面看不到徽记。改成 `cy + 0.0125`（背面埋 1.5 mm、正面凸 9 mm）。
5. **广场石界的前段要收在侧段之间**。两侧石界通长、前石界通宽，转角就是两块同高的     
   0.404 顶面 —— 俯视一直在闪。前段宽度改成 `PLZ_X*2 − 1.00`，与侧段只共边。
6. **老虎窗在这套体量上读不出来**。1.24 m 宽、0.62 m 窗洞，在 1:100 的场景里不足 15 px，     
   3/4 视角只读成两个灰方块（像烟囱）。两版之后删掉，屋面靠瓦垄 + 戗脊 + 封檐三层线脚撑住。
7. **构件"落在斜屋面上"要埋到最低点以下**。老虎窗的板/体只埋 6 cm 时，屋面往后升高，     
   后半截就浮在瓦面上。要按"该构件最靠后的一点"算埋深（这版直接埋到 8.40）。

## 5. 风格：这是不是"三渲二"？

**不是。** 这套资产是**低模硬表面 + PBR 平涂色块 + AgX 影调**的写实化卡通风，  
不是三渲二（cel / toon shading）。区别在四个可验证的点：

| 判据 | 三渲二              | 这套资产                      |
| -- | ---------------- | ------------------------- |
| 明暗 | 色阶断带（2–3 阶 ramp） | **连续**的 PBR 明暗（GGX + 环境光） |
| 描边 | 反向外扩壳 / 边缘检测     | **没有描边**，轮廓靠几何本身与暗部对比     |
| 高光 | 通常压掉或只留一条        | 金属（金 / 铁）保留**各向异性高光与反射**  |
| 阴影 | 常压平成色块           | 有软阴影、AO、色彩反弹              |

它的"像 2D"来自另外三件事，不是着色器：**低模 + 大色块（每材质一个纯色）+ 硬边几何**，  
再叠 AgX Punchy 把中间调压紧。要真的变成三渲二，得换材质（Ramp + 描边），  
那时贴图/图集这一套就白做了 —— 所以**建议保持现状**，需要"更二次元"时靠图标与 UI 补，  
不要动 3D 渲染管线。
