## 3 组件化：五层，可拆可换

| 模块 | 前缀 | 件数 | 内容 |
|---|---|---|---|
| `body` 种族躯体 | `lg_ bd_ ar_ jt_` | 84 | 靴/腿/腿甲/胯/腰带/裙甲/外套/胸甲/护颈/双臂/双拳 |
| `head` 头 | `hd_ bm_` | 33 | 颅骨/脸/鼻/眼/眉/桶盔/蓝顶/冠徽/护颊/护颈/**上下胡 + 两条辫** |
| `shoulder` 护肩 | `pd_` | 8 | 弧壳 + 叠片 + 金边 + 铆钉（每侧 4 件） |
| `gear` 装具 | `gr_` | 8 | 火药角（木身/骨嘴/双铜箍/皮挂带）+ 弹囊 |
| `weapon` 武器 | `wp_` | 23 | 枪托/枪管/喇叭口/双铜箍/队色箍/锁板/击锤/药池/扳机/护圈/准星/通条 |

**两条硬接口**（改这里 = 改所有换装组合）：

1. **骨名 = 动作表的键**：
   `root → hips → spine → chest → neck → head`；`shoulder/upperarm/forearm/hand_R|L`；
   `thigh/shin/foot/toe_R|L`；`weapon_R`（枪插座）· `prop_ramrod`（通条）· `weapon_L`（副手插座，预留）＝ **25 根**。
2. **材质名 = 染色协议的键**：`主体`（图集）/ `team`（蓝）/ `team_trim`（金）。

拆装方式：
- 想换武器 → 删掉 `unit_weapon` 这个物体，把别的武器 glb 挂到 `weapon_R`；
- 想换头/盔 → `build(modules=["body","head","shoulder","gear"])` 只出这几层，
  或按 `组件清单.json` 里的名字逐件替换；
- 想轻装 → 去掉 `gear` 层（火药角与弹囊整组消失，不影响骨架）。

## 4 骨架与蒙皮

- 25 骨（联盟白名单 24~25 之内），`_R/_L` 后缀，**与步兵/弩兵同一套**；
- 一块 = 一根骨、权重 1.0（刚性蒙皮）：`zero=0 / max_inf=1 / unnorm=0`；
- 脚底 z=0.000，正面 +Y，原点在双足中间；
- 归一化顺序：`build → finish（倒角/细分/合并）→ build_rig → bind → 动作`。

关键枢轴高度（m）：`hips 0.520 / chest 0.780 / neck 0.955 / head 1.010 / 肩 0.900 /
膝 0.357 / 踝 0.195`；臂展 0.494（矮人短臂，比步兵 0.63 短），大腿 0.167 / 小腿 0.164。

## 5 动作（30 fps，7 条）

| 动作 | 帧 | 时长 | 循环 | 说明 |
|---|---|---|---|---|
| `idle` | 0..120 | 4.00s | **是**（首末帧逐骨矩阵差 = 0） | 两次呼吸 + 重心左右 + 一次轻微看四周 |
| `idle_alt` | 0..150 | 5.00s | 否 | **悠闲**：抬手捋两下胡子（掌根贴胡子走）→ 扭头看一眼 |
| `walk` | 0..30 | 1.00s | **是** | 矮人重步：步幅 ±0.128、抬腿 0.072、起伏 32 mm、胯摆 ±3.4° |
| `attack` | 0..40 | 1.33s | 否 | 扛肩 → 落枪到腰射 → **f16 击发（40%）** 后坐 → 收枪 |
| `reload` | 0..84 | 2.80s | 否 | 枪横腰前 → 左手去火药角 → 灌药入喇叭口 → 抽通条 0.16 → 捅回 → 归位 |
| `hurt` | 0..11 | 0.37s | 否 | 上半身一缩（可被任意动作打断） |
| `death` | 0..40 | 1.33s | 否 | 中弹一顿 → 膝盖一软跪倒 → 上身垮下 → **f28..f40 绝对静止（0.40s）** |

姿态算法：**躯干 FK + 四肢双骨解析 IK**——手/脚先落在目标点，再反解骨骼朝向；
武器的世界朝向直接给定，右手（含枪）跟着转，左手的握点由枪的实际变换算出来，
所以"手永远在枪上"，不靠手调角度。

前三帧的枪位是三个不同的识别姿态：**扛肩（rest）/ 腰射（attack）/ 横端（reload）**，
三条动作不会互相看混。

## 7 穿模口径（逐件 BVH 交测试）

把 156 个零件按骨合并成 21 组，两两求 BVH 交。31 组相交，逐条都能给出物理理由：

| 相交 | 理由 |
|---|---|
| `hand_R × weapon_R` | 拳心就是枪托（握把重叠是设计如此，与规范 §8-⑧ 同一口径） |
| `prop_ramrod × weapon_R` | 通条躺在护木槽里（装填时沿骨轴滑出 0.16 m） |
| `hips × spine`、`chest × spine` | 外套/胸甲/胯三块体块有意叠压成"一个躯干" |
| `head × chest`、`head × spine` | 胡子从下巴垂到胸口（胡子末端埋在胸甲里，露出来的是正面一段） |
| `hips × thigh`、`thigh × shin`、`shin × foot` | 关节轴故意插进两侧（缝里那根更细的深色轴） |
| `upperarm × shoulder`、`forearm × hand` | 肩缝/腕缝同理 |
| 护肩 × 胸甲 | 护肩弧壳压在肩窝上 |

**本轮真正修掉的两处**（不是设计叠压，是错位）：
1. 枪管在肩高处埋进护肩 1.3 cm → 枪整体前移 8.7 cm（`GUN_G.y 0.205→0.292`）；
2. 腕骨沿"拳→肩"回退，方向几乎与枪管同轴 → 腕子陷进枪托 → 改成沿"拳→肘"回退 72 mm。

## 8 已知取舍与偏差（不许悄悄改判据）

① **RTS 阵营色 11.17%**（正视图 7.14% 在范围内）。
   来源是**蓝盔顶**：它是俯视角下唯一的水平队色面（规则 C30：俯视染色必须画在水平面上），
   砍掉它 RTS 会掉到 8% 但"蓝顶矮人"的识别点就没了。参照登记：步兵 13.99%、弩兵 8.97%。

② **身高 1.467 m（含枪口）**，身体 1.437。枪口比盔顶高 3 cm 是故意的——
   竖向道具要跳出身体轮廓才能进背景（交接手册 §6.3 第 1 条）。

③ **低模档 9,830 面**略超联盟 3,000~9,000 的上限。
   多出来的全是"块面倒角"（156 个零件每个 12~40 面）。要压到 9k 以下只能删零件（胡子辫环/护肩叠片），
   会直接掉识别点，所以保留并登记。

④ **不做手指骨**：手是一个拳块 + 四指浮雕，握持靠"拳心 = 枢轴"保证不飘。
   加手指骨会多 10 根骨、多 4 套动作，收益在 96px 下为零。

⑤ **death 是跪倒不是仰倒**：绕脚踝整体前倒 78° 会让背/枪穿地 0.29 m（实测），
   跪倒式既贴地又不穿模，观感也更"被打死"。

⑥ **`cast` 未做**：`attack` 已经覆盖远程开火，引擎降级链 `attack→shoot→cast→walk` 能兜住。

## 10 本轮踩的坑（写进规则前先记这里）

1. **姿态层的骨根位置必须把偏移转到父骨的静止局部系**：
   `T[子] = T[父] + R[父] @ (rest_head[子] − rest_head[父])` 是错的——偏移是世界向量，
   要先过 `R_rest[父]⁻¹`。症状很隐蔽：静止帧正常，一降重心整条腿往上翻 0.4 m。
2. **动作必须显式绑 action slot**：Blender 5.2 的 layered action 只设 `animation_data.action`
   不会求值，`action_slot = act.slots[0]` 少一行，整条动作看起来"没生效"（而且 loop Δ 会是 0，很像通过）。
3. **EEVEE 不能在桥接的 socket 回调里渲染**：GUI 里 `bpy.ops.render.render()` 会卡死（CPU 不涨、窗口还在响应）。
   渲染一律走独立后台进程 `blender -b`；桥接只做纯数据操作。
4. **删光 `bpy.data.objects` 会把桥接的 socket 线程搞死**：之后 ping 全超时。清场只删自己建的集合。
5. **腕骨方向要垂直于武器轴**：沿"拳→肩"回退时，腕子正好沿枪管滑进枪托里（护臂跟着穿模）。
6. **`rotation_difference` 是 self→other**（正着用没问题，但排错时容易把方向搞反）。
