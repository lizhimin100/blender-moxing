# 方块人 · 矮人火枪手 v2（方块人语言返工）

> v1（`docs/火枪手/报告.md`）做成了「低多边形写实的矮人」，不是这套资产要的**方块人**。
> 本版把几何全部重写，骨架、骨骼命名、7 条动作、组件分层、导出链**原样保留**。
> 判据来自 `单位/文档/单位资产规范.md` §4/§8/§13 与 `制作要点与经验.md` §9.2。

## 1 用户指出的四个问题 → 根因 → 改法

| # | 用户原话 | 根因 | 本版做法 |
|---|---|---|---|
| ① | 「这个手指好奇怪」 | `fist()` 在 0.10 的拳块上又套了 4 根手指 + 指节垫 + 拇指块，全部 `sub=1`（Catmull-Clark）→ 揉成一团肉球 | **手 = 一块方块**。删掉手指/指节/拇指/指缝块，只留 `ar_fist`（0.092×0.114×0.098，平面着色）。方块人尺度下手只负责「握住了」这一条信息 |
| ② | 「胡子上怎么会有金色点缀」 | 两条辫子各挂了 2 个金环（`bm_ring_*`），是 v1 自己加的装饰 | **金环全删**。胡子上只允许一种颜色（`rust`）。护肩金钉、腰带金冠、大腿亮脊等「多出来的小片」一并删掉 |
| ③ | 「符号所在的地方不对，换个地方」 | 三尖金冠压在**头盔前额**上，正对镜头读成「额头贴了张符」，也不符合联盟语言 | 金冠移到**胸前垂布中央**，与弩兵同一位（弩兵：胸兜中央；步兵：盾面）。前胸 + 后背各一枚，`scrown(pre="gr_"/"grB_")` |
| ④ | 「不是说参考联盟的吗？我要的是方块人」 | 全身用了 6/8 边圆管（`tube n=6/8`）、弧形护肩壳（`arc_plate`）、9 点带脊截面（`sec9`）、大量 `sub=1` —— 这是「低多边形」，不是「方块人」 | 按 `经验 §9.2`**全部改成 4 点截面 + 平面着色**：四肢 `blimb`（4 点倒角截面）、躯干/胯/盔/枪托 `poly_rect` 放样、护肩改三层扁方板、头改一整块立方体 |

## 2 方块人语言（本版的硬规则）

```
截面   四肢 = 4 点截面（blimb / poly_rect ch=0.014~0.024），躯干/头/盔 = 矩形截面放样
着色   一律 smooth=False（平面着色）；只有「必须圆」的不用 —— 本版一件都没有
倒角   只用 bevel（0.003~0.012），一律 sub=0。**硬表面只倒角、永不叠 CC**
细节   贴片（plate / 薄 box）叠在体块上，不雕、不挖、不做曲面过渡
手      一块方块
胡须    两条方辫（poly_rect 放样，5 排收分），无任何金属饰件
徽记    只有一处：胸前垂布上的三尖金冠（背后同款）
```

面数从 v1 的 11,658 降到 **8,992**（回到联盟 3000~9000 的区间内），整体反而更清楚。

## 5 骨骼与动作（与 v1 同一套，未改）

25 骨，联盟白名单命名：`root / hips / spine / chest / neck / head` +
`shoulder|upperarm|forearm|hand_R|L` + `thigh|shin|foot|toe_R|L` + `weapon_R / prop_ramrod / weapon_L`。

姿态层是「躯干 FK + 四肢双骨解析 IK + 武器世界朝向直给」：手和脚先落在目标点，
武器朝向直接写世界向量，右手（含枪）跟着转，左手握点由枪的变换算出。

| 动作 | 帧 | 时长 | 循环 | 说明 |
|---|---|---|---|---|
| `idle` | 0–120 | 4.00s | ✅ | 呼吸 + 枪口微晃，首末帧逐骨矩阵差 = 0 |
| `idle_alt` | 0–150 | 5.00s | — | 捋两下胡子 → 扭头 |
| `walk` | 0–30 | 1.00s | ✅ | 重步：步幅 0.256、抬腿 0.072、髋滚 3.4° |
| `attack` | 0–40 | 1.33s | — | 落枪腰射，**f16 = 40% 击发**，后坐 + 枪口上跳 |
| `reload` | 0–84 | 2.80s | — | 火药角 → 喇叭口灌药 → 抽通条 0.16 → 捅回 |
| `hurt` | 0–11 | 0.37s | — | ≤0.35s 门限内（0.367 含末帧） |

## 7 已知偏差（按规范 §9 的口径登记，不悄悄改判据）

**① 网格对象 4 个，规范要 3 个。**
第 4 个是 `unit_weapon`（832 面）。原因是任务要求「武器做成能拆卸、拼装的独立组件」——
焊进 `unit_body` 就失去了「换枪」的能力。代价是引擎多 1 个 draw call（4，仍在 §4 的 ≤4 内）。

**② 阵营色 正视 10.58% / RTS 14.08%，规范 6–8%。**
正面三带（蓝顶 2.0% + 前垂布 5.6% + 腰带 2.1% + 枪箍 0.9%）。
RTS 偏高是因为**俯视整块蓝顶**（顶面 0.30×0.29，占头顶面积约 70%）——
这是「蓝顶矮人」唯一的远距离识别点。与步兵 13.99% 同级，比弩兵 9.56%/8.97% 高一档 —— 蓝顶面积是换来的识别度。
要压回 8% 只需把 `hd_helm_cap` 的 `team` 改 `team_deep`（一行），但识别点会掉一档。

**③ death 末段膝盖压地 12.6 mm。**
跪倒姿势下护膝压进地面 1.26 cm。规范 ② 的 |min_z|≤0.002 只针对 rest（本版 0.0000）；
动作内的压地是「跪实」而非穿模，与 v1 的 −0.0115 同级。

## 10 这轮踩到的坑（补进 `制作要点与经验.md` 的候选）

**10.1 「方块人」不是「低多边形」。**
判据只看两条：**截面是不是 4 点**、**着色是不是平的**。
v1 用了 6/8 边管 + CC 细分 + 弧面护肩，面数 11,658 却完全没有方块感；
本版砍到 8,992 面，反而「更方块」。

**10.2 `u.plate` 的 `offset` 是「背面」那一层，正反两面的层级方向相反。**
正面垂布：金边 `offset=0.172`、蓝布 `offset=0.180`（蓝布更靠外 → 正确）。
背面垂布如果照抄数值符号，金边 `-0.198` 会跑到蓝布 `-0.196` **外面**，
整块背心就变成一片金 —— 实测踩到，背视图里是一块金色五边形。
正确写法：金边 `-0.194`、蓝布 `-0.200`（蓝布更负 = 更靠外）。

**10.3 头盔的「横向分层」会立刻读成礼帽。**
底檐 + 盔身 + 蓝箍 + 独立顶盖 = 四条水平线，正面看就是「帽子叠帽子」。
解法是**减层**：一整段钢壳（从眉上直通到顶）+ 一块蓝布顶 + 一个小钮，只留两条水平交界。

**10.4 胡子和垂布的前后关系必须按 y 排，不能按 z 排。**
胡子前表面 y≈0.216、垂布 0.180~0.200 —— 胡子必须在垂布**前面**。
v1.5 写反过一次，蓝旗压在胡子上，读成「蓝色围嘴压在红胡子上」。
检查法：量 `bm_*` 与 `gr_tabard*` 的 max/min y。

**10.5 手上有东西时，拳头不要比握持物宽太多。**
拳块 0.092、枪托 0.070 —— 宽 0.011 正好「包住」；v1 的拳块 0.104 + 四根手指，
在 RTS 下就是「一只手抱着个肉球」。
