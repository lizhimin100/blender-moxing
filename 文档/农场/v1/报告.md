## 1. `mono_pitch` 怎么落地

参考图里农舍和谷仓都是双坡，但六座屋顶类型必须两两不同，农场抽到的是**单坡**。
单坡做成"谷仓"而不是"农舍"，三个理由：

1. **谷仓本来就是单坡的大跨建筑**（lean-to barn 在中世纪北欧很常见）——一面向下落的
   长屋面正好覆盖"门开到最大、里面堆草料"的使用方式；
2. 单坡的**山墙是两侧的梯形墙**，正面看到的是"一堵墙 + 一条压在上面的屋面边"，
   和另五座的三角山墙 / 平顶垛口 / 四坡 / 双坡亭 / 敞棚在剪影上完全不同；
3. 谷仓可以做得比农舍宽（8.4 m），单坡的"斜线"才有足够长度，3/4 视角一眼就认出来。

数值：前檐 5.40 / 后檐 7.40（进深 5.00，**21.8°**）/ 左右出檐 0.36 /
屋面厚 0.26（木瓦）/ 前檐下一排 9 个露明椽头 / 屋面上 2 个通风百叶。

## 2. 布局：三块体量 + 一个院子

```
         田垄（三条，麦/白菜/南瓜）      筒仓（φ2.9，最高的点 10.98）
              ↓                              ↓
   ┌──────────────────┐            ┌────┐
   │   披屋（农具棚）  │  谷仓      │    │
   │   2.25 × 2.60    │  8.40×5.00 │    │
   └──────────────────┘  （单坡）   └────┘
              水井 · 草垛 · 水槽 · 板车     ← 前院（石座木栏 + 双开门）
```

- **谷仓**在中心偏右（x −4.20…4.20），**筒仓**咬在它右前角（φ2.90，重叠 0.10 —— 结构关系），
  **披屋**贴在左墙后段（2.25 × 2.60），**田垄**在左前、院子外，**水井 / 草垛 / 水槽 / 板车**
  按"进门 → 取水 → 装车"的动线摆。
- 占地 15.44 × 12.75：横向展开是农场的本体特征，和哨塔的 3.0 竖比例刚好互补。

## 4. 材质与染色：为什么最后落在"两条长线"

农场剪影面积是哨塔的 3 倍，同样的染色面积占比只有一半。**零散小件堆不上去**，
只能染最长的结构线：

| 高度带 | 位置 | 面积 |
|---|---|---|
| 低 0.6–3.7 | 门柱箍 + 门板嵌板 + 筒仓出料口 | ~1.5 m² |
| 中 4.2–4.5 | **前墙 + 两侧山墙的通长腰梁**（0.24 高，全座最长） | ~5.2 m² |
| 中 1.8–8.6 | **筒仓三道铁箍**（φ2.9 整圈） | ~6.4 m² |
| 高 2.5–4.6 | 四角包角柱**上段**（下段留深木，蓝不通天） | ~2.3 m² |
| 低 0.5–2.6 | 围栏前段两道横杆（金）+ 板车车篷 + 披屋檐柱箍 | ~1.8 m² |

实测：正视 **6.10%** / 3-4 视 **4.73%**。

三档木色在这里的作用：
- `wood_mid #5F3D1F` 墙板（大面）
- `wood_warm #9B6236` 门扇 / 椽头 / 屋面缝下的板
- `wood_dark #3E2718` 骨架（腰梁之外的横梁、斜撑、柱、门框）

屋面用 **`roof_wood #7A5B3C`**（暖棕木瓦）—— 和另四座的深蓝灰板岩完全分开，
一座农场在一片"蓝灰屋顶"里立刻跳出来。

## 6. 这一轮踩到的坑

1. **门柱没跟门的中心走**：门洞中心在 x=0.80，门柱却写在 `±(GATE_W+0.11)`（相对原点），
   门扇与门柱错开 0.8 m，门洞里出现一条黑洞。
2. **门扇宽度写死 1.30**：门洞改成 3.60 后，两片门扇还是 1.30，两侧各留 0.5 的黑边。
3. **窗函数只支持 ±X 墙**：正面（±Y 面）的窗用错函数，落在墙外。
   补了 `window_y()`。
4. **铺板/草垛/木桶压在场地面同高** → 一批 COPLANAR_UP；桶和草垛统一压进地面 20 mm。
5. **筒仓箍穿围栏**：围栏右段原来从 y=0.60 起，正好穿过 φ2.9 的筒仓；
   改成"在筒仓前沿（y=3.30）截止"。
6. **披屋屋面伸进谷仓墙 0.30** → 穿山墙竖柱；改成只进 0.10。
7. **山墙斜撑是"想当然的细节"**：从柱脚斜到檐口，必然穿窗、穿披屋柱、穿筒仓 ——
   改成两道横梁（板墙的正常骨架），问题消失。
8. **左墙的窗落在披屋里**：披屋贴在左墙后段，窗必须在它之外（y 1.35）。
9. **阁楼窗与斜屋面**：窗楣是平的、屋面是斜的，两者后端必然相交；
   窗做小（0.50 × 0.40）并抬到横梁之上才让开。

## 7. 留给下一版的

- 农场只有一座"主建筑 + 一个筒仓"，参考图是"农舍 + 谷仓 + 筒仓"三座。
  要再加一座，占地会到 20 m 以上，先要确认 RTS 的占地预算。
- 马、鸡、狗这类活物不在本包范围（"只含建筑，不含角色"）。
- 田垄的作物是"三色交替的方块"，近景能看出麦/白菜/南瓜，RTS 距离读作三条色带。
  要更细就得给作物单独做图集格（现在图集 25 格已满）。
