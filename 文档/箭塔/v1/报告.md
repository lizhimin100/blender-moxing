# 箭塔 v1 · 报告

> 第九座，**独立新资产**：`assets/箭塔` + `blender/bs_v6/at_model.py`。
> 哨塔（`assets/哨塔` / `wt_model.py`）原样保留、一个字没改 ——

## 1. 升级关系怎么读

| | 哨塔（17.34 m） | 箭塔（18.32 m） |
|---|---|---|
| 顶部 | 木挑台 + **双坡瞭望棚**（`gable_steep`） | **不封顶**：垛口平台 + 弩炮 + 角亭（`hip_spire`） |
| 塔身 | 石基 3.60 高，上面两段**木**塔身 | 石基 4.16 + **收分下段（石 4.28）** + **上段（木 3.68）** |
| 上法 | 外挂 57° 木梯，跨过门洞 | 内部楼梯（不表现）；外部靠"望楼角亭"读作梯头 |
| 挑出 | 两层挑台（5.30 / 5.00），四面栏板 | **一层**战棚（5.40），底下 12 根斜撑 + 投石孔 |
| 识别点 | 斜梯、双坡棚、三层挑台 | **垛口环、弩炮、挑出的战棚、攒尖角亭** |

一句话：哨塔是"往上叠"，箭塔是"往上收"。两座的剪影重合度很低（见
`docs/箭塔/v1/主图.png` 与 `docs/哨塔/v1/主图.png` 对照）。

## 2. 两轮形体推演

### v1 初版：像一栋办公楼

第一版按"石塔 + 木冠"搭，尺寸 3.88 宽、17.0 高，出来四个问题：

| 问题 | 现象 | 根因 |
|---|---|---|
| 比例太瘦 | 石塔身占 60% 高度、宽高比 1:4.5 | 只想着"塔要高"，没算"石头要厚" |
| 弩炮读不出 | 平台上是一堆交叉木条 | 用"两根侧颊 + 前后横梁 + 立式扭簧"拼，俯视全是斜线 |
| 队色像贴纸 | 塔身每面 3 段短蓝条 + 战棚 2 块蓝嵌板 | 在立面上"撒点"，没走结构线（违反规则 A-30） |
| 顶部像花盆 | 5 个细垛口 + 蓝压顶 | 垛口太细、缝太宽、压顶用队色 → 读成"蓝架子" |

### v2 定稿：加宽、加托石、换弩炮、把队色赶到水平面

| 项 | v1 | v2 |
|---|---|---|
| 石基 | 4.32 × 4.16 | **4.84 × 4.16** |
| 塔身 | 3.88 → 3.60 | **4.28 → 3.68**（收分 0.60，视线上真的"收"了） |
| 石线脚 | 2 道 | **4 道**（墙裙 / 腰线 / 退台 / 压带）+ 退台下 16 块托石 |
| 垛口 | 5 个 0.56×0.28，缝 0.24 | **6 个 0.56×0.34，缝 0.16**（读成"有缺口的墙"） |
| 压顶 | 队色 | **深木**（队色改到垛口压顶这个**水平面**上） |
| 弩炮 | 侧颊 + 横梁 + 扭簧 | **中柱 + 通长弩床 + 近横向弩臂 + 上弦弩矢**（俯视一个"T"） |
| 角亭 | 1.30 见方，檐下蓝带 | **1.38 见方 + 四根檐下斜撑 + 檐下金线** |
| 队色 | 立面撒点 | **4 条结构线**：门套 / 退台箍 / 垛口压顶 / 旗 |

### v2.1 定稿（最后一轮）：上段换木 + 正面开射击口

1. **塔身上段（8.18–11.00）从石构换成木构**。石塔身占 3/4 高度时，与哨塔并排
   （`docs/箭塔/v1/与哨塔对照.png`）整座"发白"——明度节拍是 stone → stone → stone，
   而这一套资产的语言是"石座 + 木上层 + 木冠"。换成 `wood_mid` 墙 + `wood_dark` 角柱
   + 一道 8.72 的腰梁之后，暖色补回来了，上段与战棚也连成了一片。
2. **炮座抬高 0.40，弩床与弩矢前伸过垛口**。原来弩炮整个躲在垛口后面，
   1080 px 的主图里只剩一个模糊的小疙瘩。现在弩矢前伸 0.44 m、
   弩床压过压顶，3/4 视能读出"一根箭指出去"。
3. **正面中间两个垛口留空**（1.28 m 射击口）+ 一道 0.18 高的低栏。
   这是全座唯一破坏"垛口环完整"的地方，换来的是弩炮在 3/4 视里读得出来。
4. **门套加木框**（两根 0.28 × 3.28 立柱 + 一道过梁）：石基正面本来就灰，
   门这一圈给暖木，入口的分量才够。

## 3. 屋顶：九座唯一的四坡攒尖

| 项 | 值 |
|---|---|
| 类型 | `hip_spire`：方形金字塔，底面封闭（4 个三角面 + 1 个底四边面） |
| 底面 | 1.90 × 1.90（亭身 1.38 + 出檐 0.26） |
| 脊尖 | 15.30 |
| 附件 | 檐口封板（45° 斜接环）、四条戗脊（0.08 方木压条）、金宝顶、铁箍 |

**为什么平台不封顶**：这套里"有顶的塔"已经是哨塔（双坡）、"平顶带垛口"是兵营。
箭塔要跳出这两个，只有"开顶 + 把武器露出来"这一条路 —— 顶一封，弩炮就只剩一个影子。

## 6. 这一轮踩到的坑

1. **`frame_ring` 会在正立面拉一条通长石带** —— 墙裙（0.42–1.06）和腰线（2.36–2.46）
   直接用，就把 2 m 高的门扇拦腰截断。必须用"正面留缺口"的五段环
   （`band_ring_gap`，缺口 0.92 让开门洞 + 门柱）。
2. **拱上墙的轮廓要从拱脚起算**，不是拱顶。从拱顶起算会在拱肩两侧各留一块
   0.6 × 0.6 的三角洞，从正面能看进门厅。
3. **门扇竖板间距按"半扇宽"重算**：`GW*0.5 + k*0.205`（k 取 −2…2）跨到 1.16，
   而半扇只有 0.66 —— 三块板跑到石墙里去了，正面只剩两块。改成 0.13。
4. **回转体轮廓别以 `r=0` 收尾**：`[(0,0),(1.06,0),(1.06,0.10),(0.94,0.16),(0,0.16)]`
   会把顶面塌成一个锥（炮座变成"倒扣的碗"）。要平顶就让最后一点 `r>0`，靠
   `revolve` 的端面封口。
5. **`bslib.cyl(axis="Z")` 返回 None**（只支持 X / Y）—— 绞盘鼓要沿 X 躺倒，
   竖直圆柱走 `br_model.vcyl`。
6. **抬起来的"板缝"会和所有落地道具相交**：5 条 12 mm 高的暗缝压在平台上，
   弩炮座 / 水桶 / 火盆全部 CLIP_CROSS。板缝在 RTS 距离看不见，直接删。
7. **道具别放在台基投影里**：台基 5.76 见方、高 0.42，箭捆架 / 石堆原本摆在
   |x| 2.5–2.8，整组埋进台基。地面道具必须落在 y > 2.88 或 |x| > 2.88 的场角。
8. **队色压在垛口顶面上要薄**：0.07 厚、出檐 0.08 时读成"蓝砖块"；
   改成 0.048 厚、出檐 0.023 才读成"刷上去的一层漆"。
9. **火盆要按平台尺寸重做**：哨塔的 `brazier` 火舌 0.82 高，放到 5.4 m 的平台上
   读成一支火把 —— 按 0.6 比例重写（石座 0.30 + 盆 r0.24 + 焰 0.33）。
10. **弩炮的"结构完整性"和"剪影可读性"是两件事**：侧颊 + 横梁 + 扭簧在工程上更对，
    但俯视是一堆交叉木条。RTS 只认"一根长梁 + 一根横梁 + 一根箭"。

## 7. 留给下一版的

- **弩炮在正视里几乎看不见**（臂在 12.84，正面垛口顶 12.62）。要让正视也读得清，
  得把射击面那一列垛口压到半高（试过，读成"缺了一块的墙"，已回退），
  或者把整台机器再抬 0.4 m（会像"架在旗杆上"）。这一版选择让俯视 / 3-4 视读。
- **石塔身仍是三块大平面**：图集是"每格纯色"，要加石缝只能换 UV 方案。
- **场地只有 0.84 m 外圈**：再想加一组地面道具，得把场地扩到 8 m 以上（会拖长碰撞体）。
- UI 图标里弩炮只剩 20 px，读不出来 —— 如果以后要"箭塔"在建造菜单里靠图标区分，
  考虑给图标单独换一个偏俯视的机位（现在是 26°/24°）。
