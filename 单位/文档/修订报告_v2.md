# 单位 v2 重建报告（弩兵 / 豺狼人战士 / 斥候）

日期：2026-11-02　范围：`单位/产出/联盟/方块人_弩兵.glb`、`单位/产出/野怪/豺狼人战士.glb`、`单位/产出/野怪/豺狼人斥候.glb`
基线：`单位/产出/_history/v1/`（原仓库 GLB 原样备份）

## 0 一句话结论

三件全部按**方块人**语言重建：弩兵修掉"圆球绕弩"（那其实是 v1 的左手方块）、把弩做成真正的重弩；
豺狼人战士 / 斥候改成**方块截面 + 平面着色**的兽人，战士加重鬃冠/骨刺/刚性流星锤并把攻击改成"举过头→砸下"，
斥候改成**双持宽刃猎刀 + 斜背标枪 + 双羽**。五件数值门全部落在预算内，差异化和武器可见性两项新增门槛均通过。

## 1 三个原始问题的根因与修法

### 1.1 弩兵"弓弩上有个圆球不停旋转"

**根因不是道具，是左手。** v1 的手是一块约 **0.20 m** 的方块，块心偏离腕骨；走动作里腕骨有旋转，
方块就绕着手腕（也就是绕着弩身）扫。把 `hand_L.head → weapon.head` 的距离量出来是**恒定 0.0683 m**
—— 手骨没离开弩，离开的是**手的几何**。

**修法（三道一起上）**

1. 手改成 **0.086 m 的包杆拳块**，拳心直接落在弩身轴线上（`palm/fist` 不再是一个挂在腕外的大方块）；
2. `walk` 动作里把 `shoulder/upperarm/forearm/hand` 与 `weapon/prop_bolt` 的旋转、位移全部锁回 rest
   —— 行军时双手端弩不摆臂；
3. 弩身重新做成"有弩臂/弦/弦枕/踏环/上膛矢/蓝箍"的重弩，手有明确的握点。

**实测**：walk 全帧 `hand_L ↔ weapon` 距离 **0.0683 m 恒定**；QC 连续帧不再出现绕弩旋转的块。

### 1.2 豺狼人"种族特征不清晰"

v1 的头是"方头 + 方管吻"，耳朵是两片薄三角，没有鬃、没有颈毛、没有可见獠牙；
两兵种的头/躯干/四肢/尾 100% 同几何。

**修法**

- 头改成**一条沿 Y 的连续放样**（后颅 → 颅顶 → 吻根 → 鼻头），方块截面 + 倒角，不再"两个方块对接"；
- 大圆耳（方块耳，根埋在颅骨里，从耳骨枢轴起，避免转头时整只耳飞出去）；
- 上/下獠牙各两颗，开口角可见；鼻梁皱纹、斜切暗眶 + 琥珀眼点；
- **3D 鬃冠**（6 片楔形毛，从中额一直压到肩背）+ **环状颈毛**（10 段毛环 + 10 束垂毛）；
- 方块四肢（4 点截面）、平底大脚掌 + 三爪；尾尖白毛。

### 1.3 战士"攻击动作幅度太小"

v1 的流星锤锤头在 rest/攻击里都拖到地面（z≈0.05），攻击读成"低位横扫"；v2 量到的手部弧线虽然不小，
但锤头被身体挡住。

**修法**

- 流星锤改成**刚性单骨**（handle + chain + head 全部绑 `weapon.R`），不再让链条骨在攻击里乱折；
- 在 attack 动作里给 `weapon.R` 写局部 Z 旋转关键帧：`0° → 150°（举过头）→ 95° → -20° → -45° → 0°`；
- 躯干/骨盆放大 ×1.42、右臂 ×1.52（保留原有手部路径）。

**实测（锤头网格）**：攻击全程 z **0.45 → 1.82 m**（垂直弧 **1.37 m**），手部 z 0.95 → 1.57（0.62 m）；
idle 锤头最低 **0.219 m**、walk **0.205 m**、attack **0.451 m**，全部 ≥0.15，不再拖地。
RTS 机位能看到"举过头 → 砸到左前方"的完整弧线。

### 1.4 斥候"匕首太小太细"

v1 匕首刃长 0.24 m、宽 0.052 m、末端 0.010 m（64 px 高时约 0.3 px），且与腿同明度。

**修法**

- 改成**双持**：主刀刃长 **0.41 m**、宽 **0.108 m**、厚 **0.052 m**；副刀 0.90 比例、护手位前下 45°；
- 刀身 `steel`、刀脊 `steel_light`、柄尾骨环、柄上红布；与毛色明度差 **0.185**（steel 0.601 vs fur 0.416）；
- 副刀从"朝下"改成"前下 45°"——朝下时 rest 刀尖只有 z=0.142，且会拖地。

**实测**：RTS 武器投影 **10.87%**（门槛 ≥8%），walk 武器最低 **0.292 m**、attack **0.384 m**。

## 2 同种族差异化（战士 vs 斥候）

| 高度带 | 战士 | 斥候 |
|---|---|---|
| ① 头颈 | 大颅 + 长鬃冠（6 片）+ 大圆耳 + 上下獠牙 | 小颅 + 窄吻 + **红/骨白双羽** + 短耳 |
| ② 躯干肩 | **左肩两层铁甲 + 三根骨刺**；斜挎骨串 | **左肩短披 + 斜背标枪**；单条皮索 + 两颗骨牙 |
| ③ 下肢/武器 | 刚性流星锤（锤头 0.225，投影 8.39%） | **双持宽刃猎刀**（投影 10.87%）+ 绑腿 |

- **剪影差异**：RTS 40°、96 px 高，`Silhouette Δ = 35.1%`（门槛 ≥30%）；
- **比例差异**：肩宽/身高 战士 0.66/1.906 = **0.346**，斥候 0.54/1.84 ≈ **0.293**，差 **18%**（门槛 ≥8%）；
- 没有用整体缩放做体型差 —— 斥候的腿长/身高、肩宽/身高都单独调过。
- 部落色：战士 **3.18%**、斥候 **4.28%**（目标 3~5%），三带分布（头羽/肩披/腰布/臂环）。

## 3 风格与材质

- **方块人**：所有有机体改成 4 点截面 + 平面着色；CC 只保留给"必须圆"的头骨/肩甲弧面，
  且**永不与倒角叠加**（v1 的耳朵 424 tri → 160 tri 就是这条的代价）。
- 硬表面：倒角 1 段（8–10 mm）；软体：0 倒角 + 平面着色；倒角只给甲片/武器。
- **材质干净**：共用 256² 纯色图集 `产出/图集/单位色板.png`（40 格，最近邻采样，UV 取格心），
  联盟 `主体 + team + team_trim`，野怪 `主体 + M_tribe + M_eye`；材质名与引擎 `zone_of()` 完全兼容。
- **与建筑同一套染色语言**：联盟蓝 `#2E5FB4` + 金 `#F1CD79`，胸兜/背兜用建筑同款"盾 + 三尖冠"徽记；
  野怪用部落红 `#8C3A2A` + 骨白，三爪纹与王冠的三尖同构。
- **资产不重**：弩兵 8,658 tri / 战士 3,992 / 斥候 3,582，均在预算内；单件网格 3 / 4 / 4 个，材质 3/3/3。

## 5 未达成 / 取舍（如实写）

1. **弩兵正面 team 9.56%**，略高于单位规范 6~8%；RTS 机位 **8.97%** 落在**建筑** 6~9% 区间内。
   胸兜是识别主面，再收会读不到；按 §9 登记为已知偏差（比 v1 步兵 13.99% 接近规范）。
2. **流星锤是刚性的**：链条骨（chain.01–03）保留在骨架里但不再参与蒙皮。
   好处是攻击弧线完全可控、锤头不再拖地；代价是没有链条的二次摆动。方块人尺度下链条本来也读不出。
3. **豺狼人的头偏大**（RTS 识别优先），正面近看会有"大头兽人"的玩具感；
   这是刻意的 RTS 剪影取舍，近景 QC 保留。
4. **斥候的标枪让包围盒高度到 1.919 m**，身体本身约 1.84 m；标枪是竖向识别点，不砍。
5. 未做 LOD、未加法线贴图 —— 与既有单位管线一致。
6. `unit_weapon` 的武器投影是 **RTS/idle 口径**；如果引擎在 rest（无动画）下取景，副刀/锤头仍然可见，
   但 warrior 的 rest 锤头 z≈0.156，刚好在 0.15 线上。
