## 3 坐标与归一化

1. 1 世界单位 = 1 米；Blender +Z 向上；**正面 +Y**（导出后 Godot 为 −Z）。
2. 脚底 z=0 **严格**；原点在占地中心（不是包围盒中心）。
3. 归一化顺序固定：\`finish_geo() → normalize() → rig() → bind()\`。
4. 归一化后必须打印 \`[zmin]\` 前四名，**最低件必须是脚趾/趾垫**（武器垂到地下会把整只顶起来）。

## 6 动作标准

| 项 | 值 |
|---|---|
| 帧率 | 30 fps（\`export_anim_slide_to_zero=True\`） |
| idle / walk | 循环，**首末帧逐骨矩阵差 = 0** |
| attack 命中帧 | 40%（±3%）：战士 40.7%、斥候 38.1%、步兵 40.7% |
| hurt | ≤ 0.35s，可被任意动作打断 |
| death | 停最后一帧；**末 0.4s 绝对静止** |
| 根位移 | 除白名单外 = 0 |
| 姿态算法 | 手/脚落在**目标点**（IK），不手调角度；武器杆直接写世界朝向 |

姿势约束（做动作前先量）：联盟臂展 **0.63~0.68m**、野怪 **0.64m**；
双手持械时副手握在杆尾（grip2 = −0.095），两手都靠近中线，否则肘部外翻、双臂绞成一团。

## 7 新增一个单位（8 步）

1. 抄 \`野怪/gnoll.py\` 或 \`联盟/unit_步兵.py\` 的骨架段，改 \`J\` 关节表（**先定关节，再定部件**）。
2. 写部件表（一条数据一行），加 \`bone=\`（前缀表覆盖不到就补表）。
3. \`run_<名>.py\`：建体 → \`normalize\` → \`rig\` → \`bind\` → 打印 \`[zmin]\` 与面数。
4. 跑一次 \`preview.py\`（或 \`run\` 的前半段），看三视图，改到剪影成立。
5. 写动作：先 BASE 姿态，再 attack（先定命中帧），最后 idle 的小事件。
6. 跑 \`audit.run()\`，**十项全绿**（联盟允许 ⑦ 按 §9 记录偏差）。
7. 出 3 张 QC（同机位同三点光）+ 各动作 6 帧连续条。
8. \`dump_table.py\` 重生成 \`文档/对照表.md\`，然后 \`git commit\`。

## 8 验收门槛（十项，来自 \`库/audit.py\`）

| # | 项 | 硬门 |
|---|---|---|
| ① | 零权重 / 影响数 / 归一化 | 必须 \`zero=0 max_inf≤4 unnorm=0\` |
| ② | 脚底 z=0 | \`|min_z| ≤ 0.002\` |
| ③ | 正面 +Y | 面部特征件重心 y > 全身重心 y + 0.02 |
| ④ | 动作名 + 循环首末一致 | 六个名字齐全；loop Δ < 1e-4 |
| ⑤ | 根位移 | 白名单外 < 0.002 |
| ⑥ | 三角面 | 在 §4 区间 |
| ⑦ | 换色位占比 | 在 §4 区间（偏差须在 §9 登记） |
| ⑧ | 极限帧穿模 | 0 处（武器**只查锤头/链条**，握把与手心重叠是设计如此） |
| ⑨ | 趾行三点 | 膝前顶 + 跗关节后收抬高 + 趾尖 z≈0.05 |
| ⑩ | 三处微动 | jaw/ear/tail 四元数极差 > 1e-4 |

## 10 与引擎的接口：glb 放进去**不等于**能用

\`\`\`
① 放文件    美术/模型/<分组>/<名>.glb                     ← 已有：方块人/ 与 野怪/
② 重导入    godot --headless --path . --import           ← 少了这条，运行时报找不到模型
③ 登记单位  代码/配置/单位表.gd 里加一个 UnitDef 块        ← 必须有，否则场上不会出现
④ 染色键    代码/美术/调色板.gd 的 colors 加 "tribe"      ← 仅野怪需要
\`\`\`

**③ 的最小字段集**（照 \`footman\` 抄）：
\`id / display_name / kind / model_path / anim_set / height / body_radius /
max_hp / armor / attack_damage / attack_cooldown / attack_range / move_speed\`。
动作名**不需要**登记：引擎按名播放，缺失走降级链 \`attack→shoot→cast→walk\`、\`death→hurt→idle\`。

## 13 同种族多兵种：差异化（硬性）

> 起因：豺狼人战士 / 斥候共用同一份 `J` 关节表与 `torso()/leg()/head()/tail()`，
> 头/躯干/四肢/尾 **100% 同几何**，差异只落在"肩饰 + 武器"，而武器在 RTS 俯角下不可辨
> （匕首刃末端 0.010m，64px 高时 ≈0.3 像素；锤头拖地且与腿同明度）。
> 完整诊断与实施细则见 `文档/建模交接手册.md` §6。

### 13.1 三条硬指标（同种族 ≥2 个兵种时生效）

| # | 指标 | 门槛 |
|---|---|---|
| A | 识别点 | **≥3 个，且分布在三个高度带**：① 头颈 / ② 躯干肩 / ③ 下肢+武器。判据：RTS 图缩到 96px 高仍可指认 |
| B | 武器可视性 | 投影占比 **≥8%**（RTS 机位，口径同 ⑦）/ 主件最小厚度 **≥0.05m** / 最低点离地 **≥0.15m** / 与相邻身体件明度差 **≥0.15** |
| C | 剪影差异 | 同种族两两比对，RTS 机位 96px 剪影，**Silhouette Δ ≥ 30%** |

体型差异**不许靠整体缩放**（`slim` 只收 X/Y，剪影形状不变）；
要拉开体型必须改比例：`肩宽/身高` 或 `腿长/身高` 至少一项差 **≥8%**。

### 13.2 差异化的有效性顺序（RTS 场景）

1. **竖向道具**（旗杆 / 长矛 / 图腾 / 背旗 / 高耸头饰）——俯角下会跳出身体轮廓进入背景，最强
2. 头颈与躯干的**结构性**轮廓差异（耳型、护肩形态、背鳍、背负物）
3. 动作节奏（步幅、idle 小事件）——只在动起来时有效，不能替代几何
4. 配色——换色位仅占 3~5%，**不得作为兵种区分的主要手段**

### 13.3 追加两项自检（原 §8 十项之外）

| # | 项 | 硬门 |
|---|---|---|
| ⑪ | 剪影差异（同种族两两，RTS 96px） | Δ ≥ 30% |
| ⑫ | 武器可视性 | §13.1-B 四项全过 |

仅 1 个兵种时写 N/A。新增兵种**必须与同种族已有兵种逐个比对**，不能只跟自己比。

> **v2 实测（2026-11-02）**：豺狼人战士 / 斥候 ⑪ 剪影 Δ **35.1%**、⑫ 武器投影 **8.39% / 10.87%**，
> 两条新增门槛均通过；三件全部改成方块人语言、脚底 0.000、权重 zero=0/max_inf=1/unnorm=0。
> 完整回执见 `自检报告.md` §8，根因与取舍见 `修订报告_v2.md`。
