## 4 四条硬经验（下一批别再踩）

1. **`slab` 是格、`loft` 是米**。v3 第一版把米传给 `slab`，整根枪的贴片跑到身体中线上，
   远看"枪在旁边、箍在腰上"。道具库现在只有一个 `_sl()` 入口，新道具一律走它。
2. **两层面贴在一起就会闪**。不是"看起来差不多"就行：外表面必须错开 ≥3 mm
   （`zfight` 的容差是 1.2 mm）。护膝高光、腰扣高光、枪缨、斜挎带的高光都是这么中招的。
3. **背面剔除不是可选项**。封闭体开 `use_backface_culling=True` 之后，贴片背面与母件正面
   同深度的那一类闪烁直接消失（眼睛/鼻子/腮线全是这一类）。
4. **手短就是手短**。肩距 0.76 / 臂长 0.40，两只手不可能同时掐在"指前"的杆上还让枪指正前
   —— 枪轴必然和身体朝向差 40~60°。v3 的解法是**侧身斜刺**：躯干反拧 40°，枪轴侧过来，
   两只手都落在杆上（掌-轴 0.000）。想根治只有一条路：基准 v2 把前臂加长一格。

## 6 重建

```bash
# 造型 / 自检（桥接或后台都行）
blender -b --factory-startup --python 库/run_vox.py -- 联盟/长枪兵 unit_长枪兵
blender -b --factory-startup --python 库/run_vox.py -- 联盟/弓箭手 unit_弓箭手
# 动作体检（六动作 + 逐帧探针 + 接触表）
blender -b --factory-startup --python 库/pose_vox.py -- 联盟/长枪兵 unit_长枪兵 --step 2
# 出货 glb 的独立复检
blender -b --factory-startup --python 库/audit_anim.py -- <glb> --pairs hands
# 图标（英雄姿势 + 步兵规格卡面）
blender -b --factory-startup --python 库/icon_vox.py -- 联盟/长枪兵 unit_长枪兵 docs/_tmp/icon/sp.png icon 0
python 库/icon_post_vox.py docs/_tmp/icon/sp.png assets/单位/联盟/长枪兵/长枪兵_图标.png
```

GUI 桥接（DSH 插件，TCP 9876）用 `build/bl_boot.py` 拉起、`build/bl_act.py act <脚本>` 发命令；`库/vox_studio.py`
是桥接里唯一安全的建/拍入口（不要在里面调 `wm.read_factory_settings`，会把插件一起重置掉）。
