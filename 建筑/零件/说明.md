# 可复用零件（13 件）

跨建筑、跨场景反复用的小件。全部由**同一份参数化代码**（`dl_kit` / `dl_parts`）按标准尺寸生成，
不是从成品建筑里抠出来的 —— 所以比例、材质、倒角口径和它们所在的建筑天然一致。

- 单位：米。原点在占地中心，**地面 z = 0**。
- 朝向：正面 +Y（导出后 −Z），与建筑同一约定。
- 材质：用桌面档调色板材质，**没打图集**。单件只有 1–5 个材质，不值得为它单独开一张图集。
- 用法：Blender 里 `Append` 或直接拖进 Godot；摆场、做新建筑、当遮挡物都行。

## 为什么不拆得更细

「台基 / 墙体 / 门墙 / 后场」这种**按系统拆**在这套资产里没有意义：引擎里没人会往场景里拖一块「石壳」。
真正会被反复用的是上面这些**尺度确定、位置自由**的小件。建筑内部的复用靠源工程的参数表
（`dg_layout.py` 这类，改一个数整座跟着动），不靠把成品切成块。

## 为什么锁杠在门正面

早期版本把门饰（线脚 / 门钉 / 门环 / 锁杠）的偏移写死在 −Y 一侧，
结果整扇门从外面看只有两道铁箍，装饰全在隧道里侧。2026-11-05 给 `door_leaf` 加了 `face` 参数修正。
**这是一条通用教训**：建模式 +Y 是正面，任何"贴在表面上"的细节都要显式声明朝哪一侧。
