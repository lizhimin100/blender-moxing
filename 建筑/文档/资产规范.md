## 1. 目录与命名

```
assets/
├─ 铁匠铺/                     ← 一座建筑一个目录，中文、不带版本号
│   ├─ 铁匠铺.glb              曲面细分版（宣传 / 转端游）
│   ├─ 铁匠铺_手游_近.glb       手游 LOD0（默认用这个）
│   ├─ 铁匠铺_手游_中.glb       手游 LOD1
│   ├─ 铁匠铺_手游_远.glb       手游 LOD2
│   ├─ 铁匠铺_低模.glb          20 材质未合图集的低模（对照 / 兼容）
│   ├─ 图集/                   主体.png · ORM.png · 自发光.png
│   └─ 说明.md                 这一份交付是什么、用哪个
├─ 兵营/                      同上
├─ 城镇大厅/                   同上（第三座；钟塔 + 后附楼 + 前庭台）
├─ 地形/                      不是建筑，是地表底材
│   ├─ 草地.png · 泥土.png     512² 无缝 Albedo（8bit RGB，无 alpha）
│   ├─ blender/_源文件/地形/地形材质.blend          节点源（terrain_grass / terrain_dirt）
│   └─ 说明.md
└─ _历史版本/                  铁匠铺_v6/v8/v9/v10 · 兵营_v1/v4（原样冻结，不删）
```

规则：

1. **版本号只出现在 `docs/` 与 `CHANGELOG.md`**，资产文件名永远不带 `_v10`。
   换版 = **覆盖同名文件**，不是新建目录。
2. **中文目录 + 中文文件名**（用户拍板：看得懂优先，打包出问题再统一改 ASCII）。
3. **材质名、节点名、脚本 class_name 保持 ASCII**：`team` / `team_trim` / `stone_mid` /
   `BS-主体` 这些是**接口**，引擎和换色脚本按名字找，改中文就找不到。
4. 后缀固定这几个，不要发明新的：`_手游_近 / _手游_中 / _手游_远 / _低模`。
5. 历史版本进 `_历史版本/`，**不删**（"改回上一版"要靠它）。
6. 代码目录 `blender/bs_v6/` 保留原样（用户明确：代码不需要中文化），
   但里面的**输出路径必须指向上面的中文目录**。

## 2. 单位、坐标、朝向

| 项 | 约定 |
|---|---|
| 单位 | 1 unit = 1 m |
| 原点 | 占地中心，`y = 0` 是地面 |
| 建模期 | X 右、Y 前（+Y 是正面）、Z 上（Blender） |
| 导出后 | 正面朝 **−Z**（glTF Y-up，`export_yup=True`） |
| 镜像 | `finalize()` 最后沿 X 镜像一次 —— 建模期 +X 在成品里是 −X |

> 近景相机（pshot）的坐标要取负 X，否则拍到的是背面。

## 3. 材质与图集（手游档）

**4 个材质 = 4 次 draw call**（原来是 20）：

| 材质 | 内容 | 说明 |
|---|---|---|
| `主体` | 17 个石/木/瓦/铁/金/煤/地面/草/沙/玻璃 | 512² 基础色 + 512² ORM（G=粗糙度，B=金属度） |
| `team` | 阵营主色 | 纯色，**换阵营只改它** |
| `team_trim` | 阵营辅色 | 同上 |
| `自发光` | 火焰 / 炭 / 窗光／门缝 | 同一布局的自发光图，强度统一 1.8 |

- 图集不是"缩图"，是**每格一块纯色 + 所有面 UV 钉在格心**。原模型没有贴图细节，
  钉死之后采样只取一个点，等于零成本拿到"逐材质颜色"。
- 格子布局在 `bs_atlas.ATLAS_ORDER`（**5 列 × 5 行**，512²，每格 102 px，色块内缩 22 px；用 23 格，后两格留空）。
  **改顺序 = 改 UV**，必须同时重新生成图集并重导。
- 格心采样 + 22 px 内缩：mip 掉到 1/8 也不会串到邻格。
- 兵营比铁匠铺多 `earth_dark` / `sand` / `glass` 三个材质，所以网格从 4×5 扩到 5×5 ——
  两座共用同一套布局，图集 PNG 各自一份（改一座不牵连另一座）。
- **材质名必须是 `主体` / `team` / `team_trim` / `自发光`**。模型自带的 20 个材质里本来就有
  `team`，新建同名材质会被 Blender 改名成 `team.001` —— 换色脚本按名字找，找不到就静默失效。
  `build_materials()` 里已经先删同名再建，GLB 回查里材质名带 `.001` 就是这里又漏了。
- 图集材质用 `Closest` 采样，避免线性插值把相邻格的颜色混进来。

### 想加细节时

图集是"每格纯色"，**没有逐面 UV**（所有面都钉在格心）。要加磨损 / 污渍 / AO：

- 轻量：在 `主体.png` 的格子里画脏迹 —— 只会让**整个材质**变脏；
- 逐面：得回到 `smart_uv()` 重新摊 UV，等于换一套图集方案（那时要改 `pin_uv`）。

### 地形底材（不是图集）

地面是**唯一有真实贴图**的一层，规则和图集相反：图集"每格纯色、UV 钉死"，
地面要"整张有内容、UV 连续平铺"。

| 项 | 约定 |
|---|---|
| 尺寸 / 格式 | 512²、8bit **RGB**（无 alpha）、sRGB |
| 平铺尺寸 | **8 m**（512 px → 64 px/m）；6 m 在 40 m 视野里有格子节奏 |
| 无缝 | UV → 4D 圆环（`R = 1/(2π)`，弧长 = 1 tile），Noise/Voronoi 全走 4D |
| 明度 | 地面是全包**最低一档**：草地 0.479 / 泥土 0.397（墙体 0.55–0.59） |
| 色相 | 只能从建筑调色板借（`moss` / `earth` / `sand`），不另起色系 |
| 采样 | Linear + mip；roughness 0.95、metallic 0、specular 0 |

细节见 `docs/地形/地形_报告.md`；生成脚本 `blender/bs_v6/tr_tex.py`。

## 4. 三级 LOD

| 档 | 判据 | 铁匠铺 | 兵营 | 城镇大厅 | 用途 |
|---|---|---|---|---|---|
| 近 | 全量（566 / 670 / 684 构件） | 14,614 tri / 1,018 KB | 17,440 tri / 1,249 KB | 18,324 tri / 1,275 KB | 默认 |
| 中 | 体积 ≥ 0.012 m³，去掉地面碎屑；**不再倒角** | 7,276 / 486 KB | 7,632 / 522 KB | 8,912 / 573 KB | 1/2 距离 |
| 远 | 体积 ≥ 0.22 m³ + 钟/尖顶/旗整组白名单；**道具整组去掉**，钟面刻度/指针/钟亭拱石/尖顶铅箍走 LOD2_DROP | 1,796 / 134 KB | 1,224 / 90 KB | 4,064 / 266 KB | 远景 |

三档材质数 4 / 4 / 4，**切档不重传贴图**。

> 城镇大厅的远景比兵营重：钟亭的柱、通口、钟、尖顶是一组"细杆撑大盖"的构件，
> 按单件体积筛会留下悬空的顶盖，所以 `LOD_KEEP_2` 把 `tw_ / bf_ / sp_ / flag_` **整组**保留；
> 钟面刻度/指针、钟亭拱石、尖顶铅箍这些 1–2 px 的小件再走 `LOD2_DROP` 剔掉，
> 远景从 5,476 压到 4,064。省不下多少面，但远景剪影不会散架 —— 这一条比面数重要。

三条硬规则：

1. **判据用包围盒体积，不用最长边**。瓦垄、旗布、横杆"又长又薄"，最长边够大，
   但视觉上只是几条线，占的面却不少。
2. **道具整组走或整组留**（`PROP_PREFIXES`）。按单件筛会把"磨石轮"留下、把支架丢掉，
   远景就出现一块浮在空中的圆盘。
3. **LOD1/LOD2 关掉倒角**。远景看不出 2 cm 的棱，倒角却会把大件面数翻 2–3 倍
   （14.6k → 6.3k 主要就是这一步）。

不用 Decimate：它会把硬边磨圆、把 UV 搅烂、把"这是门窗还是洞"的边界打散。
模型本来就是构件化的，**按构件筛**比按面筛干净得多。

## 5. 验收口径

| 检查 | 命令 | 通过线 |
|---|---|---|
| 错位 / 穿模 / 共面 / 悬空 | `bs_align.py` | `CLIP_CROSS 0`、`COPLANAR_UP 0`、`FLOAT 0` |
| 三角面预算 | 导出回执 | 近 ≤ 18k、中 ≤ 9.5k、远 ≤ 3.2k |
| 材质数 | 导出回执 | 手游档 ≤ 4 |
| 贴地 / 朝向 | 导出回执 | `grounded`、`front_ok` 均为 true |
| 阵营色可见占比 | `bs_teamshare.py` | 正视 6–9%，3/4 5–6% |

> `CONTAIN` 只做参考：大结构件的包围盒（旋转的屋面板）会把贴附件整个包住，
> 那不是"埋进去"。脚本已经把大件排除在判据外。

## 6. 导出流程

所有步骤都从 `build/assemble.py` 走（顺序有依赖，别打乱）：

```bash
python build/assemble.py             # 全跑：导出 → .blend → 体检 → 出图 → 图标
python build/assemble.py --only 图标  # 只跑名字带"图标"的步骤
python build/assemble.py --list      # 看步骤
```

单独跑某一步时：

```bash
# 手游档（图集 + 三级 LOD）—— 主交付
python build/bl_act.py act blender/bs_v6/export_mobile.py

# 标准档（低模 20 材质 + 细分 20 材质）
python build/bl_act.py act blender/bs_v6/export_blacksmith.py

# 出图（9 张）
python build/bl_act.py act blender/bs_v6/bs_shots.py

# 体检 / 阵营色
python build/bl_act.py act blender/bs_v6/bs_align.py
python build/bl_act.py act blender/bs_v6/bs_teamshare.py
```

- 通道是 DSH Blender 插件的 **TCP 9876**（`build/bl_act.py`）；9877 是宿主代理，本机通常没开。
- 建模脚本只定义一次形体：低模 / 细分 / 手游档都是同一次 build 的不同收尾，**不要复制模型代码**。
- 出图与报告进 `docs/<建筑>/v<版本>/`；`探针/` 放体检报告。

## 7. 踩过的坑（Blender API）

| 坑 | 现象 | 正确做法 |
|---|---|---|
| `image.pixels` 写的是**该图色彩空间的原始值** | 往 sRGB 图写线性值 → 整图暗一档 | 用 `_raw()`（hex/255）写，不是 `bslib.srgb()` |
| `image.colorspace_settings.name = ...` | 在写像素**之后**设，会把整张图清成黑 | 先设色彩空间，再 `foreach_set` |
| `pixels.foreach_set()` 之后不 `update()` | `save()` 出去全黑 | `foreach_set` → `update()` → `save()` |
| `clear_scene()` 连 Image 一起删 | 图集节点指针失效（`StructRNA removed`） | 图集落盘，每档从磁盘 `images.load()` 重新载入 |
| `filter_lod` 只是"不 join" | 被筛掉的构件留在场景里，且**没走 mirror_x**，飘在建筑外面 | 筛完必须 `bpy.data.objects.remove()` |
| `can_z()` 是坡棚板**底面** | 件"坐在棚面上"却整块埋进 0.17 的板里 | 按 `can_z + 板厚 / cos(坡角)` 放 |
| `extrude(..., origin=(u, v))` | v 是"沿第二个轴的起点"，不是偏移量 | 玻璃忘加 `wz` 会一直贴地 |
| 多边形顶点顺序 = 法线方向 | 顺序反了渲染成黑三角，肉眼只当阴影 | `ray_cast` 从相机打过去反查构件 |

## 8. 美术规矩（这套资产自己长出来的）

1. **只有一套纹章**：盾 + 王冠，`bs_model` 与 `br_model` 是同一段几何，改一处两座一起变。
   不要给某座建筑另画"更贴主题"的符号。
2. **旗帜同一套零件**：木杆 + 金端头 + 3 只铁吊环 + 底角流苏 + 徽记；
   挂点不同才换吊架（棚口 L 形铁吊架，墙面挑杆）。
3. **地面一层一个高度，不留薄片**：薄贴片（2–3 cm）在 RTS 相机下只剩亚像素，会闪。
   煤渣、草簇、碎石都必须是有厚度的实体。
4. **纯黑物件压在灰铺石上会读成一个洞**：煤堆要给木框（煤仓），不能只给一团黑。
5. **新加构件必跑 2–3 轮体检**：墙面已经有墙裙 / 腰线 / 檐口三条水平线，
   任何新件都要躲开它们（背墙横幅换了三版才落进去）。
6. **读不出语义的细节是负资产**：发光顶盖会读成"一块橙板"，锥形罩会读成"灯罩"，
   0.55 m 的铁砧立饰会读成"一根黑柱" —— 删掉比留着好。

## 9. 图标（UI 用）

图标**不是**"把模型按某个角度截一张"，也不是"透明底抠图"。它是 UI 资产，
和 LOD 远景（省面数）是两件完全不同的事。脚本：`icon_shots.py`（Blender 出 raw）
+ `icon_post.py`（系统 Python 合成 alpha 与背板）。

### 形态：卡面，不是抠图

现代 RTS / 策略游戏的建造图标基本都长这样：**主体占画面 75–85% + 非空背板 + 边框**。
透明底那张只适合 UI 自己有底板的情况；贴到任意深色界面上，深蓝屋面会直接糊进背景。

| 项 | 规定 | 为什么 |
|---|---|---|
| 尺寸 | 512² 母版 → 128 / 64（缩后补锐化） | 128 给建造按钮，64 给地图 / 快捷键格 |
| 底 | **暖石背板** `#988C78 → #16120E`，上浅下深 | 建筑是冷灰石 + 深蓝瓦，暖底是最大对比；上浅衬深屋面，下暗压亮墙脚 |
| 机位 | **方位 26°、俯角 24°**，正交 | 34° 只剩屋面、26° 以下立面被压平（`docs/图标/机位与背板.png`） |
| 取景 | 顶点逐个投影；**底边固定落在画面下方 5%**，横向上限 6% | 四边等留白会把旗尖切在画框上，切了旗的图标读起来像 bug |
| 布光 | 相机相对：主光左上偏前 + 右补光 + 背后轮廓光，AgX Punchy | 光源绑世界坐标时，换机位受光面就变 |
| 后期 | 底部渐隐 13% / 软描边 2 px / bloom / 暗角 0.42 / 投影 | 地台被画框切断时硬边像"模型被裁了"；软描边把浅色墙从亮底里分开 |
| 缩放 | LANCZOS + UnsharpMask(1.0, 55%) | 512 的细节直接缩到 64 会糊 |

### 三条容易踩的

1. `ImageChops.add(a, b, scale=...)` 的 `scale` 是**除法**，传 1.6 等于整张背板压暗一半。
2. Blender 自带的 Python **没有 PIL**，合成必须拆到系统 Python（`icon_post.py`）。
3. 图标用**细分版**几何出图（52.5k / 81k tri）——离线渲染，面数与运行时无关。

**新增一座建筑**：`icon_shots.py` 的 `targets` 里加名字 → 跑 → 跑 `icon_post.py`。
机位、背板、取景全是常量，**不要为某座建筑单独调** —— 一套图标里出现两个视角就是不合格。

## 10. 交付打包

交付物只有三样：**建筑资产 / 图标 / 资产规范**。

```
交付/
├─ 建筑/
│   ├─ 铁匠铺.blend            打包贴图，别的电脑直接打开
│   ├─ 铁匠铺_手游_近/中/远.glb
│   ├─ 兵营.blend
│   ├─ 兵营_手游_近/中/远.glb
│   ├─ 城镇大厅.blend
│   └─ 城镇大厅_手游_近/中/远.glb
├─ 图标/
│   └─ 铁匠铺_图标.png · 兵营_图标.png · 城镇大厅_图标.png（512 卡面）
└─ 文档/
    └─ 资产规范.md
```

### .blend 的三条硬性（`export_blend.py`）

1. **Pack Resources**：`bpy.ops.file.pack_all()` 把图集打进 .blend。
   GLB 天生内嵌贴图，`.blend` 不会 —— 不打包，换台电脑打开就是一片洋红。
2. **相对路径**：`save_as_mainfile(relative_remap=True)`，不写 `D:/测试一/...`。
3. **文件里带说明**：`bpy.data.texts` 里放一段"读我"，写清单位、朝向、4 个材质、怎么换图集。

回查口径（脚本自己跑）：重新打开文件，确认
`所有 image 都有 packed_file` + `材质数 == 4` + `对象 4 个（BS-/BR- 前缀）` + `落地 z≈0`。

### 归档不进展交付包

旧版本一律留在项目里、**不进交付包**，否则接手的人分不清该用哪个：

```
assets/_历史版本/   铁匠铺_v6/v8/v9/v10 · 兵营_v1/v4 · 万邦_v5
blend/_历史版本/    万邦_v5（v5 那套的 6 个 .blend）
blender/_归档/      废弃脚本、一次性探针
docs/<建筑>/历史/    旧版出图与报告
```
