## 1. 一句话

**一块石壳被凿开一道槽，槽的尽头两扇石门关着；门墙两端埋在土坡里，顶上是一道
塌掉的断脊 —— 它是从地底冒出来的，不是一段立在空地上的门。**

两次判词对应两轮改版：

| 轮次 | 用户原话 | 推翻的东西 |
|---|---|---|
| 第一轮 | "整体风格太像联盟势力的建筑，同时门都没关上" | 抬台基 + 外爬梯 + 断塔 + 对称门楼 + 半圆拱 + 三面蓝旗 |
| 第二轮 | "太方正了，这是从地底冒出来的入口，不要看着像某片废墟残余的门部分" | 矩形门墙 + 三级平台阶顶 + 露出台面的石壳 + 联盟蓝队色 |

## 3. 关键决策（为什么这么做，不是做了什么）

### 3.1 "从地底冒出来"是靠**关系**做出来的，不是靠加土

加了土坡不等于"埋"。三条一起做才成立：

1. **土坡必须高过门墙两端**（断脊两端 2.10–2.18 < 土坡 2.72–3.16）。差这一档，
   墙端就会露出一条方正的竖边，立刻读回"残墙"；
2. **前段土坡要没过石壳面**（1.38 → 1.58），只让压边露一条线。石台一露，
   读法就变成"平台上的门"；
3. **土坡后高前低**。一整条等高土脊会把门夹成"土墙里的一个洞"，而且土是画面里
   最亮的东西，会抢主角；前段塌下去，正面看到的还是石头。

### 3.2 门套是断的，不是画框

右柱只砌两段（上段塌了），过梁压在断口上。一个完整的矩形门套在 20–40 m 上就是
"一个门框"；断掉一角，它才变成"一处塌了的入口"。
门扇仍然是关死的（两扇 + 铜锁杠 + 门脚楔石 + 上沿 10 cm 黑缝）。

### 3.3 台阶为什么是 1.10 m 宽、0.40 m 高

26° 机位下，踏面可见深度 = `踏宽 − 踏高 / tan(26°)`。
踏高 0.48 / 踏宽 0.80 时这个值是**负数** —— 整跑台阶会读成一面竖墙。
1.10 / 0.40 才让每一级露出 0.28 m 踏面，加上亮鼻线，俯视才读得出"往下走"。

### 3.4 队色：三座都不是联盟蓝

`team` / `team_trim` 是引擎换阵营用的两个材质，**名字不能改**。但失落帝国是中立
废墟，套联盟的 `#2E5FB4` 会一眼读成"人族据点" —— 这是 v1 被判"太像联盟"的第一条。
现在三座（地牢入口 / 地下城入口 / 折壳入口）共用 `dl_parts.LE_TEAM_STYLE`：
**氧化铁红 `#743A2E` / 灰骨粉笔 `#A99578`**，铜绿与铁的金属度也一起压到 0.18 / 0.45
（EEVEE 没有环境贴图时 metallic 0.7–0.9 会渲染成纯黑）。

坑：`dl_kit` 里的 `grate()` 内部会再调一次 `all_materials()`，那一步会**按 PALETTE
把 team 刷回蓝色** —— 覆盖必须放在所有零件建完之后；手游图集档还要单独再套一次
（`bs_atlas.pack` 会重建 team 材质）。两处都接同一个来源。

队色只做**两道**（规矩：一座不超过两道横线）：前庭中带（连续跨三级台阶 + 槽底，
水平面 → 俯视主力）+ 冠顶漆带 / 门楣横线。

### 3.5 组件化

- **`dg_layout.py`**：唯一改数字的地方。改 `open_hx` 一个数，过梁 / 门扇 / 门套 /
  门槛 / 踏步高度一起动（踏步高度由 `(石壳面 − 铺石面) / 级数` 派生）。
- **`dl_parts.py`**：失落帝国共享零件库 —— `u_body` / `step_run`（踢面踏面分材质）/
  `door_leaf`（**`ang` 一个参数就能开门**）/ `lock_bar` / `column_ruin` / `mound` /
  `bone_long` / `root_strands` / `brazier_tipped` / `restyle`·`apply_team_style`。
- **`dg_model.py`**：只装配。`Model(parts=("door",))` 可只建两扇门。

### 3.6 新增材质 `ancient_mid`（图集第 44 格）

`ancient`（Y 0.116）与 `ancient_dark`（Y 0.019）差 6 倍，中间缺档 —— 一套只有两档的
石头在俯视里就是"双色块"。补 `ancient_mid #454B54`（Y 0.076）给石壳 / 断脊 / 踢面。
**追加在 `ATLAS_ORDER` 末尾**，前 43 格索引一个都没动。

## 5. 已知取舍

- **队色只有 0.7–2.2%**（废墟类通过线是 5% 上下）。刻意的：中立废墟不是玩家据点，
  只留"远征队的记号"两道；也让蓝/金彻底不进剪影。
- **正面几乎看不到队色**（0.71%）：土坡把槽口的队色中带挡掉了一半。这是"埋"的代价；
  俯视 2.15% 仍然读得出归属。
- **土坡占了画面 40%**。它是"从地底冒出来"这句话的支点，但也把模型从"建筑"拉向
  "地形"。如果游戏里要和纯地形区分，只能靠那圈亮压边和断脊。
- **门是关的**，拍不到"走进去消失"。门扇组件化（`dg_layout.door_open` 一个数），
  要拍开门就改这个值重导一次。
- **槽底只有 0.8 m 深**（台阶占了 3.3 m）。再深，26° 机位下槽底会被上一级踏面挡住。
