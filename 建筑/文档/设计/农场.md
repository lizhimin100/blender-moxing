# 农场 v2 · 报告：石砌仓塔 + 真正的谷仓大门

> 任务：用户反馈两条 ——「筒仓太像现代了」/「没看到门在哪里，或者说不明显」。

## 一、筒仓为什么"太现代"：三条独立的病因

v1 的筒仓是 φ2.90、8.0 m 高的**直筒十二边形** + 三道蓝箍 + 金属爬梯与护笼 + 现代通风帽。
用户说"太像现代"，对照参考图（一座**石砌圆塔 + 木锥顶 + 小方窗**），病因有三条，
每一条单独拿出来都足以让它读成"水泥筒仓"：

| # | 病因 | 改法 |
|---|---|---|
| 1 | **三道蓝箍**：等距、等宽、通体一圈，这是钢板筒仓的加强箍语言 | 改成**两道深木腰箍 + 一道队色布带**（布带上下的金线把它钉住，读作"绑了一圈布"） |
| 2 | **被磨成圆柱**：十二边形相邻面夹角 30°，低于 `shade_auto` 的 32° 阈值 —— 整座塔被"平滑"掉了 | 石塔整组走 `flat=True`，保留十二棱硬边 |
| 3 | **工业附件**：金属爬梯 + 两道半圆护笼 + 锥台通风帽 + 金球 | 全部删掉。换成**石砌基座 + 石檐口 + 木锥顶 + 铁风向标 + 队色飘带** |

另外三件事让它"像一座塔"而不是"一根筒"：

- **正面开一扇门**（0.72 × 1.70，石砌门套 + 阶梯拱 + 队色门扇 + 两级踏跺）；
- **五个小方窗**（正面 1 / 外侧 2 / 背面 1 / 斜前方 1，木框 + 冷玻璃 + 石窗台）；
- **四个鸽舍洞**（上部一圈 0.19 × 0.25 的深色小洞 + 小石台）—— 鸽舍塔的中世纪读法。

尺寸：φ3.16（SR 1.58），基座 0.10 → 1.50（从**场地**起，不是从石台 —— 塔基前缘比石台多出
0.4 m，从石台起会悬空），筒身 1.50 → 6.98，石檐 6.98 → 7.22，木锥顶 7.22 → 9.22（48° 坡），
旗到 10.11。v1 的 11.48 压到 10.11，高:宽从 0.74 变 0.66 —— 更矮更"压得住"。

锥顶坡从 v1 的 36°（1.60 高 / 底 1.88）改到 **48°**（2.00 高 / 底 1.78）：
36° 在俯视角下读作"蘑菇帽"，48° 才是一条明确的山脊线。

## 二、门"不明显"：一个真 bug + 三条读法

### 2.1 真 bug：门洞和门扇差了 0.8 m

v1 的墙上门洞按 **x = 0** 开（`sgn * GATE_W`），而门柱 / 门楣 / 门扇都按 **x = 0.80** 摆。
结果：

```
门洞     −1.80 … +1.80      （中心 0）
门扇     −1.00 … +2.60      （中心 0.80）
        ↑ 左边 0.8 m 是**空缝**（能看到屋内）      ↑ 右边 0.8 m 压在墙上
```

v1 的报告里只记了"门柱没跟门的中心走"，修了门柱，**没修墙上的洞**。
现在门洞、门柱、门楣、门扇、门牌、台阶全部从同一个 `gx = 0.80` 取值。

### 2.2 三条读法

| 层 | v1 | v2 |
|---|---|---|
| 门套 | 亮木（`wood_warm`）两条竖线 + 木门楣 | **石砌**：两根 0.34 × 0.46 的石柱 + 0.32 高的石门楣，凸出墙面 0.17 |
| 门扇 | `wood_dark`（#3E2718），和墙面 `wood_mid`（#5F3D1F）只差一档 | **`wood_warm`**（#9B6236），配 5 根中棕竖板条 + 2 道深木横档 + 1 根 Z 形斜撑 + 队色封条 + 3 只铁合页 |
| 门楣 | 贴一块 2.42 × 0.05 的薄蓝板（凸 6 cm，在这套光照下完全读不出厚度） | **门楣石梁分三段，中间一段换材质**（2.64 宽，上下各高 2 cm、前后各凸 1 cm，边缘自带一条硬阴影）+ 一道金线 |
| 地面 | 一块 `door_sill` 悬在石台外侧 | 两级石踏跺（0.42 / 0.21）+ 门前渐窄的石板小径 |

**没有再试"半开门"**：两扇各 1.77 宽，往院子一开就压到田垄和作物上（左扇 52° 时
门扇末端到 x 0.08，正好压在第三条垄上）。谷仓大门在 RTS 尺度上就应该是一整块。

### 2.3 顺带修掉的三处

- **盾徽埋在墙里**：`crest(..., BY - 0.04, ...)` 的中心写在墙面内侧 4 cm，
  整枚徽记在墙里，主图一个像素都没有。改成 `BY + 0.02`。
- **腰梁和门楣连成一条**：4.34 的腰梁 + 4.00–4.36 的门楣匾，中间只隔 0.02，
  从正面看是一条 0.7 m 宽的粗蓝带。腰梁在门洞上方**断开**成左右两段。
- **门楣匾被石梁埋掉**：v2 第一版的匾中心写在 `BY + 0.13`，石梁外表面在 `BY + 0.17`，
  匾整块在石头里 —— 和盾徽同一个坑。最后改成"石梁换材质"，从根上避免贴片。

## 三、阵营色：从 6.10 / 4.73 提到 8.57 / 6.02

v1 的染色靠"三道筒仓蓝箍 + 通长腰梁"。筒仓改成石塔后：

- 三道蓝箍 → 一道布带，**少了约 2.4 m²**；
- 腰梁在门洞上方断开，**少了 0.96 m²**。

补回来的五处（全部贴结构线，不做零散贴片）：

| 高度带 | 位置 | 面积 |
|---|---|---|
| 中 5.14–5.66 | 石塔的队色布带（加宽到 0.52，上下金线） | ~5.0 m² |
| 中 2.28–2.48 | 石塔基座之上的窄腰带（"塔是谁的"） | ~1.6 m² |
| 低 0.62–2.32 | 塔门扇整块染队色（0.72 × 1.70） | ~1.2 m² |
| 低 0.62–1.06 | 谷仓门柱箍（加高到 0.30）+ 两扇门板的队色封条（0.64 × 0.44） | ~1.4 m² |
| 中 2.9 | 水井的木架横梁（hero 视角前景） | ~0.3 m² |
| 顶 9.9 | 塔顶飘带（加大到 0.62 / 0.40 / 0.20 三段） | ~0.3 m² |

实测：**正视 8.57% / 3-4 视 6.02%** —— 两个视角都进了 6–9%（v1 的 3-4 视只有 4.73）。

## 四、这一轮修掉的脚本 bug（都是量出来的）

1. **门洞中心和门扇中心差 0.8 m**（见 2.1）。
2. **门扇子件的偏移方向**：右扇 `rot = π` 时，如果把厚度偏移 `v` 乘进局部轴，
   所有板条会翻到门扇**内侧** —— 近景里是一块光板（调试了三轮才发现）。
   改成 `v` 一律沿世界 +Y。
3. **盾徽 / 匾额的中心写在墙面内侧**：贴面件的中心必须在墙面**之外**。
4. **十二边形被 `shade_auto(32°)` 磨成圆柱**：夹角 30° < 32°。石塔整组走 flat。
5. **石塔的窗 / 鸽舍洞撞谷仓侧墙窗**：塔在 y −0.03…3.13，侧墙原来的窗在 y 0.45，
   改成 −0.75。
6. **鸽舍洞的石台顶穿屋面封檐板**：塔心 5.66、180° 面在 x 4.13（比谷仓右墙 4.20 还靠里），
   180° / 240° 两个面本来就陷在墙里 —— 只做朝外的四个面。
7. **`gate_step` 从 z=0 起**：埋进夯土 0.16，白名单里加 `("gate_", "yard_")`。
8. **腰梁和门柱相交 0.14**：腰梁缩到门柱之外 0.06。

## 六、留下的

- **石塔的队色布带偏宽**（0.52，占塔身高度 8%）。视觉上略重，但它是 hero 视角唯一
  大面积可见的染色带 —— 收窄会让 3-4 视掉回 5.6% 以下。取"识别优先"。
- 筒仓的锥顶是十二边形（`revolve` 12 段），**细分时必须排除**；石塔整组还要走 flat。
- 塔与谷仓的咬合深度 0.12（筒身左缘 4.08 / 右墙 4.20），屋面右出檐 0.42 会插进塔身 ——
  这是"塔贴着谷仓、屋面顶到塔"的结构关系，align 里已作为白名单（`("tower_", "roof_")`）。
