# 酒馆内部 v1 · 报告

> 第十二座资产。**场景**，不是房子：一个被剖开的房间。
> 代码 `blender/bs_v6/tv_model.py` · 体检 `docs/酒馆内部/v1/align.txt` · 图 `docs/酒馆内部/v1/`

---

## 1. 一句话

**正面整面墙拿掉，两侧墙从后往前逐段降低（3.38 / 2.56 / 1.62 与 3.38 / 2.80 / 1.92），
断口做成浅色石芯 + 一道暗线的"剖面"；屋里是一条吧台、一座石壁炉、三张桌、一部上二楼的木梯，
正中一盏六支蜡烛的铁环吊灯。**

和九座人族建筑同一套审美：暖木三档 + 石灰墙 + 铜 + 队色；但语言从"外立面"换成了"平面布置"。

---

## 2. 平面（俯视）

```
        ┌──────────── 后墙（横幅 + 酒架 + 壁炉）────────────┐
        │  吧台（-4.55…-0.75）      壁炉（1.55…4.25）        │
        │  桶 ×3 / 酒瓶 / 高脚凳 ×3   火 + 烟囱胸墙 + 铜锅     │
   左墙 │                                                   │ 右墙
  （梯）│   长桌 ×1（2.55×0.98）    方桌 ×2（1.34 / 1.30）   │（逐段降低）
        │   条凳 / 桌旗 / 杯盘烛                               │
        └──────── 前墙只留两个墙墩 + 两根前柱 + 前檐梁 ────────┘
```

- 走道：从门口（+Y 正中）直对吧台，两侧是桌 —— 一条清晰的"进门 → 点单"动线；
- 视觉焦点：吊灯（俯视一圈亮点）+ 壁炉火（暖色）+ 后墙横幅（队色大块）；
- 左下角：木梯（6 级 + 平台 + 扶手）把角落填满，也给一个"往上"的方向；
- 右下角：两只桶 + 木箱 + 麻袋，压住空角。

---

## 3. 关键决策

1. **剖切要"读作剖面"**：每段墙顶有 6 cm 浅色石芯 + 一道 2.5 cm 暗线（`wall_cut` / `wall_cut_line`），
   三段墙高故意左右不同（3.38/2.56/1.62 vs 3.38/2.80/1.92），俯视才有台阶感。
2. **梁只留两根横梁 + 一根前檐梁**。三根横梁 + 通长脊檩会把房间切成四个格子，俯视全是木条。
   中段切口加两根通高壁柱，第二根梁才"有支撑"（不是悬空）。
3. **吊灯挂在梁下**：铁环 r 0.94、六支蜡烛、三根吊链；环上再加一圈内环和六根辐条 ——
   俯视是一个有厚度的铁环，不是一条线。
4. **壁炉是"体"**：炉体左右 + 上楣 + 内壁 + 炉顶 + 炉底 + 炉台 + 烟囱胸墙，
   炉口 1.44 宽 × 1.32 高，火在炉膛里（0.70 高，不穿炉顶）。
5. **队色**：后墙横幅（竖直，正视 7.17%）+ 两条桌旗 + 两侧墙小横幅 +
   吧台前沿漆线（水平）——3/4 与俯视都靠水平面，5.1 / 4.4%。

## 5. 踩到的坑

1. **地板板面必须真的到 0.28**：地板条中心写 `F0+0.055` 时顶面只有 0.25，
   所有落地家具都悬空 3 cm —— 体检一次报了 14 个 FLOAT，根因只有这一条。
2. **吧台台面与立面差 5 mm 也算悬空**：台面厚 0.11、中心 `BAR_H-0.005` 才贴住 1.10 的立面上沿。
3. **酒架会穿横幅**：横幅从 3.16 垂到 1.14，正好盖住 1.55 / 2.02 两层的酒瓶；
   把酒架拆成左右两段、给横幅让出中间 —— 比把横幅挂高更像真酒馆。
4. **炉火会穿炉顶**：0.86 高的火从 0.52 起，顶到 1.38；炉口内顶 1.32。压到 0.70 才对。
5. **低矮建筑不能套三步脚手架**：3 × 2.2 = 6.6 m，比 3.49 m 的房子还高，SCAF_OVER 直接判失败。
   `cs_kit` 现在对 H < 5.2 m 的建筑允许 1–2 步。
