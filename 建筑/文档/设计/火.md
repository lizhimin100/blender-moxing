# 火载体四件套 v1 · 报告

> 第十三至十六件资产（道具）。**四个载体 + 同一套火**：
> 营火 / 火把 / 火炬 / 火堆，分开摆放，也可以把 `flame_*` 拆出来挂在别的载体上。
> 代码 `blender/bs_v6/fr_model.py` · 图 `docs/火/v1/`

---

## 1. 为什么是四件

用户要的是"分开摆放或建模，方便直接套用或利用不同的火载体模型"。
所以不是做四堆火，而是把火拆成**载体 + 火**两层：

| 资产 | 载体 | 尺寸（m） | 火 |
|---|---|---|---|
| 营火 | 石圈 9 块 + 4 根交叉柴 + **三脚架吊锅** + 备柴 | 2.05 × 1.56 × 1.08 | 0.52 高，5 外焰 + 3 中焰 + 芯 |
| 火把 | 石座 + 木杆 + 承托盘 + **布头**（深木 + 浅布带 + 铁箍） | 0.48 × 0.48 × 2.52 | 0.40 高 |
| 火炬 | 八角石座 + 三铁腿 + **铜绿火盆** + 三吊链 | 0.96 × 0.96 × 2.12 | 0.78 高 |
| 火堆 | 8 块大石 + **两层原木**（3+2+1）+ 两根斜支架 + 队色小旗 | 3.17 × 2.72 × 1.96 | 1.30 高 |

## 2. 火的三段结构（一套代码，四个载体共用）

`dl_kit.flame()`：**5 条外焰（暗橙，0.34–0.66 高，半径 0.26–0.42r）+ 3 条中焰（橙，0.62–0.80 高）+ 1 根芯焰（亮黄，1.0 高）**。

- 外焰必须**短、散、歪**：同高的几条外焰会连成一块橙色板（第三次踩这个坑，见 `建模规则.md` C38）。
- 芯焰只占整朵火的 1/3 高度、0.15r 半径，远景才读得出"火心"。
- 每条火舌是 7 边回转体 + 3 段收分，末端按 `lean` 往一侧卷 —— 不做球、不做贴图。

四个载体的火只是**缩放 + 种子**不同，换载体不换火。

- 体检（四件全）：**CLIP_CROSS 0 / COPLANAR_UP 0 / FLOAT 0**（火堆有 1 对炭块残余，俯视不可见）。
- 材质：全部 ≤ 4 —— 营火/火把是 2 材质（主体 + 自发光），火炬/火堆 3 材质（多一个 `team`）。
- 火把与火炬是**左右对称**的，`front_ok` 用 0.90 的比值判（不是 1.0）。

## 4. 设计取舍

1. **火把做成"落地杆"而不是"墙上挂钩"**：墙上挂钩单独立不住，作为资产必须先能摆在场景里。
   杆头留了一个铁环（`tr_ring`），要挂墙时把石座和杆去掉即可。
2. **营火的三脚架是它与火堆的分水岭**：没有三脚架，两个都是"一圈石头 + 一堆火"；
   有了吊锅，营火才读作"有人在这里做饭"。
3. **火堆给了一面队色小旗**：四件火里只有它和火炬带队色；营火/火把保持中立，
   这样同一堆火可以给任何阵营用。
4. **不做建造动画**：建造系统服务建筑；四件火是道具，硬套脚手架会变成"给篝火搭架子"。

## 5. 复现

```bash
blender -b --python blender/bs_v6/fr_quick.py      # 四件快速看片
blender -b --python blender/bs_v6/dl_export.py     # 低模 + 细分
blender -b --python blender/bs_v6/export_mobile.py # 图集 + LOD
blender -b --python blender/bs_v6/dl_shots.py      # 交付出图
```
