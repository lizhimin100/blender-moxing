# 折壳入口 v2 · 巨壳残片

> 2026-11-05 ／ 脚本 `blender/bs_v6/fs_model.py`（v1 在 `_历史版本/fs_model_v1.py`，
> 全部产物在 `_历史版本/折壳入口_v1/`）

## 0. 一句话

**一片巨壳的残片，半埋在山里；帝国在它弧面上凿了一道门，又给门套了一圈方门楼。**
壳是"天然"的、斜的、断的；门楼是"人造"的、正的、浅色的 —— 两种语言叠在一起，
轮廓才立得起来。

## 1. 四条反馈怎么改的

| 用户原话 | v1 的病灶 | v2 的做法 |
|---|---|---|
| 外形太规律平整 | 等距折棱 + 等比缩放的回转壳，读成帐篷 | 改成 **±96° 的一段弧墙**；角度采样不等距（12°–14°）；顶边**量化成 0.34 m 台阶** + 两个宽缺口；每段顶再加 ±0.05 抖动 |
| 高高的，没有深度 | 10.115 m 高，正面一整片 14 m 平墙 | 高度压到 **4.56 m**；纵深 5.2 m（门口→隧道尽头），中间夹内拱 + 四级下沉 + 洞内一线暖橙 |
| 门太靠内 | 门扇退进裂口 1.81 m，前面还压 8.6 m 台阶 | 门扇立在拱洞前缘 **0.62 m**（墙厚的 57%）；外面再套凸出 0.36 m 的**方形门楼** |
| 门前横着一根骨头 | 撑骨横穿洞口 | 撑骨**整根删除**；骨只做结构（三根肋骨 + 六根骨钉 + 一根骨刺），**门前一块都没有** |

## 2. 明度秩序（深度的来源）

```
土 0.28  →  墙 0.36  →  破口/门套 0.52  →  门扇 0.19  →  隧道 0.03
```

- 土山用 `earth_dark`（#55432F），前庭用 `paving`（#8A8378），墙用 `ancient`（#5B6069），
  门楼用 `ancient_pale`（#868D95），门扇用 `door_stone`（#2E333B），隧道用 `void`（#0B0C0E）。
- 极差 **17 倍**；最亮的是门楼与墙顶断面，最暗的是洞口 —— 视线被自动吸进去。
- 队色**只两道**：檐口顶面漆线（水平面，俯视唯一一条）+ 门扇横带；另有一面营旗。
  实测占比 **正 3.90 / 三四 3.03 / 俯 2.81**（v1 是 1.34 / 0.69 / 0.32 —— 几乎没有队色）。

## 3. 层次（从外到内 6 层）

1. **土台**（不规则 12 边形，不是矩形板）
2. **土山**：左右两座 + 后山 + 隧道顶土脊；三层缩放的坡；墙的两端**被土吃掉**
3. **前庭**：下沉 0.06，两侧挡土石墙 + 土翼，门前两级踏步
4. **弧墙**：±96°，阶梯顶边，两道砌缝，四道扶壁，两道裂缝，土沁环
5. **门楼**：两墩 + 过梁 + 檐口 + 三块残垛 + 基座暗带 + 两块崩角
6. **隧道**：四级下沉 + 内拱 + 断链 + 尽头一线暖橙

## 4. 组件化

```python
PARTS = ("pad", "ground", "shell", "portal", "door", "cave", "bones", "props")
Model(smooth).build(only=("door",))      # 只出两扇门
```

- 换一颗卵：`RX / RY / H_REF / TOP_T`
- 换一张嘴：`PHI_M / SPRING / ARCH_H / ARCH_P`
- 换土坡：`berm_h()` / `hill(...)` 的半径与高度
- 骨 / 门套 / 道具都是纯函数式小构件，可以整段搬给别的资产

## 7. 已知取舍（下一轮可动）

1. **土山的表面还是偏平**：三层缩放的土丘在俯视里读得出体量，但缺少冲沟/车辙/小径
   这类"地被"细节；再加会牵动 UV 与面数，这轮先停在"干净的土"。
2. **骨刺仍偏"剪影道具"**：已经加粗 40%、缩短到 0.9 m，但在主图上仍读成一根白色的角。
   下一轮可以改成"半埋在土里的肋骨端头"，不露出尖。
3. **队色 2.8–3.9%** 低于失落帝国其它三座（4.5–5.2%）。这是刻意的（队色克制），
   但如果引擎里需要更强归属感，把檐口漆线加宽到 0.8 m 即可回到 ~4.5%。
4. **低模 7.1k tri** 比 v1（4.4k）重一些，多出来的是门楼、砌缝与土脊 —— 如果手游档
   要更省，`finalize` 里把 `seg=1` 改成 0（只留 flat）可回到 ~5.6k。
