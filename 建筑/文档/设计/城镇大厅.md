# 城镇大厅 v3 · 报告

> 三座资产包的第三座。v3 针对三条反馈重做：
> **① 主体窄而高没有美感 → 扩宽 + 加主体组合；② 屋顶怪、丑；③ 入口不要一片突出的平地。**
> 交付后又改了三轮：先按"太矮了"拉高（15.85 → 19.53），再按"主体像被砍了一刀、少了一截"
> 从两层改成**三层**（19.53 → 24.16），第三轮还是"像被砍了一截"，做的是**几何归因**
> 之后的整体重排（24.16 → 25.18）。
> 上一版在 `docs/城镇大厅/v2/`。

---

## 1. 三条反馈怎么落地

### ① 窄而高 → 三段式

| | v2 | v3 |
|---|---|---|
| 宽 × 深 | 10.90 × 7.20（主体） | **18.10 × 8.92**（含石台与台阶） |
| 高 | 19.19（旗尖） | **25.18**（旗尖） |
| 宽 : 高 | 1 : 1.76（窄高） | **1 : 1.39** |
| 正面开间 | 3 个（钟塔占中间一整间） | **5 个**（3.4 / 3.6 / 3.4 + 3.2 / 3.2） |
| 层数 | 2 层 | **3 层 + 顶层退台 0.45**（一层拱窗 / 二层大窗 / 三层高窗） |
| 主体组合 | 主楼 + 贯通钟塔 + 后附楼 | **主楼（檐 12.39）+ 两侧翼楼（檐 8.70）+ 屋脊钟塔** |
| 平面轮廓 | 矩形 + 后方一块附楼 | "凸"字：主楼在前 0.75，两翼后退 |

关键的一条：**钟塔不再贯通立面**。v2 的塔从地面通到 13.35，正面被它切成两半，
读起来是"一座钟楼带两片裙房"。v3 把塔改成**骑在屋脊上的方形石座**（12.39 → 17.10），
只在屋面上冒出 1.6 m —— 立面因此是完整的一条，塔变成"屋顶上的冠"。
立面高度 11.6（三层）、屋面 4.21、塔 7.3。

### ② 屋顶又怪又丑 → 缓坡四坡 + 披檐

v2 的两段孟莎（下段 57° / 上段 42°）在 10.9 m 的窄进深上读成"帐篷上扣了一顶帽子"，
折脊还正好横穿钟塔四周，接缝处堆满三角墙。

v3 换了四件事：

1. **坡度 44.6°**（檐 12.39 → 脊 15.90，水平 3.60），缓坡把"帐篷感"去掉；
2. **屋面拆成三段**：主楼四坡（深板岩 `roof`）+ 两翼单坡披檐（浅瓦 `roof_pale`），
   高差 3.25 m，颜色差一档 —— 俯视能读出"深色主楼 + 两片浅色披屋"；
3. **塔座两侧各留 0.68 m 正脊**，脊不再是"被塔吃掉的零头"；
4. **厚石檐口**（0.24 高）+ **封檐板压在石檐之上**（不再遮住石材）+ 13 道通长瓦垄
   （深色 `roof_edge`，与坡面差一档，俯视有明确的条纹）。

第一次做的时候翼楼用了"小四坡"，结果正面是一个尖三角（翼窄而深，四坡的脊只能沿进深走），
俯视又被主屋面遮掉 —— 三段式完全读不出来。改成**披檐**（单坡、贴主楼墙高、向外落低）后，
正面是一条明确的斜线，俯视是两条朝外的斜带。这是这一版返工最多的一处。

### ③ 入口不要延伸一片平地 → 只留台阶

v2 的前庭台 4.5 m 深、0.42 高、带矮墙与铺石分格，俯视是一块"名片底座"。
v3 整块删除，只留：

- 石台（17.30 × 6.90，三层，顶 0.55）
- **5 级踏步**（宽 3.8、每级 0.11 / 进深 0.28、总出挑 1.40）
- 两侧矮墙 + 端柱 + 金球
- 一圈 0.06 高的散水（左右后三面）

中轴靠"拱门 → 山花 → 盾徽 → 钟塔 → 旗"读出来，不靠平台。

### ④ 两轮高度返工：先拉高，再补一层

**第一轮（15.85 → 19.53）**：反馈"太矮了，高些"。墙身 +1.55（檐口 6.72 → 8.67）、
屋面 +0.5、塔 +2.2。顺带把门拱脚从 2.30 抬到 2.88（原来只占一层净高 47%，
读作"小人国的门"）、腰线色带 0.32 → 0.44、翼楼补二层小窗、隅石 4 → 6 块。

**第二轮（19.53 → 24.16）**：反馈"不仅整体高度，建筑主体也像凭空被砍了一刀，少了一截"。
这是**层数不对**，不是高度不对 —— 之前一直是两层，2 × 3.7 = 7.4 的墙身撑不住 18.1 的宽度，
所以后面接一个大屋顶，读起来像"被削掉了上半截"。

改成**三层**：

| | 两层（19.53） | 三层（24.16） |
|---|---|---|
| 墙体 | 0.55 – 8.43（7.88） | 0.55 – **12.15**（11.60） |
| 层高 | 3.75 / 3.73 | **3.71 / 3.73 / 3.40** |
| 腰线 | 1 道（4.26） | **2 道（4.26 / 8.43）** |
| 窗型 | 一层拱 + 二层方 | **一层拱 / 二层大窗 / 三层阁楼小窗** |
| 檐口 / 正脊 | 8.67 / 11.45 | **12.39 / 15.90**（44.6°） |
| 塔顶 | 18.22 | **22.85**（旗 24.16） |

窗的节奏是这一轮的重点：如果三层都用同样的"窄高条"，15 扇窗连成一片，
读作"一栋公寓楼"。改成**一层拱窗（1.35×2.40）/ 二层大窗（1.45×2.90）/
三层小方窗（1.05×1.35）**之后，三层读作"阁楼层"，节奏是"拱 - 方 - 小方"。

翼楼刻意只做两层（檐 8.70），比主楼低一整层 —— 腰线也只有一道，
层数差靠"腰线条数"读出来。

### ④ 第三轮：把"像被砍了一截"拆成可验证的几何

反馈原话是"整体观感还是怪怪的，还是像被砍了一截"。这一轮不做整体加高，而是先把
"被砍"翻译成四条可测量的几何事实，逐条改：

| 病 | 量化 | 改法 |
|---|---|---|
| 屋面收窄太急 | 正面投影 **10.60 → 3.96**（收掉 63%） | 脊长 3.96 → **5.60**，收窄变成 10.60 → 5.60（47%） |
| 屋顶太薄 | 屋面 3.51 = 立面 22% | 脊 15.90 → **16.60**（49.3°），屋面 **4.21 = 25%** |
| 檐口没有分量 | 0.24 高 × 0.40 出挑 = 立面 **1%** | 三段檐口 **0.51 高**（挑板 0.30 / 檐板 0.55 / 封檐板）+ **36 个托架** |
| 屋面是空板 | 坡面上只有瓦垄 | **2 个老虎窗**（1.40×1.20）+ **2 个天窗** + 瓦垄改亮一档 |
| 上半部没有基座 | 墙从 0.55 直通 12.15 | **顶层退台 0.45**（三层 9.50 宽，一/二层 10.40） |
| 两翼像贴上去 | 中央只凸出 **0.40**（总宽 2%） | 凸出 **0.75**（WYF 2.80 → 2.45） |

五条里最有效的是**退台**和**屋脊加长**：

- 退台让第二道腰线变成"上层的台基"，轮廓从"直筒"变成"分级收束"；
- 屋脊加长后，正面不再是"10.6 直杀 3.96"，屋顶读作"一片宽坡"而不是"一根尖帽子"。

瓦垄是从 `roof_edge`（#232730，比屋面深）改成 `roof_pale`（#525A68，比屋面亮）——
深色沟在深色屋面上只有 1.5:1 的明暗差，24 m 高的时候读作一整片糊掉的深灰；
换成亮脊之后是 2.4:1，屋面立刻有起伏。

**这一轮修掉的真 bug**：
- 老虎窗原来是 1.95 宽 × 1.55 进深、放在 y=2.72 —— 侧墙背面到 y=1.17 处，
  那里四坡的 hip 只到 x=3.19，而老虎窗右缘在 4.475，**整个背面悬空在屋面之外**。
  四坡的前坡是梯形，可用宽度随 y 线性收窄：`x_max(y) = EFX − (EFX−RIDGE_X)·(EFY−y)/EFY`。
  老虎窗必须"离檐口近、进深浅"才坐得进去。
- `win_slit`（侧墙窄窗）挂在 W2（5.21）上，退台后三层墙面在 W3（4.75）—— 悬空 0.46。删掉。
- 转角处侧墙托架与后墙托架同高共面（11.880），后墙那一排退到 x ±4.42。

## 6. 先低模、再细分

| | 低模 | 细分 |
|---|---|---|
| 三角面 | 17,340 | 44,338 |
| 四边 / 三角 / n-gon | 7,793 / 816 / 166 | 18,529 / 5,731 / 318 |
| 孤立顶点 | 0 | 0 |
| 文件 | 1,188,732 B | 2,896,792 B |

- 低模：`max(dims) ≥ 1.10` 的体量件留 1 段倒角，其余不倒角，全平面着色。
- 细分：体量件 `Bevel(1) + Catmull-Clark(1)`，线脚 / 瓦垄 / 窗 / 门 / 旗 / 徽记 / 道具一律不细
  （`skip_cc` 列表），否则斜面会被再磨圆一轮、面数白涨。
- 两版共用同一套材质、UV 与坐标，可以直接当 LOD0 / LOD1。

## 7. 结构规则（本轮新踩到的，已写进规范）

1. **翼楼窄而深时，四坡顶的脊只能沿进深走** —— 正立面看到的是"尖三角"，
   俯视又被主屋面遮掉。附属体量要么做单坡披檐，要么做平顶，**不要做四坡**。
2. **披檐的贴墙一侧必须低于主楼檐口**（这里用 8.35 < 8.43），否则会穿过主屋面。
3. **封檐板要压在石檐口之上，不是套在外面**。套在外面会把石檐口整条吃掉，
   剪影最外的一条线就变成深灰色封檐板。
4. **wainscot / 色带 / 壁柱三者同高时，必须互相错开 5 mm 以上**，
   否则 `COPLANAR_UP` 一定报（`string` 3.700 / `band_m` 3.700 就是这么撞的）。
5. **开放拱廊的拱券半径 = 柱间净距的一半**：柱 0.32 见方、净距 2.22 → 半径 1.11。
   写大了拱会顶穿上枋，写小了柱子与拱之间会留一道缝。
6. **钟亭四面砌墙 = 钟看不见**。墙厚 0.2、开口 1.6、钟在亭心，3/4 视角下
   被开口边缘整个挡掉。要让人看见钟，只能做开放拱廊。
7. **整体拉高时，阵营色占比会同步下降**：剪影面积按高度线性涨，染色面积不变。
   这次从 8.04 掉到 6.53，靠"门抬高 + 腰线加厚"补回 7.86。**拉高一定要重测。**
8. **"主体少了一截"多半是层数不对，不是总高不对**：两层 × 3.7 = 7.4 的墙撑不住 18.1 的宽度，
   后面接一个屋顶就像"被削掉上半截"。18 m 宽的市政厅要**三层**（11.6 m 墙）。
9. **多层建筑的窗必须分层变奏**：三层都用同样的"窄高条"，15 扇窗连成一片，读作公寓楼。
   正解是"一层拱窗 / 二层大窗 / 三层阁楼小窗"，让最上一层读成 attic。
10. **"被砍了一截"要先量化再改**：这次拆成六条可测的几何事实（屋面收窄率、屋顶占立面比、
    檐口厚度比、坡面上的构件数、退台、中央凸出量），逐条改，比"再长高一点"有效得多。
11. **四坡屋面上放附属体量，先算该处的可用宽度**：`x_max(y) = EFX − (EFX−RIDGE_X)·(EFY−y)/EFY`。
    老虎窗"离檐口近、进深浅"才坐得进去；按檐口宽度摆、按脊附近的高度算，背面一定悬空。
12. **深色屋面上的瓦垄要用"亮脊"不要用"暗沟"**：`roof_edge` 与屋面只有 1.5:1 的明暗差，
    在 24 m 高、深色背景下读作一整片糊掉的灰；亮一档（2.4:1）屋顶立刻有起伏。
13. **退台会让所有"按旧墙宽算"的贴面件失效**：檐口、托架、隅石上段、檐下色带、侧墙窗。
    改退台宽度必须整组重算（这次 `win_slit` 就悬空了 0.46）。
14. **层高变了，所有贴墙件的标高都要跟着重排**：窗台（会不会埋进墙裙）、窗顶（会不会穿窗楣）、
   壁灯（会不会撞色带）、隅石（块数与步距）、圆窗（会不会撞檐下带）。
   这次一口气撞了四处，都是"按旧层高算的位置"。

## 9. 已知

- 屋面的瓦垄是"15 道通长压条"而不是一片片瓦 —— 这是低模语言的选择，
  近景（< 8 m）能看出是压条，RTS 距离下读作瓦垄。
- 穹顶是阶梯 8 边形 + 8 条肋，极近景能看到每一级的分段；4 m 外读作"穹顶"。
- 石台四周的散水很薄（0.06），从极低视角看会是一条浅色细线。**不要加厚**，
  加厚就变成 v2 那块"名片底座"。
- 侧面（进深 8.99）仍然是四面里最弱的一面：翼楼外墙 5.65 m 深只有两个开间，
  主楼三层侧墙是退台后的两扇窗。RTS 俯视读不到这一面，所以没有继续加密。
- 中央山花的斜边斜率（1.686）是**刻意等于戗脊斜率**（4.21 / 2.50）的。
  不等的话，山花会读成"贴在坡上的一块三角板"。
- 一层窗的高宽比 1.88，半圆拱在这比例下读起来略像"尖拱"。要更罗马式就把窗加宽到 1.45，
  但那样一层窗会显得矮，所以保持。
