这一轮把铁匠铺的符号整套换成兵营的：`crest()` / `emblem()` / `kite()` / `wallbanner()`
与 `br_model.py` **同一段几何**，铁砧退回道具与招牌（门口的砧、工具架、挂牌）。
同时把 v9 遗留的 8 类构件级穿模清到 `CLIP_CROSS 0`，前场地面按兵营 v4 的口径重做，
并补上 5 处 RTS 视角的细节（煤仓 / 煤渣 / 草簇 / 碎石 / 散板）。

## 1. 符号统一：换的是"几何"，不是"配色"

### 1.1 为什么必须换几何

v9 的徽记是 `emblem()` 里的两条 `beam` + 两个锤头，在 0.4 m 的旗面上只读得出
"两根金线打了个叉"。而兵营的冠盾是 **7 段折线盾 + 冠带 + 三尖 + 三宝石**，
剪影在任何分辨率都读得出来（兵营 v3.4 定稿时验证过：狮头、双剑、三塔城堡都被否，
只有王冠与 X 在 30 px 上读得出）。

v10 直接把 `br_model.crest()`、`emblem()`、`kite()`、`wallbanner()` 搬进 `bs_model.py`，
**逐字不改**（包括 `cz` 是"底边"这个容易搞错的语义、徽记整体上移 5% 的偏移、
盾是 1.00·sz × 1.05·sz 的比例）。两座建筑从此共用一枚符号 —— 这是"统一"的硬约束：
以后改徽记只改一处，两座一起变。

### 1.2 旗帜：同一套零件，两种挂法

| | 兵营 v4 | 铁匠铺 v10 |
|---|---|---|
| 墙面垂旗 | 挑杆 + 3 吊环 + 底角流苏 + 徽记（1.46×2.00） | 同构，1.95×2.10（侧墙）/ 1.55×1.95（背墙） |
| 檐下垂旗 | 无 | **L 形铁吊架 + 木杆 + 金端头 + 3 吊环 + 流苏 + 徽记**（0.80×1.45） |
| 燕尾旗 | 屋顶中央旗杆（1.08×0.72） | 屋脊旗杆（1.16×0.72）+ 烟囱风向小旗 |
| 盾 | 筝形盾 + 只画王冠（避免"盾中盾"） | 同构，1.22×1.50 / 1.16×1.44 |

**L 形吊架保留**：这是 v9 修出来的真 bug —— v8 的旗杆画在梁里，正、侧两轴都读成
"旗从梁里长出来"。吊架（竖杆 0.29 + 横臂 0.28）让旗顶离梁底 0.375 m，
中间露出木梁和铁件，层次才立得住。兵营的墙面垂旗是挂在墙上的，没有这个问题，
所以它没有吊架；两座建筑的旗**共用杆 / 环 / 流苏 / 徽记**，吊架按挂点不同而不同。

### 1.3 删掉的东西（都是"读不出语义"的细节）

| 删除 | 原因 |
|---|---|
| 脊端铁砧立饰（0.55 m） | RTS 尺度上是一根黑柱，而且和门口的砧、工具架上的砧重复三次 |
| 旗面上的铁砧纹章（4 个 box） | 0.4 m 的旗面上是一块模糊的亮斑 |
| 门前小盾 0.84×1.02 | 盾底尖必然扎进拱心石（见 §2.1） |
| 靠墙的长剑 / 战斧 | 门廊翼整面都是拱洞，兵器只能扎进拱券石 |
| 侧墙根的原木堆 | 基座外沿到墙面只有 0.55 m，放不下 0.6 m 宽的木堆 |
| 侧墙根的煤槽 | 与前场的煤仓重复，且和原木堆抢同一段墙根 |
| 檐下托牙 ×4 | 0.15 m 的方料在背墙上只剩一个深色圆点，读成"墙上三个洞" |
| 龛内洗墙光板 2.4×1.6 | 自发光面在拱洞里就是一块橙色屏幕，把火焰层次压平了 |

## 2. 错位 / 穿模：这一轮修掉的 8 类

v9 的体检口径只报"可见共面"，没有把"跨系统相交"清零（422 条全靠人工判断）。
v10 把兵营 v4 的口径整套搬过来（真实顶点投影、crest 同族排除、LINK/VIA/SLAB 白名单），
**逐条修到 0**，而不是加白名单糊过去。真正修掉的：

### 2.1 门头：盾 + 兵器 + 拱心石

```
door_key    ↔ shield_door_rim     12 个三角形
door_arch   ↔ axe_haft            12
```
门廊翼正面只有 1.85 m 的拱门 + 拱心石，小盾的底尖与拱心石共占同一块体积；
战斧斜靠时斧头正好切进拱券石。**修法**：删门前小盾、删两件靠墙兵器
（武器语汇留给兵营，铁匠铺留工具）。

### 2.2 侧墙：窗 / 扶壁 / 腰线 / 横幅挤在同一条线上

```
buttress.002 ↔ winR2_frame   12
string.001   ↔ wbanner_L_cloth  8
string.001   ↔ wbanner_L_field  6
shield_R     ↔ string.001       6
```
后扶壁在 y −2.05、宽 0.55，窗框宽 0.98 —— 必然相交；墙面横幅离墙 0.10，
而 3.74 的腰线凸出 0.13，布面被腰线刺穿；侧墙盾顶 3.82 也压在腰线上。
**修法**：删 winR2（侧墙留一扇窗 + 一面旗）；横幅外移到离墙 0.22 并降到 1.89–3.99；
盾下移到 2.86；窗高 1.24 → 1.10 并下移到 2.80。

### 2.3 屋面：椽条 / 封边 / 隅石

```
quoin.004/009/014 ↔ rafter.*   6/6/6
buttress.002      ↔ fascia.001  8
```
隅石顶块到 4.35，露明椽在 4.17–4.29 —— 隅石被椽条切掉一角。**修法**：隅石步距
0.88 → 0.82（顶块 4.11），扶壁压到檐下 0.55（4.15）。

### 2.4 前场：道具半埋 / 同高共面 / 悬空

| 问题 | 修法 |
|---|---|
| 磨石在 z=0，被铺石吞掉 0.26 | 抬到铺石面（0.254） |
| 陶罐箍压在夯土台边缘 | 外移到 −4.94 |
| 煤仓端板与侧板顶面同高（四角共面） | 端板夹在两侧之间、矮 4 mm |
| 铁锭两层堆叠，上层无支撑（悬空） | 改成平铺一层、各抬 4 mm |
| 道具底面与铺石顶面共面（会闪） | 统一沉 6 mm（`G_PAVE − 0.006`） |
| 散板压在铁砧树桩上 | 移到 (1.56, 7.54) |

### 2.5 坡棚：罩顶 / 椽条 / 通风口

```
canopy_rafter.003/004 ↔ hood / hood_throat   6/5/4
```
烟罩顶 4.42，而露明椽在棚下垂 0.14–0.22，在 y≈4.7 处正好切过罩顶。
**修法**：罩顶压到 4.32；通风口基座从"埋在棚板里"抬到棚面之上
（`can_z()` 是棚板**底面**，原来 `+0.02` 等于把铁框埋进 0.17 的板里）。

### 2.6 山墙：托梁 / 百叶立柱 / 斜撑

```
collar ↔ vent_post   6/6      canopy ↔ collar   6
```
托梁顶 5.95，百叶立柱从 5.80 起 —— 立柱穿过托梁；坡棚高边 5.58 加上板厚后
顶到 5.75，也钻进托梁。**修法**：坡棚高边 5.58 → **5.44**（板顶 5.61），
托梁压到 5.64–5.94，立柱从 5.95 起。

### 2.7 背墙：新增横幅的三次返工

第一版 2.74 高、离墙 0.12：托架够不到墙（浮空）；第二版 2.53：杆与金端头切进
3.74 的腰线；第三版 2.48 才落在腰线下沿。**这类"新加的构件"必然要跑三轮体检**，
因为墙面上已经有墙裙（1.56）、腰线（3.74）、檐口（4.70）三条水平线。

## 3. 低模 → 曲面细分：与兵营同一条管线

`finalize()` 从"每个构件自带 bevel/sub 参数"改成**按体量分档**：

```python
chunky = min(dims) >= 0.10 and dims[0]*dims[1]*dims[2] >= 0.12
细分版: Bevel(1 段) + Catmull-Clark(1 级)   # 体量件
         Bevel(1 段)                        # 小件
低模版: Bevel(1 段) 仅 max(dims) >= 1.20    # 只有真正的体量
        全平面着色
```

两点与兵营不同，都是被面数逼出来的：

1. **倒角 1 段就够**。CC 会把 0.02 的斜面本身再磨圆，2 段倒角在 30 m 外看不出差别，
   却把每条棱的面数翻倍（整模 89k → 66k → 52k）。
2. **低模的倒角门槛从 0.55 提到 1.20**。0.55 会让 359 个构件吃倒角（低模 19k），
   1.20 只留屋面 / 墙体 / 基座这 29 个真体量（低模 14.6k）。

## 4. 前场地面：为什么必须重做

v9 的前场是"一块 stone_mid 石板（0–0.26）+ 2 条石带 + 5 条石缝"，后两者是
**3 cm 厚的薄贴片**，顶面互相只差 2–3 mm。这正是兵营 v4 修过的两个毛病：

- **泛白**：整块场地用 `stone_mid`，和墙体只差一档，俯视时建筑浮在一块水泥板上；
- **闪烁**：薄贴片的边在远处只剩亚像素，拖动视角就是一片闪。

v10 改成兵营的"一项一层高度"：

```
夯土台    0.200   9.20 × 2.50 实体
铺石 ×4   0.260   2.21 × 2.36 × 0.06，缝 4.5 cm（露出 6 cm 深的夯土）
前牙子    0.280   9.20 × 0.18
门槛石    0.310   比铺石高一级
```

一条薄片都不留。点缀全部是有厚度的实体：**煤仓**（木框 + 满仓碎煤 + 3 块碎煤）、
**煤渣**（4 cm 厚的 7 边形，压在铺石上）、草簇 ×4、碎石 ×4、散板 ×1。
煤仓取代了原来的圆煤堆 —— 纯黑的圆堆压在灰铺石上会读成一个洞。

## 6. 还没有做的

1. **屋脊旗杆在正立面正交视图里会从楼阁前面穿过**。这是真实遮挡（杆 y=3.00、楼阁 y=−1.55），
   3/4 与 RTS 视角都分得清。要彻底避开得把旗杆挪到脊的后端，但那样 3/4 主图里旗子会被屋脊压住。
2. **旗面是平板**。没有做布料起伏 / 迎风扭曲 —— 与"硬边几何"的包规一致，但也意味着
   近看是一块蓝色硬板。兵营同理。
3. **前场没有做"人流痕迹"**（脚印、车辙）。兵营用土斑 + 沙圈解决，铁匠铺的地面更小，
   加了会变成噪点。
4. **没有用贴图**。`earth` / `paving` 是纯色，靠明度差分层；上图集的话这两块最值得先做。
