# 哨塔 v1 · 报告

> 接手任务：建模哨塔，参考 `参考图/哨塔.png`，与另三座同一风格；先 low poly 再曲面细分；
> 俯视角下达到"小品 RTS 手游 / 独游"的品质；装饰与细节符合这套审美、资产不重；
> 任何部位不许错位、不许穿模。
>
> 结论：**503 构件 / 低模 9,624 tri / 细分 25,332 tri / 手游 9,624 · 5,036 · 3,228**；
> 体检 **CLIP_CROSS 0 / COPLANAR_UP 0 / FLOAT 0**；阵营色 **9.42% / 6.55%**；
> 尺寸 **7.16 × 7.12 × 17.34**。

## 1. 参考图读出来的四件事，以及本套语言怎么落

| 参考图 | 本套落法 | 为什么 |
|---|---|---|
| 石砌基座（粗石、拱门） | 4.20 × 4.20 直墙石基，真开 1.20 宽的拱门，两道线脚 + 四角隅石 + 压顶托石 | 石基是"塔的基座"不是"石屋"，所以只在正面开门，侧面只留箭孔 |
| 木塔身 + 三层挑台 | 木塔分两段（3.60 / 3.10），中间夹 5.30 的中层挑台、顶上一圈 5.00 的观景台 | 收 / 放 / 收 / 放 —— 俯视四个同心方、正视四条水平线，层次全靠这个节奏 |
| 顶部开放平台 + 旗 | 平台四面栏板 + 中央**陡坡双坡瞭望亭**（3.20 × 3.60）+ 脊上旗 | 六座屋顶类型必须两两不同，剩下的一格是 `gable_steep`；亭子只盖平台中央，四边留 0.90 环廊，读作"架在柱子上的顶棚" |
| 外挂木梯 | 57° 木梯从石台右前角斜靠到中层挑台左前角，跨过门洞上方 | 全座唯一的斜线，也是"哨塔"最好认的一笔 |

## 2. 三轮形体推演（每轮都出图对比）

### v0 初版：石基太矮、顶棚像教堂

- 石基 4.76 × 3.10、木塔 3.90、平台 5.20 / 5.70（**上大下小**）、顶棚 3.90 × 4.70 全覆平台。
- 出图后三处不对：
  1. **比例像"木屋加石座"**：石基 3.10 / 总高 17.5 = 18%，但宽度 4.76 让石基读成"一层楼"；
  2. **顶棚是"教堂山墙"**：山墙三角占顶部 40%，而且把平台整个盖住 —— 参考图的"开放观景台"读不出来；
  3. **栏板的队色带 0.20 高**，占 1.00 栏板的 20%，整圈读成"蓝白横条围栏"。

### v1 中版：收比例、缩顶棚、改配色

| 项 | v0 | v1 |
|---|---|---|
| 石基 | 4.76 × 3.10 | **4.20 × 3.60** |
| 木塔 | 3.90 / 3.40 | **3.60 / 3.10** |
| 平台 | 5.20 → 5.70（倒锥） | **5.30 → 5.00**（正锥，和参考图一致） |
| 顶棚 | 3.90 × 4.70，全覆 | **3.20 × 3.60**，环廊 0.90 |
| 队色带 | 0.20 通长 | **0.19 分段嵌板**（每两根立柱一块） |
| 石基色 | `stone_light` | **`stone_mid` + `stone_light` 线脚** |

- 正锥 vs 倒锥：参考图是"底层挑台最宽、往上略收"，倒锥会读成"头重脚轻"。
- **分段嵌板**是这一轮的关键：通长队色带读成"围栏刷漆"，分段后读成"木栏板上的队徽嵌板"。

### v2 定稿：屋顶语言 + 细分收敛

- **不铺瓦垄**：3 m 的坡上，亮脊（`roof_pale`）会读成"银白条纹板"；
  改成 2 道暗缝（`roof_edge` 细条压在坡面上只露几毫米），读作"木板拼接"。
- **前后不出檐**：山墙是端面，屋面只在左右出檐 0.36 —— 正面读到的才是
  "木山墙 + 压在上面的屋顶"，而不是"一块深灰的屋面边缘"。
- **细分只磨小体量件**：石基 / 木墙 / 平台板 / 屋面板是大平面，
  Catmull-Clark 会把棱磨成一圈渐变的圆，正是"塑料感"的来源
  （对照 `docs/城镇大厅/v3/主图.png` 的硬边）。细分后 9,624 → 25,332 tri。

## 3. 屋顶类型为什么是"陡坡双坡"

六座现有屋顶：交叉山墙（铁匠铺）/ 平顶垛口（兵营）/ 缓坡四坡 + 两翼披檐（城镇大厅）/
单坡（农场）/ 敞棚（伐木场）。**缺双坡**。

但"双坡"放在哨塔上有两个坑：

1. **做成覆盖整座塔的大双坡，就变成钟楼 / 教堂**（城镇大厅的钟塔已经是这个语言）。
   → 只能做**小体量、架在柱子上**的瞭望亭，让"平台"仍是主体。
2. **山墙朝前 + 屋面出檐**，正面会先看到"屋面板的端面"，山墙被压在后面。
   → 前后不出檐，山墙外移 0.06 成为端面。

数值：檐 13.34 / 脊 14.90（3.60 长，坡度 44°）/ 左右出檐 0.36 /
柱 4 根 0.26 见方（柱头金 + 队色柱箍 + 斜角撑）/ 山墙下半敞开、上半三角板 + 三根竖棂 + 冠盾 0.46。

## 4. 材质与色彩：克制 + 秩序

三档木色（这一版新增 `wood_mid`，图集第 25 格）：

| 材质 | 色值 | 用在哪 |
|---|---|---|
| `wood_mid` | #5F3D1F | 木塔身墙板、栏板实板、山墙三角板 |
| `wood_warm` | #9B6236 | 平台铺板、梯档、柱头、檐下椽头、原木 |
| `wood_dark` | #3E2718 | 角柱、腰梁、扶手、梯梁、压条 |

- **石**：`stone_mid` 墙身 + `stone_light` 线脚/隅石/门套 + `stone_dark` 门洞内。
  石基是"深灰石 + 亮线脚"，不是一块白板。
- **顶**：`roof` 深板岩 + `roof_edge` 封檐/暗缝 + `gold` 脊端。
- **唯一强饱和色**：火盆（`ember` 外焰 + `flame_in` 内焰）。

## 6. 这一轮踩到的坑（都是脚本 bug，不是审美）

1. **石基主块 y 尺寸漏算 0.14**：`(SBX - DW) * 2` 写成 `SBX * 2 - DW` 才对 ——
   否则后墙与主块之间有条 0.14 的缝，后侧 4 块托石全部悬空。
2. **侧墙窗的 `wall` 参数要带符号**：`wall=W1` 让左右两扇窗都落在 +X 墙内侧，
   穿墙 + 两窗框同高共面。必须 `wall=sx*W1`。
3. **后墙窗同样**：`wall=-W1`，不然落在正面墙里。
4. **铺板嵌进了平台板**：`d1_plank` 中心比 `d1_deck` 顶面低 0.16 —— 从任何角度只剩 4 条缝。
   铺板必须**抬到平台板之上**（板顶 = 平台顶）。
5. **托石循环变量泄漏**：`for sx ... for sy ...` 之后又用 `sx`，只生成了 +X 一侧；
   且顶面与石基顶同高（4.02）→ 8 对 COPLANAR_UP。
6. **后墙箭孔写错坐标**：`("Y", SBX, 2.05, 1)` 落在右前角，撞隅石。
7. **栏板端柱与角柱完全重合**：栏板两端各内缩 0.20 让开角柱，梯口两侧改用短柱。
8. **转角同高**：四个面的栏板横档 / 立柱顶面同高 → 给每面一个 6 mm 的 `lift`，
   视觉上看不出，但脱开共面。
9. **`fire_core` 不在图集里**：图集 25 格已满，新材质只能复用已有格。
   火焰改成"外 `ember` + 内 `flame_in`"，反而更符合"外暗内亮"。

## 7. 留给下一版的

- 场地外圈只有 0.5 m（石台 5.10 / 夯土台 7.08），柴堆那类 1 m 宽的堆料放不下。
  要加地面道具得先把场地扩到 8 m。
- 俯视时瞭望亭会盖住平台后侧：亭 3.20 宽 / 平台 5.00，环廊 0.90 是
  "撑得住双坡"与"看得见平台"两条线的交点。
- 石基是大片平面，只有线脚和隅石；要加石缝得换一套 UV 方案（见 `docs/资产规范.md` §3）。
- 木塔身的窗是贴片窗（木框凸 0.035 / 玻璃凸 0.010），不真开洞。
