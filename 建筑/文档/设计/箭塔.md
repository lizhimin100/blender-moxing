# 箭塔 v2 · 报告：整顶攒尖亭 + 剪影箭

> 任务（用户原话）：顶部不要再把攒尖顶角亭做在一角，**攒尖顶亭要是整个顶部**；
> **去掉弩炮**；在攒尖顶亭的外形里加入"像箭"的特征，一眼能看出是箭塔（War3 人族
> 箭塔的读感）；与其余九座同一风格；先 low poly 再曲面细分；俯视角达到小品 RTS
> 手游 / 独游品质；构图紧凑、层次清晰、轮廓明确、色彩克制、材质干净；
> 不许错位、不许穿模、资产不重。

---

## 一、v1 的三个问题（改版的理由）

| 问题 | 具体表现 |
|---|---|
| 顶部是"平台 + 角亭" | 3.5 × 5.4 的战棚上摆着一个 1.38 × 1.38 的小亭，亭只占一个角；俯视读作"平台上的一个盒子" |
| 弩炮抢戏 | 弩炮是平台的主要体量，但它读的是"攻城器械"，不是"箭" |
| 顶部没有"整"的形 | 垛口 + 弩炮 + 角亭 + 旗，四件各自成立，合起来没有一句话 |

## 二、v2 的形：把"层"从 5 段改成 4 段

```
石基（4.76 × 3.48 高）→ 塔身两级（4.28 / 3.80）→ 挑出的木战棚（5.72）
→ 整顶攒尖亭（8 柱 · 环绕栏板 · 5.40 见方的单段攒尖顶）→ 剪影箭（17.46 塔尖）
```

设计上真正做对的三件事：

1. **层高重排**：v1 的战棚 + 垛口只有 1.5 m，而塔身 8.9 m —— 冠部被压成一条。
   v2 把塔身压到 8.85 m、把冠部拉到 8.6 m（战棚 0.44 + 亭 2.3 + 顶 2.6 + 箭 2.8），
   **头身比 1:1**，这才是 War3 人族塔的读感（大盖压住塔身）。
2. **屋面放到几乎与栏板齐平**（5.40 vs 5.68）：屋顶不再"扣在平台中间"，
   而是**盖住整个顶**——这是"整顶亭"这句话在几何上的落点。俯视时靠 58° 的
   位差（高处的东西往相机方向偏 0.62·h）仍然露出一圈战棚边沿，所以俯视不塌。
3. **亭是敞开的**：8 根柱 + 1.0 m 栏板 + 空的暗部 + 亮的铺板。三样东西同时在场，
   俯视是"深色屋顶 + 一圈暖木 + 两道蓝线"，3/4 视角能看进亭里。

## 三、箭饰：三个方案的对照实验

"在攒尖顶的外形里加箭的特征"最先做的是**绕杆一圈的四片箭羽**（每片 1.2 m 高、
半径 0.54），结果从任何水平方向看，四片羽都合成一个**对称的梭形 / 灯罩**——
越调越像装饰球，不像箭。于是做了一张三方案对照图（`_look/_箭饰对照.png`）：

| 方案 | 几何 | 结果 |
|---|---|---|
| A 四片绕轴羽 | 4 × 竖直薄板，径向 0.54 | **蓝蝴蝶结 / 灯罩**，剪影对称，读不出羽 |
| B 三片绕轴羽 | 3 × 120°，径向 0.42 | 一根蓝色叶片，仍是对称的"针" |
| C 剪影箭 | 两片互成 90° 的**箭形板**（铁箭身 + 蓝羽） | **一眼是箭**：镞、杆、羽都在剪影里 |

选 C，并把两片板转到 **45° / 135°**——正好接在两条戗脊的延长线上：

- 3/4 机位（方位 −34°）：45° 那片只偏 11°，几乎正面，读作完整的箭；
- 另一片接近侧棱，只剩一条线（不添乱）；
- 俯视：两片成十字，箭尖仍指天。

尺寸：镞宽 0.60、箭身 2.84 高、羽展 0.72。箭尖 17.46（比宝顶高 2.86）。

## 四、色彩：从 4.36% 调到 6.20%

队色（team）按"结构线"分配，一开始只有门 + 门楣 + 一道蓝扶手，实测 4.36%，
低于 6–9% 的口径。逐轮调整（每次都用 `at_teamshare.py` 重测）：

| 版本 | 改动 | 正视 | 3/4 | 俯视 |
|---|---|---|---|---|
| a | 门 + 匾 + 蓝扶手 + 细檐线 | 4.36 | 4.45 | 5.07 |
| b | 战棚封檐板改队色（冠部最宽一圈） | 6.23 | 6.23 | 6.96 |
| c | 扶手改金（三道蓝箍连排读成"包装带"） | 5.70 | 4.88 | 5.58 |
| d | 亭内加两面燕尾旗 | 6.37 | 5.86 | 6.22 |
| e | 封檐板 0.20 / 檐线 0.15 / 军旗加宽 | **7.02** | **6.20** | **6.33** |

**结论（写进规则库）**：三道队色横箍连排 + 间距 1 m = 包装带；**两道 + 中间隔一层
空的暗部**才对。军旗这类竖向色块在 3/4 视角里被屋顶遮掉一半，**不能当主力色源**；
靠它补 1% 可以，靠它补 3% 不行。

## 五、体检

| 项 | 结果 |
|---|---|
| 构件 | 295 |
| CLIP_CROSS / COPLANAR_UP / FLOAT | **0 / 0 / 0** |
| 三角面（细分 / 低模） | 18,282 / 7,140 |
| 手游三档 | 7,140 / 3,082 / 1,882；材质 4 / 4 / 3 |
| 占地 | 7.08 × 7.03 × 17.46 |

修掉的四处真问题：

1. **托石 × 斜撑**：托石在 8.55–8.85、斜撑从 8.58 起，8 处跨系统相交 + 16 处同高共面
   → 整组删掉托石（挑檐只出挑 0.16，斜撑已经把"挑出"讲清楚了）。
2. **下段壁柱顶面 = 墙顶面**（6.25 同高）→ 壁柱压低 30 mm。
3. **柱顶面 = 檐梁顶面**（11.65 同高）→ 檐梁加高 20 mm，柱顶埋进梁里。
4. **拱心石整块埋进拱上墙**（CONTAIN）→ 挪到拱券外皮（SBX+0.045）。

## 六、这一轮新增的坑

1. **`disc_y()` 造出来的靶面圆盘忘了 `self.add()`**：物体在场景里能渲染，
   但不进 items → 不合并 / 不进图集 / **不跟随 mirror_x**，交付 .blend 里多出
   3 个对象和 1 个 `sand` 材质。这是规则 A4（`rib_quad` 只创建不加入）的复发。
2. **拱内木鼓 + 门楣梁 = 门洞里塞着一块木头**：把拱内填石（`stone_mid`），
   门读成"实心石拱 + 一扇方门"，门楣梁才有意义。
3. **蓝壁柱贴在拱肩上是"贴纸"**：删掉；队色改由门扇下板 + 横匾承担。
4. **`eave_flash` 做成外凸 0.12 的环 = 蓝塑料托盘**：改成贴在封板外立面上的
   一道漆线（外凸 0.005，厚 0.15）。
5. **四片绕轴的箭羽会合成梭形**（见第三节）；剪影箭的内缘必须给到 r=0.02
   埋进中心杆，否则整片羽判 FLOAT。
6. **改版前没归档资产**：v1 的 GLB 被 v2 覆盖（`assets/_历史版本/` 里没有箭塔_v1）。
   规程是"覆盖同名"，但**改版前应先把整个 `assets/<建筑>` 复制进
   `_历史版本/<建筑>_v<n>/`**。这一条已写进规则库。
