你是**电影美术指导 + 关卡场景设计**。要重做一个室内场景，**先只谈空间，不谈装饰**。

## 背景：这个场景有两个用途，必须同时成立

| | 用途 A：RTS 游戏 | 用途 B：短视频拍摄 |
|---|---|---|
| 观看方式 | Godot 4，45° 俯视，相机高度角 30–35°，同屏几十座 | 16:9 横屏或 9:16 竖屏，镜头能推、能摇、能升降 |
| 距离 | 20–40 m（建筑尺度） | 0.5–8 m（房间内），会有**近景特写** |
| 要什么 | 俯视一眼读得懂、面数省 | 有纵深、有上下层、有可数的光源、经得起近看 |
| 时长 | 1 秒 | 15–60 秒，镜头会移动 |

美术语言：低模硬边、平面围合、100 % flat shading、零曲面零圆角，颜色靠纯色材质而非贴图。

## 现状：已经做出来的 v1（要被推翻）

- 房间 **10.83 × 9.08 × 3.49 m**，**单层**
- **正面整面墙一刀平切**，两侧墙三段递降（3.38 / 2.56 / 1.62 与 3.38 / 2.80 / 1.92），
  断口露出浅色石芯 + 暗线表示"这是剖面"
- **后墙一条直线摆满**：左边吧台（3.8 × 0.78，台高 1.16，配 3 只桶、两段酒架、3 张高脚凳），
  右边石壁炉（宽 2.7，炉口 1.44 × 1.32，烟囱胸墙到 3.38）
- 左墙木梯 6 级 → **1.68 m 假平台，进深只有 1.0 m**（读作"上面还有"，但没有二层）
- 房中央一盏六烛铁环吊灯（梁底 3.30）+ 三张桌 + 凳
- 材质 4 个 / 低模 9,754 tri / 细分 33,189 tri

## 为什么不行（三条，按严重程度）

### 1. 它是"被切开的盒子"，不是空间

一刀平切 + 单层 + 家具全部靠墙 = 娃娃屋。视线只能沿墙绕一圈，中间空着，
**没有中心、没有纵深、没有上下关系**。

### 2. 三个"心脏"互相打架

壁炉（火）、吧台（人）、吊灯（光）—— 三个都要当主角，但壁炉和吧台被推到同一面后墙，
吊灯孤零零挂在正中。观众的眼睛没有落点。

### 3. 精度撑不住短视频近景

4 个材质、512² 图集、家具只有轮廓（腿是方柱、台面是一块板、没有接缝/磨损/五金）。
**在一米内看，全是色块。**

## 硬要求（不满足直接淘汰）

### A. 空间结构

1. **真的两层**。一层净高 ≥ 3.4 m，二层净高 ≥ 2.9 m，总高 ≤ 8.5 m（含屋架）。
   **1 m 深的假平台不算二层。**
2. **二层必须让出中庭**，挑空面积 ≥ 二层楼板的 25 %。
   理由很硬：RTS 俯视时，如果二层铺满，一层就完全看不见 —— 中庭是"俯视能看进去"的唯一办法。
3. **至少两个标高**（地面 + 0.30–0.45 m 的台，或做下沉），楼梯按真人尺度
   （踏高 0.17 / 踏宽 0.28）。
4. **三个机位点**：设计时就要为它们留空间（不能等家具摆完才发现没地方站相机）：
   - 机位① 门口向内推（进门第一视角，看到吧台/楼梯的斜线）
   - 机位② 二层栏杆俯拍一层（要能看到至少两张桌 + 一个火源）
   - 机位③ 贴地仰拍（火塘或吧台的低角度，天花与梁入画）

### B. 尺度（比现在大一圈）

| 项 | 值 |
|---|---|
| 占地 | **16 × 12 m**（可 15×11 ~ 17×13），不小于 15×11 |
| 一层净高 / 二层净高 | ≥ 3.4 / ≥ 2.9 m |
| 总高 | ≤ 8.5 m |
| 人体尺度锚点 | 门洞 2.1 m、吧台 1.10 m、踏步 0.17×0.28 m、栏板 1.0 m、桌高 0.75 m |
| 三角面 | 拍摄档 ≤ 80,000（细分）；RTS 近档 ≤ 18,000 |

### C. 剖切策略（本轮最关键的决策，方案里必须选一个并说明理由）

| 策略 | 做法 | 代价 |
|---|---|---|
| **A 完整房间 + 可隐藏剖切件** | 做整套墙 + 屋顶，把"前墙 / 半片屋顶"做成**独立节点**；RTS 模式隐藏，拍摄模式显示 | 需要 Godot 侧按模式显隐；两套用途共用一份 GLB |
| **B L 形剖面** | 只保留两面墙 + 半片天花，切口沿 L 折一次 | 永远"缺一面"，拍摄时靠机位避开 |
| **C 屋顶敞开** | 保留四面墙，屋顶只做梁架 + 半片瓦，像"被掀开" | 俯视能看进去，但夜戏/雨戏的包裹感弱 |

> 我的倾向：**A + C 混合**（墙齐、屋顶半开、前墙独立）。但这是方案里要辩论的点，不要照抄。

### D. 精度（拍摄档的新要求）

- 允许**两套品质**：拍摄档（更多材质、图集 2048²、细分到 60k+）与 RTS 档（4 材质、18k）。
  这要在管线里分两条导出线（本轮不做，但方案按这个前提设计）。
- **近景可读的细节必须靠几何，不靠贴图**：榫卯接头、木板缝、铁件、钉子、砖缝、磨圆的桌角、
  被烟熏黑的炉口上沿。贴图在一米内一定穿帮。

### E. 光

- **每一个光源都要是可见的实体**（烛台、油灯、壁炉、灯笼），因为镜头会拍到它。
- 光源 6–10 个，分布要形成明暗节奏，不能平均。
- **不允许"来源不明的光"** —— 短视频里最假的就是一片均匀亮。
