## 世界观（这条决定一切）

"失落帝国沉入地底，后人进去探索"。
**但这里真正的主语不是"帝国"，是"后来占了这个洞的东西"。**
帝国留下的是**秩序**（砌体、拱、柱、排水沟）；现在占据它的是**失序**（根、膜、骨、沉积、水）。
恐怖来自"**一个文明的空间被另一种东西接管了**"，不是来自"很旧"。

## 为什么不行（四条）

### 1. 构成撞车：它是"矮一点的联盟要塞"

主方向全是**向上**（抬台基、爬外梯、塔往上升），而"地牢入口"应该**向下**。
更致命的是它用的「台地 + 塔」**和城镇大厅、哨塔是同一套语法** —— 观众分不出阵营。
（同一个包里「地下城入口」用的是"崖式"，九座里没有第二个，所以它反而读得出"入口"。）

### 2. 语汇是"文明的石工"，不是恐怖

方整砌块、对称门楼、半圆拱、干净的压顶线脚 —— 这些是**秩序**的语言，
读起来是"古代建筑"，不是"不该进去的地方"。

### 3. 恐怖元素为零

没有一处"不该存在的东西"：没有抓痕、没有骨、没有"后来者"的痕迹、
没有尺度异常、没有看不见的深处（幽绿光把洞底**照亮**了，等于把恐惧关掉了）。

### 4. 双用途都不成立

俯视只看得到一块台子和一座塔（负空间被墙挡住）；
近景只有干净的灰面，没有可拍的东西。

## 恐怖怎么落地：三层配方（按观看距离）

**这是本文的核心。三个方案都必须在这三层上分别给出具体物件。**

| 距离 | 恐怖类型 | 手段 | 这座建筑的具体做法（示例，方案里要给自己的答案） |
|---|---|---|---|
| **RTS 20–40 m**（1 秒） | **剪影恐怖**：形状不对 | 轮廓本身违反"建筑应该是规整的" | 门不是拱，是上下**咬合的不规则裂口**；地平线上有 2–3 根**刺出地表的东西**（骨/柱/根）；整座微微**倾斜**（视觉上不稳） |
| **中景 5–10 m**（3 秒） | **尺度恐怖**：比例不对 | 让人意识到"这不是给我用的" | 门洞净高 **7 m**（人的 3 倍多）；门前踏步**高 0.45 m**（不是给你走的）；坡道**不平**（左右高低差 8 cm）；门框上有一道**比自己高两倍的旧门槛** |
| **近景 0.5–2 m**（短视频） | **痕迹恐怖**：有人来过，没出去 | 成组的、有方向性的细节 | 三道**平行抓痕**（深 6 cm，指距 12 cm）；一根**垂下的断链**（离地 1.6 m，正好是脖子高度）；**干涸的深色渍**从门槛往外拖 2 m；墙脚**堆叠的骨**（不是头骨堆，是长骨横竖交叉）；一块**被钉在墙上**的破布；地上一个**被踩灭的火堆**（后来者留下的） |

> 三条纪律：
> ① **不做血腥、不做尸体**（要"不安"，不要"恶心"；也避免平台分级问题）。
> ② 恐怖线索**总量不超过 3 类**，多了会变成"鬼屋道具展"。
> ③ **每一条都要在 RTS 距离上有对应**（比如抓痕在远景看不见，但门形的不规则能看见）。

## 与联盟的分离（不只是换色，五条一起做）

| 维度 | 联盟九座 | 失落势力（要做的） |
|---|---|---|
| 几何秩序 | 水平、垂直、对称、方整 | **倾斜、下沉、错缝、被覆盖** |
| 材料来源 | 石 + 木 + 金属（都是"加工过"的） | 石（帝国残留）+ **生物/矿物**（根、膜、骨、沉积） |
| 明度 | 大面积 0.55–0.86 | **大面积 0.11–0.31**（整体沉下去） |
| 色 | 暖灰 + 深蓝瓦 + 金 + 蓝队色 | **冷青灰 + 氧化铁褐**；**禁止蓝、禁止金、禁止旗** |
| 光 | 暖橙火光（安全） | **洞内纯黑 + 一线极弱暖光**（不安全） |

> **幽绿要删掉。** 绿光读作"科幻/魔法"，不读作恐惧。
> 纯黑 + 一线橙红（像里面还有火）比任何发光体都可怕。

## 硬约束

| 项 | 值 |
|---|---|
| 单位 | 1 unit = 1 m，原点在占地中心，z = 0 是地面 |
| 朝向 | 建模期 +Y 为正面（导出后 −Z） |
| 占地 | **≤ 14 × 12 m** |
| 高度 | **≤ 12 m**（如果要更高，必须论证） |
| 三角面 | RTS 近档 ≤ 12,000；拍摄档 ≤ 40,000（细分） |
| 材质 | RTS 档 ≤ 4；拍摄档 ≤ 8 |
| 形体 | 只允许长方体、楔形、棱柱、锥台、斜撑；**零曲面、零圆角** |
| 负空间 | 门洞 + 内部黑暗区，**在正视图占 ≥ 12 %** |
| 可走进去 | 门洞**进深 ≥ 4 m**（短视频要能拍"人走进去、消失"） |
| 机位 | **至少 3 个**：门前正面推入 / 门内侧身仰拍 / 坑口俯拍 |
