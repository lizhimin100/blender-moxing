# 建模规则 · 血泪清单（八座累积）

> 从 `.workbuddy/memory/MEMORY.md` 抽出来的工程规则库：**每一条都是返工换来的**。
> 记忆里只留"现状 + 不可动 + 验收"，具体做法查这里。
> 新增一条前先确认它不能被合并进已有的某一条。

---

## A. 屋面 / 屋顶

1. **屋面是薄壳**：檐口厚 0.18（椽 0.10 + 望板 0.03 + 瓦 0.05）；壳下必须有内缩 0.10 的封闭阁楼体块，否则从檐下能看见"空心"。
2. **两个屋面不许正好等高**（相切 = 闪面）；压在某个面上的构件要**高过那个面**。
3. **深色屋面上的瓦垄用"亮脊"不用"暗沟"**：1.5:1 的明暗差在 RTS 距离上糊成一片，亮一档（2.4:1）才有起伏。伐木场、神秘圣地都是 `roof_pale` 亮脊。
4. **`rib_quad()` 只创建物体、不加入 items**：留在场景里能渲染，但不进 GLB / 图集 / 交付 .blend。v2 漏过 31 根瓦垄。凡"创建但不在 items 里的物体"都要查。
5. **`rib_quad` 的 p0/p1 与 p3/p2 必须同向**，反了是扇形交叉（瓦垄呈放射状）。
6. **大面积屋面别铺密肋**：3 m 坡上排亮脊读成"银白条纹板"（哨塔）。改用 2–3 道 `roof_edge` 暗缝或干脆留白。
7. **四坡屋面上放附属体量先算可用宽度**：`x_max(y) = EFX − (EFX−RIDGE_X)·(EFY−y)/EFY`。老虎窗要"离檐口近、进深浅"；按檐口宽度摆、按脊附近算高度，背面一定悬空。
8. **窄而深的附属体量不要做四坡**：脊只能沿进深走，正立面就是一个尖三角，俯视还被主屋面遮掉。要么单坡披檐、要么平顶；披檐贴墙一侧必须**低于主楼檐口**。
9. **单坡的侧墙必须跟屋面斜度**：直角矩形会在后半段留三角洞（农场 1.7 m、伐木场小屋同）。
10. **封檐板压在石檐口之上，不要套在外面**：套外面会把石檐口整条吃掉，剪影最外一条线变成深灰。
11. **深出檐会挡死檐梁上的装饰**：1.58 出檐让 11.9 m 通长饰条从任何俯视角都看不见。染色/装饰要放到"出檐之外"的表面（封檐板下沿 / 柱子 / 侧墙）。
12. **"细杆撑大盖"的组（钟亭、旗、烟囱顶）在 LOD2 必须整组保留**，否则远景悬空。

## B. 墙面 / 门窗 / 贴面件

13. **门洞要真开**：墙拆成"左右 + 拱上"三块。`arch_band` 只做 ±Y 面，侧墙用 `arch_band_x`。
14. **`arch_profile(w, straight=0)` 有重复底点**，扇形窗会三角化出黑楔；手写半圆或给 5 cm 直边。
15. **窗函数必须区分墙的法线轴**：只写 `window(axis="X")` 时正面（±Y）的窗会落到墙外。农场补了 `window_y()`。
16. **`window(..., axis="X", out=sx, wall=...)` 的 wall 必须带符号**（`sx*W1`）。传正数 → 两扇窗都落在同一面墙内侧，穿墙 + 同高共面 + 外面看不见。
17. **贴面件中心必须在墙面之外**（栽过三次）：盾徽 `BY-0.04`、门楣匾 `BY+0.13` 都被整块埋掉。2.4×0.05 的薄片凸 6 cm **看不出来**——要做就"母件换一段材质"或加厚到 0.10 以上。
18. **墙面新件躲开墙裙 / 腰线 / 檐口三条水平线**：放件前先算"这条线上还有谁"，5–20 cm 之差就是穿模。
19. **wainscot / 色带 / 壁柱三者同高必须错开 5 mm 以上**，否则 COPLANAR_UP 必报。
20. **退台会让所有"按旧墙宽算"的贴面件失效**：檐口、托架、隅石上段、檐下色带、侧墙窗，改退台必须整组重算。
21. **多层窗必须分层变奏**：三层都用窄高条 = 公寓楼；一层拱 / 二层大 / 三层小方窗才对。
22. **多边形 ≤12 边要整组 `flat=True`**：12 边夹角 30° < `shade_auto` 的 32°，走平滑会被磨成水泥筒。
23. **四边形收分台座别用 `(SBX-DW)*2` 算进深**：正确是 `SBX*2-DW`（差 0.14 → 后墙留缝、托石悬空）。
24. **矩形环用 `frame_ring` 45° 斜接**，不要四段通长（转角两块同高顶面必闪）。
25. **四面栏板 / 12 面墙板的顶面会两两同高**：给每面 6 mm 的 `lift`，视觉看不出，COPLANAR_UP 归零。
26. **贴天花板 / 檐口的"端头小件"要顶到母件底面**（差 0.17 就报 FLOAT）；**栏板端柱与角柱错开 0.20**。

## C. 体量与构图

27. **"被砍了一截"要先量化再改**：六条可测事实（屋面收窄率 / 屋顶占立面比 / 檐口厚度比 / 坡面构件数 / 退台 / 中央凸出量）。逐条改，比"再长高一点"有效。
28. **"主体少了一截"多半是层数不对**：两层×3.7 的墙撑不住 18 m 宽，接大屋顶就像被削了上半截。
29. **大面积低矮建筑染不上色**：农场剪影是哨塔的 3 倍，同样染色面积只有一半。1.85%→6.10% 靠"染两条最长的结构线"（前墙通长腰梁 + 筒仓整圈箍），零散小件堆不上去。角柱只染上段。
30. **俯视角的染色必须画在水平面上**：立面上的 0.2–0.28 队色箍在 58° 俯角下被压扁到 1/3（实测俯视 1.53%）；压到压顶顶面做成色块才到 5.36%。
31. **读不出语义的细节是负资产**：1.2 m 老虎窗读成烟囱、发光顶盖读成橙板 → 删。
32. **地面一层一个高度，不留薄片**；铺石用大石板（小石板在 RTS 尺度读成散落瓷砖）。
33. **这个尺度（门廊 4 m 宽 3.5 m 高）不做柱廊**：两根独立圆柱 + 檐部 = "细杆撑平板"，侧视是一块悬空板。改**实心山门 + 深拱洞**。
34. **"从柱顶斜回檐梁"的撑做不出来**：柱在出檐外、檐梁在出檐内，任何连线都要越过檐口 = 悬空斜杆。两件体量的关系交给"位置 + 轨道"去读。
35. **斜撑是"想当然的细节"**：山墙从柱脚斜到檐口，必然穿窗 / 穿披屋柱 / 穿筒仓。改两道横梁（板墙的正常骨架）。**先算这条线上还有谁**。
36. **门这类带中心的组合件，所有子件都要加同一个中心**：农场门洞中心 x=0.80，门柱写成 ±(GATE_W+0.11)（相对原点）→ 门扇与门柱错开 0.8 m。门扇宽度也别写死。
37. **面板 / 铺板必须抬到母件之上**：`d1_plank` 中心比 `d1_deck` 顶面低 0.16 → 只剩 4 条缝。deck 厚 0.24、plank 厚 0.06 压在它上面，板顶 = 平台顶。
38. **水晶 / 火焰必须两档**：单档在平光下是一块色板；亮尖不超过整根 1/4，超了远景读成"白尖铅笔"。冷焰同理——整朵用亮紫会烧成一团白。
39. **重色块不要超过剪影的一档明度差**：明度秩序写死为"地面 → 台基 → 压顶 → 墙 → 暗构件 → 屋面 → 铁/金 → 队色"，每层只做一件事。

## D. 命名 / 体检

40. **对象名必须匹配体检前缀**：`post` 不匹配 `post_`，被判成 other 系统，同系统叠压立刻变 CLIP_CROSS。命名一律"前缀 + 下划线"。
41. **体检口径**：`CLIP_CROSS 0`（跨系统真相交，白名单每条要写物理理由）/ `COPLANAR_UP 0`（朝上共面会闪）/ `FLOAT 0`；`grounded` + `front_ok`。
42. **对齐脚本必须先清场**，否则 `.001` 后缀对不上；`bl_act` 的 stdout 会截断，长报告让脚本自己写文件。
43. **改建筑高度必须重测阵营色**：剪影面积按高度涨、染色面积不变，一拉高就掉。

## E. 材质 / 图集 / 阵营色

44. **新增材质只能追加在 `ATLAS_ORDER` 末尾**，且同步 `EMISSIVE_MATS`（漏了 `pin_uv` 报 `slot_of` 返回 None）。图集 5×6 / 512² / 内缩 22。
45. **木色三档**：`wood_warm #9B6236`（平台板 / 梯档 / 柱头）/ `wood_mid #5F3D1F`（墙板 / 栏板实板）/ `wood_dark #3E2718`（柱 / 梁 / 扶手）。两档撑不住 3.9 m 的墙。
46. **图集合材质前先删同名材质**：`team` 会被改成 `team.001`，换色静默失效。
47. **`roof_wood` 只给农场**（含披屋），其余用 `roof` 深板岩；`roof_pale` 只做亮脊 / 次屋顶。

## F. 细分 / LOD

48. **细分只磨小体量件**：石基 / 木墙 / 平台板 / 屋面板这种大平面，CC 会把棱磨成一圈渐变的圆（"塑料感"来源）。`skip_cc` 必须列全这些前缀。
49. **多边形件（12/8 边棱柱、穹顶、拱）必须整组 `flat=True`**，否则磨成水泥筒。
50. **宽前缀 LOD keep 会把远景撑爆**：`tw_/bf_/sp_/clock_` 全保留 = 5.5k tri。远景要 `LOD2_DROP` 单独丢钟面刻度 / 指针 / 拱石 / 铅箍 / 徽记（城镇大厅 v2 5,476 → 4,064）。
51. **手游档材质 ≤ 4**；三档预算写在各座 `export_mobile.BUILDINGS` 里，不统一。

## G. 出图 / 图标

52. **背光（rim）会在深色地面留硬边亮斑**；资产说明图用相机相对主光 + 补光 + 反弹。
53. **24 采样的快速看片会在细薄构件上出现"细密噪点带"**——那是 TAA 欠采样，不是 z-fighting。判据：64 采样干净 = 几何没问题。
54. **图标**：512 卡面（暖石背板 + 金线框）→ 128 / 64；机位方位 26° / 俯角 24°，正交；用**细分版**出图。
55. **`ImageChops.add` 的 `scale` 是除法**；Blender 自带 Python **没有 PIL**（图标后处理用系统 Python）。

## H. Blender API 坑

56. `extrude(origin=(u,v))`：v 是"第二个轴的起点"，不是偏移；`lathe` 的 z 是**绝对高度**。
57. `can_z()` 是坡棚板底面，坐棚面的件要按 `can_z + 板厚/cos(坡角)`。
58. 多边形顶点顺序 = 法线方向；定位用 `ray_cast` 从相机方向打。
59. `image.pixels` 是该色彩空间的原始值；`colorspace` 必须在写像素**之前**设；写后要 `update()`。
60. `wm.read_homefile(use_empty=True)` 之后 `join()` 会 poll failed → 手写 `hard_reset`。
61. `save_as_mainfile(relative_remap=True)` 会按上次打开目录重算相对路径；**Blender 5.2 不接受 `save_version` 关键字**，用 `bpy.context.preferences.filepaths.save_version = 0` 防 `.blend1`。
62. 脚本改完查 BOM：PS 5.1 的 `Set-Content -Encoding UTF8` 会写 BOM，Blender 报 `U+FEFF`。
63. **DSH 桥接（9876）在 `-b` 后台模式拒绝启动**：必须 GUI 模式 `blender.exe --python build/start_bridge.py`。本机 blender 在 `D:/360安全浏览器下载/blender.exe`。

## I. 第八座（蒸汽车坊）新增

64. **山墙三角形的底边 = 墙顶标高**，不是墙脚。写成墙脚会得到一块 7.2 × 7.6 的"山墙"，
    把门洞整个糊死，正面读成"一堵没有门的白墙"（v2.0 的翻车）。
65. **封檐板必须盖住屋面端头的断面**：屋面端头是竖直面、正对相机，受光后是一条白色亮带，
    像给屋顶描了银边。板中心要落在屋面厚度的中线上（下移 0.08）、厚度大于屋面竖向厚度。
66. **山墙上的横向木构要按"该高度的三角形宽度"重算**：6.34 高处只有 4.55 宽，
    5.10 宽的横梁两头会戳进屋面。同理：竖棂顶端要按 `RIDGE_IN - |x|` 收。
67. **发光面不能是一整块**：0.72 × 0.56 的整块 `ember` 读成"橙色便利贴"。
    拆成 3–4 块大小不一的火炭 + 一根铁栅 + 石槛，才读成"火"。
68. **蓝色脊帽的宽高比决定它像不像塑料管**：0.26 × 0.13 是一条圆管；0.34 × 0.065 才是油漆压条。
69. **`bslib.cyl(axis="Z")` 返回 None**（只支持 X / Y）—— 桶盖、竖圆柱一律走 `br_model.vcyl`。
70. **贴着主檐的附属体量，半径被"檐口外沿 ↔ 披屋墙内表面"夹住**：
    蒸汽车坊净空只有 1.53 m，锅筒最大 φ1.40。想放大必须先移披屋，别只改半径。
71. **后山墙百叶只做浮条 = 碎片**：必须有框 + 背板，否则四根铁条像"贴在墙上的百叶碎片"。

## J. 第九座（箭塔）新增

72. **`frame_ring` 会在正立面拉一条通长石带**：墙裙 / 腰线直接用它，就会**横穿门扇**
    （门的下半截被 0.16 厚的石带糊住，正面读作"门后面还有一段墙"）。
    凡"从地面砌到门洞高度"的环，一律用 `band_ring_gap` 拆成五段（正面留 0.92 缺口）。
73. **拱上墙的轮廓从拱脚起算，不是拱顶**：写成 `[(-GW, ARCH), ...] + 弧` 会在拱肩两侧
    各留一块 0.6 × 0.6 的三角洞，从正面直接看进门厅。正确顺序是
    `弧（π→0）+ 右上角 + 左上角`。
74. **门扇竖板间距按"半扇宽"重算**：`GW*0.5 + k*0.205`（k 取 −2…2）跨到 1.16，
    而半扇只有 0.66 —— 三块板埋进石墙，正面只剩两块。5 条板用 0.13 间距。
75. **`revolve` 的轮廓别以 `r=0` 收尾**：`[(0,0),(1.06,0),(1.06,0.10),(0.94,0.16),(0,0.16)]`
    会把顶面收成一个锥（炮座变"倒扣的碗"）。要平顶就让最后一点 `r>0`，靠端面封口。
76. **抬起来的"板缝"会和所有落地道具相交**：5 条 12 mm 高的暗缝压在平台上，
    弩炮座 / 水桶 / 火盆全部 CLIP_CROSS。板缝在 RTS 距离看不见 —— 删。
77. **道具别放在台基投影里**：台基 5.76 见方、高 0.42，箭捆架 / 石堆摆在 |x| 2.5–2.8
    就整组埋进台基。地面道具必须落在"台基之外"（|x| > 台基半宽 或 y > 台基前沿）。
78. **队色压在垛口顶面上要薄**：0.07 厚、出檐 0.08 读成"蓝砖块"；
    0.048 厚、出檐 0.023 才读成"刷上去的一层漆"。这是一条"厚度决定语义"的规则。
79. **平台上的火盆要按平台尺寸重做**：哨塔的 `brazier` 火舌 0.82 高，
    放到 5.4 m 的平台上读成一支火把 —— 按 0.6 比例重写（石座 0.30 + 盆 r0.24 + 焰 0.33）。
80. **弩炮的"结构完整性"和"剪影可读性"是两件事**：侧颊 + 横梁 + 立式扭簧在工程上更对，
    但 RTS 俯视是一堆交叉木条。只认三件：**一根通长弩床 + 一对近横向弩臂 + 一根前指的弩矢**。
81. **贴片式箭孔靠 16 mm 的深浅差**（内衬凸 20 mm、煤黑窄缝凸 36 mm），不要真开洞 ——
    开洞要把塔身拆成十几块，低模档会多出十几个面/孔，而且容易露出一条通到内腔的缝。

## K. 第九座改版（箭塔 v2：整顶攒尖亭 + 剪影箭）

82. **"绕轴一圈的羽"永远读成梭形**：四片（或三片）竖直薄板绕着一根杆排一圈，
    从任何水平方向看都会合成一个对称的梭形 / 灯罩。想做"箭"，只有**剪影**一条路 ——
    两片互成 90° 的箭形板（铁箭身 + 队色羽），转到与戗脊对齐的 45°，3/4 机位
    那片只偏 11°，读作完整的箭。尺寸：镞宽 0.60 / 箭身 2.84 / 羽展 0.72。
83. **剪影板的内缘必须埋进中心杆**（给到 r=0.02）：贴着杆放会判 FLOAT；两片板
    之间还要一根铁箍 + 金束"绑"起来，否则是两片插在屋顶上的刀片。
84. **冠部被压成一条 = 头身比不对**：v1 塔身 8.9 m、冠部 1.5 m，读作"石柱顶个帽子"。
    v2 塔身 8.85、冠部 8.6（战棚 0.44 + 亭 2.3 + 顶 2.6 + 箭 2.8）才对 ——
    War3 人族塔的读感来自"大盖压住塔身"，不是"塔身高"。
85. **"整顶亭"在几何上的落点是"屋面 ≈ 栏板宽"**（5.40 vs 5.68）。屋面缩到平台
    中间（v1 的 5.20 vs 5.72 只是诱因之一）就会读成"平台上扣了个顶"。
    俯视不会塌：58° 俯角下高处的东西往相机方向偏 0.62·h，屋面自然让出一圈战棚。
86. **三道队色横箍连排 = 包装带**：封檐板 + 栏板扶手 + 檐口漆线三样距离 1 m 上下，
    从上往下看就是一摞蓝环。**两道 + 中间一层空的暗部**才对；中间那道改深木。
87. **竖向色块（军旗 / 挂毯）不能当主力色源**：3/4 视角下亭内的军旗被屋顶遮掉
    一半，实测只补 0.7%。补 1% 可以，补 3% 不行 —— 主力还得靠水平结构线。
88. **深色屋面上的戗脊要用亮脊**（`roof_pale`）：`roof_edge` 的暗脊在 RTS 距离
    直接消失，屋面读成一块板（规则 A3 的复发）。
89. **拱内木鼓 + 门楣梁 = 门洞里塞着一块木头**：拱内改**填石**（`stone_mid`），
    门读成"实心石拱 + 一扇方门"，门楣梁才有结构意义；再加一块拱心石咬住。
90. **贴在拱肩上的"队色壁柱"是贴纸**：拱是斜的，竖条贴上去两头必然一半悬空。
    队色交给"门扇下板 + 横匾"这类有实体的面上。
91. **檐口队色线做成外凸环 = 蓝塑料托盘**：外凸 0.12、厚 0.06 的环会读成"托着
    屋面的蓝盘子"。做成贴在封板外立面上的漆线（外凸 0.005、厚 0.15）才对。
92. **`disc_y()`（或任何手工建了物体的辅助函数）必须 `self.add()`**：只
    `mesh_obj()` 不加入 items 的物体能渲染，但不合并 / 不进图集 / **不跟
    mirror_x**，交付 .blend 里会多出孤立对象和一整个多出来的材质（规则 A4 复发，
    这次踩在箭靶的三个靶面上）。
93. **托石要和斜撑抢同一段高度就先算清楚**：石挑檐只出挑 0.16 时，托石（8.55–8.85）
    与斜撑（8.58 起）必然 8 处相交 + 16 处同高共面。挑檐出挑小就直接删托石，
    斜撑已经把"挑出"讲清楚（规则 C35 的复发）。
94. **改版前先归档资产**：`assets/<建筑>` 整个复制进
    `_历史版本/<建筑>_v<n>/`，再覆盖同名文件。箭塔 v1 的 GLB 就是这样被 v2 覆盖掉的
    （只剩 `docs/箭塔/v1` 的图与报告）。

## L. 地形底材（2026-10-29 新增，7 条）

95. **要无缝，只有"把 UV 映射到 4D 圆环"这一条路可靠**：`u→(R·cos2πu, R·sin2πu)`、
    `v→(R·cos2πv, R·sin2πv)`，取 `R = 1/(2π)` 让弧长 = 1 个 tile，Noise 的 `Scale`
    直接就是"每 tile 几个周期"。offset 混合会留一圈对比变浅的带，镜像会留对称，
    Wrap 到格子里做 Voronoi 会在缝上给一条笔直的裂缝。
96. **`noise_dimensions` / `voronoi_dimensions` 不显式设 `4D`，`W` 是静默忽略的** ——
    图照出，缝照有，而且看不出来是哪一步错了。Blender 5.2 的 Voronoi 支持 4D。
97. **切噪声阈值前先标定**。FBM 的线性值集中在 0.31–0.69（sRGB 口径 0.56–0.86），
    凭感觉写 0.5 会把整张图夹死成一个颜色。标定时注意：PNG 像素是 **sRGB 编码值**，
    节点里的场是**线性值**，混用等于整体抬 0.25。
98. **草地细节不能用圆点**。抖动格点的圆点不管怎么调都读成"胡椒粒/波点布"；
    普通噪声当逐格哈希还会退化成规则网格（相邻格心太近、噪声连续）。
    要"一团有轮廓的东西" → 高频噪声取顶端几个百分点，再加一层弱光晕。
99. **平铺重复感先查"色块尺寸 vs tile 尺寸"**：一块拼图里只有一个完整色块，
    它就变成地标，眼睛会自动连成网。先把色块切碎（一个 tile 里 4–5 片），
    再加大 tile（6 m → 8 m）。加大 tile 前先确认特征尺寸还合理。
100. **低对比 Albedo 必须加 1 LSB 抖动**。明度跨度只有 7/255 时，8bit 量化会把渐变
     切成 40–70 px 宽的色带（全图只剩 8 个亮度级）。后处理加 ±0.5 LSB（固定种子），
     渲染器的 `dither_intensity` 设 0 —— 不许它自己乱抖。
101. **正交顶视渲贴图，平面要比画面大一圈，UV 周期延拓**：2×2 的平面铺满画面时，
     边缘像素的滤波会采到画面外（黑底）→ 贴图四周一圈暗边。改成 6×6 平面、
     UV 从 −1 到 2，既不给黑边又保持 u=0/1 精确对齐 tile 边界。

## M. 地形地块（干裂泥地，2026-10-29 新增，7 条）

102. **周期 Voronoi 只能跟"平移副本"比**：站点在 [0,W)² 里，每个胞元要把 ±2 圈邻格
     的 9 个平移副本一起参与半平面裁剪，否则 tile 两侧的胞元形状对不上 —— 拼合时
     缝里会出现半个胞元。裁完再按 tile 方框的 9 个位置各裁一次、平移回来。
103. **等距内缩不能用"相邻偏移边求交"**：周期 Voronoi 的胞元里常带 1 cm 级退化边，
     两条几乎重合的偏移线求交会算出**自交多边形**，表现是地板上出现一两个大洞
     （不是"少一块板"，是"多出一块扭曲的板"）。用**半平面裁剪式内缩**：每一步都还是
     凸多边形，退化边最多让那一步白做。
104. **支撑环 / 退台环必须与母面同顶点数**：拿"内缩出来的多边形"当环，裁剪可能少点，
     环面就会连错顶点、渲染出一堆**黑色三角**。要顶点数不变就沿角平分线偏移。
105. **薄板不要上 Catmull-Clark**：0.9 m 宽、4 cm 高的板被细分一级就揉成鹅卵石，
     "干裂的泥"立刻变"石板路"。地表只给 6 mm 倒角，**细分只给道具**（卵石要圆）。
     判断标准不是"项目里都上细分"，而是"细分有没有把语义磨掉"。
106. **缝壁要独立材质**：板顶与侧壁共用一个土色材质时，侧壁被主光打亮，每条缝读成
     一条**亮倒角**（像切过的石材）。侧壁压到比板顶暗两档，缝才沉下去。
107. **道具落点按"倾斜后的板面"算高度，再沉 4–12 mm**：板本身有 ±0.02 的倾斜，
     细分还会把开口件的底边往上收 —— 按平面高度摆会浮。
108. **导出前按材质合并**：一块 8×8 m 地块切出 125 个构件 = 125 次 draw call。
     `join_by_material` 之后 7 个物体，主版 9.4k tri、低模 3.2k tri，两版共用材质。

## N. 第十至十三座（地牢 / 地下城入口 / 酒馆 / 火）

109. **"往下走"的前提是台体比隧道高**。地牢台基 2.55 / 隧道 2.34 是下限；台体再矮，门洞只能做成平的。
    想表现"沉入地底"不一定要负 Z：抬台 + 隧道 + 尽头的黑，三件就够。
110. **掀顶方塔不要再盖一片残顶**。半片坡顶在俯视里读成"塔顶盖了块水泥板"，
    把"洞"糊掉；残墙锯齿 + 塔心方井本身才是最强的废墟读法。
111. **高处的贴片（苔、裂纹）会被判 FLOAT，而且远处看不见**。苔只做墙脚和台面；
    墙面高处要"脏"就换一段材质，不要贴薄片。
112. **带旋转的碎石要按顶点最低点落地**。按轴对齐的 z0 算，旋转会把底角转下去或转上来：
    要么穿地，要么悬空 2 cm。`stones()` 现在按 `min(v.co.z)` 重新落位，沉进地面 1 cm。
113. **吊笼的横箍在转角处必然同高**。x 向与 y 向的箍要差 5 mm 以上，否则 COPLANAR_UP 一次报 16 对。
114. **队色别做成"梯级条纹"**：踏面一条、踢面一条地铺，正看是一道蓝杠一道灰杠，
    读成梯子/泳道。要么整段一条毯（含踢面同色），要么不做 —— 地牢最后选了"不做"。
115. **低矮建筑不能套三步脚手架**：3 × 2.2 = 6.6 m，比 3.49 m 的酒馆还高，`SCAF_OVER` 直接判失败。
    `cs_kit` 现在对 H < 5.2 m 允许 1–2 步；三步只适合 7 m 以上的建筑。
116. **地板板面必须真的到设计标高**。酒馆地板条中心写 `F0+0.055` 时顶面只有 0.25，
    而所有家具按 0.28 摆 —— 一次体检报 14 个 FLOAT，根因只有这一条。
117. **酒架会穿横幅**。3.16 垂到 1.14 的横幅正好盖住 1.55 / 2.02 两层的酒瓶；
    把酒架拆成左右两段、给横幅让出中间，比把横幅挂高更像真酒馆。
118. **炉火高度要小于炉口内顶**。0.86 高的火从 0.52 起，顶到 1.38；炉口内顶 1.32 —— 火会从炉顶穿出去。
119. **崖顶不能是平顶**。14 m 宽的平顶会立刻读成"一栋很宽的楼"；
    一排大小/高度/微旋转都不同的碎岩（7 块就够）才读成"崖"。
120. **图集扩容只许追加**：5×6 → 5×8 用了第 28–38 格，前 27 格的列序不变；
    旧 GLB 自带旧图，不受影响，但**重生成图集与重导 GLB 必须成对执行**。
121. **同一条队色横线不要超过两道**。地牢 v1 试过"垛口压顶 + 台基压顶 + 外梯侧墙"三道，
    正视图变成蓝条纹的石头；删到只剩门楣 + 垂旗才对。占比掉到 5% 也认。
